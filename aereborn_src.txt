# AEReborn 静音标识与空块早退优化计划

本方案参考 PipeWire（`SPA_CHUNK_FLAG_EMPTY`）与 GStreamer（`GST_BUFFER_FLAG_GAP`）的成熟设计，在不污染 `ByteBlock` 图外 I/O 视图、不引入业务逻辑到 `core/` 的前提下，为 AEReborn 音频图增加 **1 字节数据存在位（Active Flag）自动传播机制**，并基于该标识在内置插件上落地 **空块早退优化（Empty-Block Early Exit）**。

---

## 1. 背景与优化目标

在固定周期软件时钟引擎中，`Engine::Clock` 会按 2--40 ms 的固定节拍持续驱动整张生效渲染计划（`Plan`），导致当前存在两类问题：

1. **语义混淆（阻塞自动优先级闪避）**：当上游 `Capture` 处于离线、预填充、队列读空（如 `PushSource` 停推、WAV 播完）或端口未连接/暂停时，引擎与端点会向缓冲填零静音。下游节点面对全 `0.0f` 样本，无法区分“**通话中对方静音但仍在推全零包**”与“**通话已挂断/文件已播完**”。
2. **空闲算力浪费与次正规数隐患**：待机中的多路网络接收槽位、静音支路或未推流的 `PushSource` 若串联了跨采样率 `Convert`（96 抽头多相 Sinc 卷积）或多路 `Mixer`，每拍仍会对全零数据执行完整编解码、卷积与浮点乘加；对于未来的 IIR / 混响节点，持续处理全零输入还容易触发 IEEE 754 次正规浮点数（Denormal）性能退化。

### 业界参考与 AEReborn 取舍

| 维度 | GStreamer (`GST_BUFFER_FLAG_GAP`) | PipeWire (`SPA_CHUNK_FLAG_EMPTY`) | AEReborn 本方案设计 |
| --- | --- | --- | --- |
| **标志载体** | `GstBuffer::flags` | `spa_chunk::flags` | `ProcessContext` 中的 `input_active` / `output_active` 视图 |
| **为何不放进 `ByteBlock`** | — | 块头与图强绑定 | `ByteBlock` 被 `WavFile`、`PushSource`、ALSA/WASAPI 等图外模块广泛复用，放入 `ProcessContext` 可保证图外接口零污染，且不破坏 `View<const OBBlock>` 的只读容器契约 |
| **默认透传方式** | 框架基类自动复制 metadata | 端口共享 `spa_chunk` + `audioadapter` 转发 | `Engine::Runner::Plan::render()` 在每步 `process()` 前集中接力并写入默认值，**用户自定义节点一行不改即自动透传** |
| **多输入汇聚规则** | 全 GAP 才输出 GAP | 全 EMPTY 才输出 EMPTY | 任意未静音输入为活跃，则输出活跃（逻辑或） |

## 2. 五条核心不变式（设计红线）

落地过程中必须严格守住以下五条契约，避免引入隐蔽的音频瑕疵或回归：

1. **存在位语义与样本值彻底解耦**
   * `active == 1`：上游本拍交付了真实音频流（**即使所有样本恰好都是 `0.0f`**，例如通话对方静音或 WAV 文件内的静音段）。
   * `active == 0`：本拍无真实数据流（端口未连接、上游被 `set_paused(true)` 排除、`Capture` 离线/预填充/读空、`Matrix` 稳态零增益关断、或 `Mixer` 全部未静音输入均为空）。
2. **静音内存安全兜底（Silence Memory Invariant）**
   * 即使某节点将 `output_active` 置为 `0` 并走早退路径，**仍必须将输出块清零（`clear()` 或 `std::memset(0)`）**。
   * 原因：`float_pool` 与 `byte_pool` 在每个 tick 间复用；不关心存在位的用户自定义节点或 `Playback` 会直接读取样本区，若跳过清零会导致上一拍残余样本循环泄漏。对单拍数 KB 的 L1 缓存块执行一次 `memset` 耗时仅纳秒级，换来绝对安全的内存不变式。
3. **热路径零堆分配、零锁、`noexcept`**
   * `input_active`、`output_active` 与 `input_sources` 全部在 `commit()` 阶段随 `Plan` 一次性分配完毕；`Plan::render()` 仅做顺序数组下标访问。
4. **对既有代码与直接单测 100% 向后兼容**
   * `ProcessContext` 保持 C++14 聚合类型（Aggregate），不引入用户自定义构造函数。既有单测直接构造 4 字段 `ProcessContext{period, tick, inputs, outputs}` 时，末尾两个 `View` 自动值初始化为空视图；`has_input()` 对空视图默认返回 `true`，`set_output_active()` 对空视图安全空操作。
5. **汇端 `Playback` 必须照常消费静音块**
   * `Playback::process()` **禁止**因 `has_input(0) == false` 而跳过写入 `FrameRing`。
   * 原因：录音文件（`WavPlayback`）与周期回调（`UsrPlayback`）需要连续时间线，异步声卡（ALSA / WASAPI）的 ASRC PI 闭环依赖稳定入队维持 $50\%$ 队列水位。

## 3. 内核改造设计（`core/`）

### 3.1 `core/types.h`：扩展 `ProcessContext`

在 `ProcessContext` 末尾追加两个轻量只读/可写字节视图，并提供语义清晰的访问方法：

```cpp
/// @brief Timing, port blocks, and per-port active flags passed to a node for one process call.
/// @note All views and backing buffers are borrowed for the duration of that call.
struct ProcessContext
{
    BlockPeriod block_period;             ///< Duration of the current engine tick.
    std::uint64_t tick_position;          ///< Zero-based position of the current tick.
    View<const IBBlock> inputs;           ///< Read-only input blocks in port index order.
    View<const OBBlock> outputs;          ///< Output blocks with writable samples in port index order.
    View<const std::uint8_t> input_active;  ///< Nonzero when an input carries real stream data.
    View<std::uint8_t> output_active;       ///< Output active flags initialized to engine defaults.

    /// @brief Check whether an input port carries real stream data on this tick.
    /// @note Returns true when input_active is omitted (for direct standalone node calls).
    bool has_input(std::size_t index) const noexcept
    {
        return index < input_active.size() ? input_active[index] != 0 : true;
    }

    /// @brief Override whether an output port carries real stream data on this tick.
    /// @note Even when set to false, the node must still write silence to the output block.
    void set_output_active(std::size_t index, bool active) const noexcept
    {
        if (index < output_active.size())
            output_active[index] = active ? 1 : 0;
    }
};
```

### 3.2 `core/engine.cpp`：编译期索引与每拍自动传播

#### (1) `port_range()` 支持可写视图重载

在 `core/engine.cpp` 匿名命名空间补充非常量版本，供 `output_active` 构造可写 `View<std::uint8_t>`：

```cpp
template <class T>
View<T> mutable_port_range(std::vector<T> &items, std::size_t first, std::size_t count) noexcept
{
    if (count == 0)
        return {};
    return {items.data() + first, count};
}
```

#### (2) `Engine::Runner::Plan` 新增三个扁平数组

与现有 `inputs`、`outputs` 一一对齐，全部由 `commit()` 一次性构建：

```cpp
struct Plan
{
    // 原有成员保持不变 ...
    std::vector<IBBlock> inputs;
    std::vector<OBBlock> outputs;

    // 新增成员：每端口 1 字节存在位及上游输出下标映射
    std::vector<std::uint8_t> input_active;
    std::vector<std::uint8_t> output_active;
    std::vector<std::size_t> input_sources; // Link::unconnected 表示未连接或上游已暂停
};
```

#### (3) `bind_blocks()` 绑定阶段记录上游下标

在 `Engine::Runner::bind_blocks()` 中同步分配数组并填充 `input_sources`：

```cpp
plan.input_active.assign(layout.input_count, 0);
plan.output_active.assign(layout.output_count, 0);
plan.input_sources.assign(layout.input_count, Link::unconnected);
```

在输入端口绑定循环内补充：

```cpp
if (link.node_index != Link::unconnected)
{
    const auto source_output = plan.steps[link.node_index].first_output + link.port_index;
    plan.inputs[input_index] = plan.outputs[source_output];
    plan.input_sources[input_index] = source_output;
}
else
{
    const auto spec = entry.inputs[port];
    plan.inputs[input_index] = plan.block(spec, spec.max_frames(period), 0);
}
```

> 容量边界安全性：`layout.input_count` 与 `layout.output_count` 已在 `measure_layout()` 中分别受 `plan.inputs.max_size()` 与 `plan.outputs.max_size()` 约束；由于 $\text{sizeof}(\text{IBBlock}) \ge \text{sizeof}(\text{size\_t}) > \text{sizeof}(\text{uint8\_t})$，新增三个数组不会发生容量溢出。

#### (4) `Plan::render()` 自动接力与默认传播

由于 `steps` 已按拓扑顺序排列（上游节点必先于下游节点执行），每拍循环如下：

```cpp
for (const auto &step : steps)
{
    std::uint8_t any_input_active = 0;
    for (std::size_t p = 0; p < step.input_count; ++p)
    {
        const auto input_index = step.first_input + p;
        const auto source = input_sources[input_index];
        const std::uint8_t active = source != Link::unconnected ? output_active[source] : 0;
        input_active[input_index] = active;
        any_input_active |= active;
    }

    // 源节点（无输入端口）默认输出活跃；处理节点默认按全部输入的逻辑或透传。
    const std::uint8_t default_output = step.input_count == 0 ? 1 : any_input_active;
    for (std::size_t p = 0; p < step.output_count; ++p)
        output_active[step.first_output + p] = default_output;

    step.node->process({period, tick,
                        port_range(inputs, step.first_input, step.input_count),
                        port_range(outputs, step.first_output, step.output_count),
                        port_range(input_active, step.first_input, step.input_count),
                        mutable_port_range(output_active, step.first_output, step.output_count)});
}
```

## 4. 内置插件的静音标识与早退优化（`plugins/`）

### 4.1 全节点行为总览

| 插件节点 | 存在位产生 / 改写规则 | 空块早退优化动作 | 算力收益 |
| --- | --- | --- | --- |
| **`Capture`** | `set_output_active(0, frames != 0)` | 离线或读空时原有逻辑已跳过队列读并清零 | 作为全图真实流源头，精确区分停推与全零包 |
| **`Playback`** | 无输出端口 | **不早退**，照常写入静音帧保时间线与 ASRC 水位 | 保障设备/录盘连续性 |
| **`Convert`** | 正常流 `1`；拖尾冲刷期强制 `1`；冲刷完毕走默认 `0` | `tail_remaining_ == 0` 且无输入时，跳过编解码与 96 抽头卷积，直接 `memset(0)` | **收益最高**（砍掉空闲分支全部重采样与编解码开销） |
| **`Matrix`** | 无输入走默认 `0`；稳态零增益显式写 `0` | 无输入时跳过矩阵乘加与斜坡计算，清零并同步 `gain_ = target` | 跳过多声道矩阵乘加与斜坡循环 |
| **`Mixer`** | 写未静音且活跃输入的逻辑或 | 跳过 `muted_[i] \|\| !has_input(i)` 的输入支路 | 空闲/静音路零样本读写开销 |
| **`Tone` / 自定义节点** | 无需改代码（引擎默认：`Tone` 为 `1`，处理节点自动透传） | 保持原逻辑；未来有状态插件可按需接入三态早退 | 零侵入兼容 |

### 4.2 `Capture`（`plugins/endpoint.cpp`）

在 `Capture::process()` 末尾补 1 行即可成为整张图的精确活跃源头：

```cpp
void Capture::process(const ProcessContext &context) noexcept
{
    const auto output = context.outputs[0].f32p_view();
    std::size_t frames = 0;
    if (enter_graph(graph_state_))
    {
        if (prefill_ready(ring_, primed_, target_frames()))
        {
            frames = ring_.read(output);
            if (frames < output.frames())
                underrun_frames_.fetch_add(output.frames() - frames, std::memory_order_relaxed);
        }
        graph_state_.fetch_and(~graph_active, std::memory_order_release);
    }
    output.subblock(frames, output.frames() - frames).clear();
    context.set_output_active(0, frames != 0);
}
```

* 离线、预填充未就绪、队列读空（WAV EOF、停推、硬件断流）时 `frames == 0` $\to$ 输出 `0`。
* 只要从 `FrameRing` 读到了真实帧（含部分短读、或调用方刻意推送的全零静音包），`frames != 0` $\to$ 输出 `1`。

### 4.3 `Convert` 三态早退优化（`plugins/convert.h` & `plugins/convert.cpp`）

`Convert` 内部可能包含有状态的 96 抽头 `SincResampler`（历史缓冲 `history_` 保存最近 $96$ 帧输入样本）。为避免硬截断尾音与脏历史残留，采用**三态早退**策略：

1. **成员变量（`plugins/convert.h`）**：新增 `std::size_t tail_remaining_ = 0;`（单位：输入帧数）。
2. **生命周期清零**：
   * `Convert::prepare(BlockPeriod)`：仅在全部缓冲与 `resampler_.prepare()` 成功后，将 `tail_remaining_ = 0;` 与新缓冲一同提交（维持准备失败保留旧状态的强异常安全）。
   * `Convert::reset()`：在 `resampler_.reset();` 后同步执行 `tail_remaining_ = 0;`。
3. **`Convert::process()` 实现**：

```cpp
void Convert::process(const ProcessContext &context) noexcept
{
    const auto input = context.inputs[0];
    const auto output = context.outputs[0];

    if (context.has_input(0))
    {
        tail_remaining_ = resampler_.tail_frames(); // 同采样率为 0，跨采样率为 96
    }
    else if (tail_remaining_ > 0)
    {
        // 冲刷 FIR 拖尾：继续消费上游保证为零的输入块，并维持输出活跃位为 1
        tail_remaining_ -= std::min(tail_remaining_, input.frames());
        context.set_output_active(0, true);
    }
    else
    {
        // 空块早退：history_ 已完全归零，直接按字节清零输出并跳过编解码与卷积
        const auto bytes = output.byte_view();
        if (!bytes.empty())
            std::memset(bytes.data(), 0, bytes.size());
        return;
    }

    // 原有 same_spec_ 直通 / decode_pcm / process_tick / encode_pcm 逻辑保持不变
    ...
}
```

#### 数值等价性与零相位漂移证明

* **比特级等价**：`SincResampler` 的滤波窗口长度 `taps` $= 96$ 帧，且 `resampler_.tail_frames()` 返回的正是 `taps`（同采样率时返回 $0$）。在输入变为 `0` 后，冲刷阶段累计喂入并经 `remember()` 移入 `history_` 的零输入帧数 $\ge 96$，故进入早退态时 `history_` 内每个浮点样本严格等于 `0.0f`。后续全零历史与全零输入的卷积结果与 `std::memset(0)` **比特级完全一致**（AEReborn 支持的全部 6 种样本格式均以全零字节表示静音）。
* **零相位漂移**：`SincResampler::process_tick()` 每拍的分数相位完全由 `(context.block_period, context.tick_position)` 无状态直接算出，不依赖跨拍相位累加器。因此空闲期间跳过 `process_tick()` 不会产生任何相位偏移，数据恢复时首拍即无缝衔接。

### 4.4 `Matrix` 空块与零增益早退（`plugins/matrix.cpp`）

在 `Matrix::process()` 中补齐两处极简逻辑：

```cpp
void Matrix::process(const ProcessContext &context) noexcept
{
    const auto &output_block = context.outputs[0];
    const auto output = output_block.f32p_view();
    const auto frames = output.frames();
    if (frames == 0)
        return;

    const auto target = target_.load(std::memory_order_acquire);
    if (!context.has_input(0))
    {
        output.clear();
        gain_ = target;
        return;
    }

    const bool steady = gain_ == target;
    if (steady && target == 0)
    {
        output.clear();
        context.set_output_active(0, false);
        return;
    }
    ...
```

* **无输入早退**：跳过全部声道矩阵乘加和斜坡计算，同时将 `gain_` 同步到 `target`。这样在静音期间修改目标增益，待音频恢复时直接按新增益生效，不会出现意外的瞬态斜坡。
* **稳态零增益关断**：增益已平滑淡出并稳定在 `0.0f` 时，主动将 `output_active` 设为 `0`（淡出过渡拍仍保持 `1`，确保淡出尾音完整传播），下游混音器或未来的 `PriorityMixer` 可立即感知支路已关断。

### 4.5 `Mixer` 跳过空闲支路与汇聚传播（`plugins/mixer.cpp`）

```cpp
void Mixer::process(const ProcessContext &context) noexcept
{
    const auto output = context.outputs[0].f32p_view();
    const auto frames = output.frames();
    if (frames == 0)
        return;

    output.clear();
    bool active = false;
    for (std::size_t i = 0; i < inputs_.size(); ++i)
    {
        if (muted_[i].load(std::memory_order_acquire) || !context.has_input(i))
            continue;
        active = true;
        const auto input = context.inputs[i].f32p_view();
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
        {
            auto *dst = output.channel(ch);
            const auto *src = input.channel(ch);
            for (std::size_t frame = 0; frame < frames; ++frame)
                dst[frame] += src[frame];
        }
    }
    context.set_output_active(0, active);
}
```

* 当混音器挂接了 8--16 路待机槽位（例如路线 A 动态网络/剪辑总线）而仅 1--2 路活跃时，其余空槽在外层循环直接跳过，彻底消除无效内存读取与浮点加法。

### 4.6 对未来插件的承接与规范

1. **`PriorityMixer`（优先级自动闪避）**：
   * 默认直接消费 `context.has_input(i)` + `hold_ms` 判定各路输入是否活跃：用户推流/播文件期间自动压低低优先级（含全零静音段，绝不误恢复），停推或 WAV EOF 排空过 `hold_ms` 后自动平滑恢复，彻底免除手动状态切换。
2. **未来有状态 DSP 插件（IIR 滤波、混响、LMS 滤波等）**：
   * 遵循与 `Convert` 相同的三态早退模式：在输入变空后等待尾音能量衰减至噪声底以下（或固定冲刷拍数）时，将内部递归状态清零并放行 `output_active = 0`，既节省空闲 CPU，又彻底杜绝次正规浮点数（如 $10^{-39}$ 级状态）引发的 CPU 飙升。

## 6. 验收测试矩阵

===== AudioEngine_Outline.md =====
# AEReborn：音频引擎框架草案

项目使用 C++14。Engine 由内置软件时钟线程推进。设备、文件和网络后端沿用本稿定义的运行边界。
命名空间统一为 `aereborn`。命名规则见 [编程约束](CODING_GUIDELINES.md#1-命名)。
图处理和虚拟 PCM 使用同一套渲染逻辑。API、运行约定和构建方法见第 7 节。

## 1. 参考与取舍

下面区分成熟引擎已有的设计，以及本项目据此作出的选择。参考设计思路，不引入这些引擎作为依赖。

| 官方参考 | 可借鉴的设计 | 本项目的选择 |
| --- | --- | --- |
| [JUCE AudioProcessorGraph](https://docs.juce.com/master/classjuce_1_1AudioProcessorGraph.html) | 处理器组成节点图，通过通道连接；提供图重建机制 | 统一 Node/Port/Connection，将图描述编译为执行计划 |
| [JACK 实时处理回调](https://jackaudio.org/api/group__ClientCallbacks.html) | 处理回调禁止内存分配及可能阻塞的 I/O、锁和等待 | 音频执行路径只处理已准备的数据，外部工作通过有界队列交换 |
| [PipeWire 图运行](https://docs.pipewire.org/devel/page_running.html)、[调度](https://docs.pipewire.org/page_scheduling.html)、[时钟](https://docs.pipewire.org/page_man_pipewire-props_7.html) | 调度组选择 driver；配置与数据处理分离；区分设备时钟并适配 | 每个 Engine 由一条软件时钟线程驱动，设备通过边界适配 |
| [FMOD 混音与连接](https://www.fmod.com/docs/2.04/api/mixing-and-routing-in-the-core-api.html)、[DSPConnection](https://www.fmod.com/docs/2.04/api/core-api-dspconnection.html) | 总线分组、子混音、效果处理；连接持有增益和声道矩阵 | Connection 只读共享同规格端口的数据；Mixer 混音，Matrix 处理声道矩阵与增益，Convert 转换格式与采样率 |

第一版不做多进程共享图、节点并行调度、插件宿主或完整 DAW 自动化系统。先实现能运行、能恢复、能验证的单进程引擎。

## 2. 核心概念与节点实现

Engine 只处理 Node、Port、Connection 三个核心概念。它拥有节点和连接，校验图、准备缓冲并按依赖顺序执行节点；不需要识别节点的具体业务角色。

```text
Node A 的 OPort ── Connection ──> Node B 的 IPort
```

| 对象 | 定位 |
| --- | --- |
| Node | 具有输入/输出端口的执行单元 |
| Port | 节点上的多声道音频入口或出口，固定声明采样率、声道数和格式 |
| Connection | 将上游输出零拷贝地借给同规格的下游输入，只读 |

使用 `engine.connect(OPORT(source, 0), IPORT(destination, 0))` 将源节点的第一个输出连到目标节点的第一个输入。`IPORT()` 和 `OPORT()` 接受节点 ID 和从零开始的端口下标，`connect()` 校验下标。`PortSpec` 固定声明采样率、声道数和 `SampleFormat`。连接两端的规格必须完全一致，规格冲突抛出 `Error(FormatMismatch)`。需要转换时显式插入 Convert。输入端口已由其他来源占用时抛出 `Error(InputBusy)`，多路求和使用 Mixer 的不同输入。没有连接的输入得到该格式的零值静音。
一个 Port 表示一组声道，声道间的选择、复制和合并由 Matrix 表达。
`NodeId` 标识图中的节点，替换节点实例时 ID 继续有效。`ConnId` 标识一次连接，重新连接相同端口会生成新的 ID。原型采用进程内不复用的唯一 ID。Node 不持有其他 Node 的共享所有权，也不各自维护连接列表或调度循环。

Source、Processor、Mixer、Sink 是具体节点的用途。Convert 负责格式与采样率转换。Mixer、Matrix 和 Tone 使用 planar float，算法节点可以声明自己需要的 PCM 格式。I/O 测试经 Capture、Playback 与实际后端交换音频，也可使用 Tone 生成可预测的信号。

| 用途 | 职责 | 当前实现 |
| --- | --- | --- |
| Source | 向图提供音频 | `Capture`、`Tone` |
| Processor | 处理输入并产生输出 | `Convert`、`Matrix`、用户算法节点 |
| Mixer | 显式合并多个相同规格的输入 | `Mixer` |
| Sink | 消费音频并交给设备 | `Playback` |

PCM 适配器和固定端口数量的自定义节点通常继承 `NodeT<I, O>`，由它保存端口描述。需要按周期准备资源的节点重写 `prepare(BlockPeriod)`，默认实现无需准备资源。节点在 `process()` 中从上下文读取周期，数据规格来自自身端口。端口数量由运行时决定的节点可以直接继承 `Node`，通过 `inputs()/outputs()` 提供固定的端口描述。引擎持有节点期间借用这些描述，节点负责保持描述及其存储有效。
后续设备、文件、网络、滤波等节点遵循同一边界。Bus 表示 Mixer 与效果节点构成的应用层总线，不是新的核心基类。

### 从输出创建输入：直接复用端口

任何 `OPort` 都能继续连接到其他节点。Bus 可提供 PreEffects、PostEffects、PostFader 等命名输出位置，第一版先提供最终输出。
需要取得总线音频时，从相应输出连接普通 Sink；需要其他数据规格时连接 Convert，再由算法节点或 Playback 消费结果。图核心不提供独立的端口订阅机制。
编译器保证一个节点每个渲染块只执行一次，同一输出供多个下游只读使用；需要修改数据的下游使用自己的工作缓冲。

这支持“输出作为另一个输入”，并且不依赖物理设备是否在线。系统全局回环录音则作为独立 CaptureSource 能力接入。
第一版拒绝所有图内反馈环，校验同时覆盖音频与侧链依赖。

## 3. 引擎骨架

`core/` 提供 Engine、Node、音频缓冲、PCM 编解码和 F32P 重采样器。`plugins/` 提供 Convert、Mixer、Matrix、Capture 和 Playback。两个端点负责经由 F32P 队列与绑定的 `Backend` 交接帧。`backend/` 的 `Backend` 统一管理设备、线程、转换工作区及漂移补偿。绑定 `Capture` 或 `Playback` 决定运行方向。依赖方向为 `backend → plugins → core`。`tests/support/` 提供缓冲夹具、测试后端和信号源 Tone。

Engine 持有编辑图和渲染计划。`commit()` 按依赖排序，从无输出的 Sink 遍历可达节点；未连接到 Sink 的分支不执行。每个可达节点每周期只执行一次。

引擎按各端口的最大周期帧数分配两块连续缓冲池，分别存放 F32P 的 float 对象和交错 PCM 的字节。连接输入只读借用上游输出；未连接的输入按存储类型共享缓冲池开头的只读零区间。所有缓冲和块视图由 Engine 管理。

`ProcessContext` 提供 `block_period`、`tick_position`、`inputs` 和 `outputs`。`IBBlock` 和 `OBBlock` 分别是只读和可写的 `ByteBlock`，携带缓冲地址、端口规格和本周期实际帧数。`byte_view()` 按原格式借用字节，适用于所有格式。`f32p_view()` 用于 F32P 端口，返回 `FloatBlock` 的只读或可写形式 `IFBlock` / `OFBlock`，声道步长为本周期的实际帧数。`FloatBlock` 也可借用插件工作区的分声道浮点样本，此时声道步长可以大于实际帧数。端口提供的视图只在 `process()` 调用内有效，节点必须写满自己的输出。

`ProcessContext::has_input(port)` 返回该输入在本周期是否需要作为活跃块处理。非活跃块保证以零字节填满，未连接输入和来自暂停节点的输入均为非活跃。源交付的全零样本和 DSP 尾音可以是活跃块。每个周期开始时，引擎将所有输出预设为活跃，因为节点可能在输入为空时继续产生音频。能保证某个输出已填满零字节的节点，可调用 `set_output_active(port, false)` 让下游跳过样本计算。标志视图同样只在本次调用内有效。直接用四个字段构造 `ProcessContext` 时，`has_input()` 返回 true，设置输出标志无效果。

Capture 读到至少一帧即标为活跃，短读补零。队列读空表示当前周期缺数据，网络欠载和正常结束都可能出现这一情况。Convert 在 FIR 历史冲刷完毕后才将空输入标为非活跃。Matrix 在淡出之后的稳态零增益块上标记非活跃。Mixer 只累加活跃且未静音的输入。Playback 继续逐拍入队，包括非活跃的静音块，以保持录音和设备输出的时间线。

渲染计划用连续数组保存端口视图、活动标志和各输入对应的上游输出下标。引擎按拓扑顺序读取上游输出标志，每个节点只访问自身端口范围。包含分数帧端口的计划在每个 tick 更新实际帧数，全整数帧计划使用预先绑定的帧数。缓冲和节点引用由计划统一持有。

控制侧 `commit()` 完成分配和节点准备。运行时，时钟线程在块边界从原子槽接管计划，控制侧等待接管后同步释放旧计划及仅由旧计划持有的节点。沿用的节点实例保留 DSP 状态。

## 4. 执行与时钟

每个运行中的 Engine 由一条内置软件时钟线程串行执行渲染。Capture 和 Playback 在图侧按每个 tick 的实际帧数交接，后端线程通过 SPSC 帧队列交接可变长度的包。队列容量由最大图块和设备单包预算决定。异步硬件以半满为预填充和漂移目标。同步文件与 Null 后端立即上线，由队列背压决定推进速度。

`Engine(BlockPeriod)` 在构造时验证推进周期，支持 2、5、10、20 和 40 ms。调用方可用 `block_period()` 查询周期，节点可从 `ProcessContext` 读取周期。`tick_position()` 返回已完成的周期数，停止后重启继续计数，`reset()` 归零。每个 `process()` 收到本周期开始时的 `tick_position`。

端口只支持 `SampleRate` 枚举中的采样率，单位为 Hz。当前为 8000、11025、16000、22050、24000、32000、44100、48000、88200 和 96000。SampleFormat::F32P 是原生 planar float32；S16LE、S24_3LE、S24LE、S32LE、F32LE 是交错小端 PCM。连接匹配包含采样率、声道数、样本格式及其布局，不做自动协商或隐式转换。

每个端口按累计时间的向上取整差值计算本周期实际帧数。2 ms 下，48 kHz 每块固定 96 帧，44.1 kHz 按 89、88、88、88、88 帧循环。44.1 kHz / 5 ms 为 221、220 帧交替。`PortSpec::max_frames()` 用于容量，`frames()` 和 `frame_position()` 用于实际块与该端口的样本时间。不同采样率端口仍由同一个基础周期驱动。Convert 将分数相位对齐到共享 tick，运行中新增或替换节点不会另起采样时钟。

内置时钟用 steady_clock 和 condition_variable::wait_until 调度，包括空图在内的每个 tick 都执行一个完整周期。延误时跳过过期的唤醒期限，逻辑时间按实际执行的 tick 前进。

独立的设备时钟由后端流式 SincResampler 补偿。消费者完成预填充后，设备侧 PI 根据队列水位在 ±2000 ppm 内修正采样步长，同标称采样率也使用这条路径。同步后端按固定比例转换，同采样率直接编解码。

### 控制与实时处理的边界

应用负责串行执行 Engine 的控制操作。应用可以用 Asio strand 承载控制命令，也可以独立使用 Asio 协调网络 I/O、设备事件和恢复定时。
设备打开/关闭、文件访问、编解码和应用回调都在非渲染路径完成。设备必要的实时缓冲交付由平台后端封装。
音频路径只读写已准备的缓冲，避免堆操作、锁等待、日志和应用回调。

```text
应用串行控制执行器 ──> 计划/参数 ──> 渲染路径
从设备 / 网络 / 文件 ──> 有界队列 ──> 音频入口节点
音频出口节点 ──> 有界队列 ──> 从设备 / 网络 / 文件
音频出口节点 ──> 有界队列 ──> 用户回调执行器
```

队列预先明确单/多生产者归属、容量和满队列行为。活跃数据流不允许无限堆积；慢回调只影响自身输出分支，录音写入跟不上时由后端报告数据缺口。
采集和播放端点使用 `core/fring.h` 的有界 F32P SPSC 帧环，推入和回调后端可复用该组件。
Engine 停止会等待图处理退出。后端停止时唤醒阻塞的异步 I/O，或先完成同步播放排空，再下线并清空队列。同步采集正常读到 EOF 后排出 FIR 尾部，并等待图消费队列。图暂停或停止期间，调用 `stop()` 或 `unbind()` 可取消这段等待。

## 5. 外部资源与恢复

逻辑端点可跨设备切换复用。后端独占借用已经准备的端点，并持有设备句柄。设备枚举、选择策略与自动恢复可由后续的 DeviceService 负责。
选择可以是固定设备、跟随系统默认、优先某类设备；不在收到任意插入事件后立即抢占当前设备。
设备身份使用平台稳定标识及匹配规则，不依赖枚举序号永久不变。

```text
逻辑意图：Running / Paused / Stopped
资源状态：WaitingDevice -> Opening -> Ready -> Recovering / Failed
```

两组状态分别维护：恢复完成仍要服从用户当前意图。
掉线期间保留图、音量和连接；缺失采集数据补静音并由后端记录缺口，输出设备不可用时丢弃该设备数据，总线及其他下游继续处理。
可就地恢复的欠载由后端处理；需重开、等待设备、不可恢复的配置错误由统一恢复策略区分。
重试带退避和取消，主动定期重开也是同一策略的选项。会话代际编号屏蔽过期打开结果与旧设备数据。

一个逻辑端点最多由一个外部参与方读写队列。播放侧在最终设备端点之前显式混音。图侧端点保持既定格式，后端在打开设备时独立协商实际格式。
设备协商格式与逻辑音频格式分离，恢复不改变应用看到的端口布局；适配不了时报告端点失败。

网络与文件复用相同入口/出口节点机制：

- NetworkSource：会话识别、乱序整理、按播放期限解码/FEC/PLC，再交付音频。NetworkSink：排队、编码、发送。先 PCM，后 Opus；协议独立版本化。
- WavCapture 在后端线程读文件，可循环播放。WavPlayback 接收同步播放队列，解绑时回填 RIFF/WAVE 文件长度。
- `PushSource`：应用推入固定规格的交错 PCM，接口返回已接收的输入帧数。帧时间和连续性信息由上层流处理。
- `PullSink`：应用从 `Playback` 拉取固定规格的交错 PCM，返回实际输出帧数。
- `UsrPlayback`：同步播放后端在工作线程按固定批次回调交错 PCM，停止时排空队列和 FIR 尾部。回调中的块只在当次调用内有效。

## 6. 混音策略归属

Mixer 显式求和，Matrix 负责声道映射与增益。两者都只支持 F32P，采样率由构造参数固定，并不要求整张图使用同一采样率。Mixer 每个输入与输出的规格相同；Matrix 的输入、输出声道数可不同，采样率保持一致。

Matrix 的行是目标声道，列是源声道，系数可用于选取、复制、合并和相位反转。全局增益与矩阵在同一遍采样处理中完成，增益在下一个有帧的处理块内线性过渡到目标值。Mixer 对每个输入独立静音，每个有帧的块读取一次设置并跳过已静音的输入。静音、零增益或零系数都跳过源样本，避免未使用的 NaN / Inf 污染输出。

总线可以由 Mixer、Matrix 和效果节点组成，不增加核心基类。Voice、Music、Alert 等抑制策略由后续插件产生增益目标，Engine 不识别角色或策略。

## 7. 时钟运行 API

应用创建 Engine，加入节点、连接端口、调用 `commit()`，再用 `start()` 启动时钟。示例演示 Tone → Mixer → Matrix → 电平 Sink，以及运行中修改 Matrix 增益。[时钟运行示例](examples/clocked_graph.cpp)

### 固定能力与连接检查

插件通过不可变的 inputs()/outputs() 声明实际端口规格。构造端口规格时显式传入 `PortSpec(sample_rate, channels, format)` 的三个参数。Mixer、Matrix、Tone 显式声明 F32P 端口。特殊算法声明其支持的固定 PCM 规格，Engine 在 `connect()` 时检查两端，节点在准备阶段验证资源条件。本版不增加动态能力列表或格式协商协议。

每个输入最多一个来源；同一输出可供多个下游只读使用。需要多路混音必须显式创建 Mixer 的多个输入。连接不包含增益、静音或矩阵，也不增加转换器。

下面的链路可以直接用 connect() 表达：

~~~text
Tone / BUS（48k F32P）
    → Convert（48k F32P → 16k S16LE）
    → 算法（固定 16k S16LE）
    → Convert（16k S16LE → 48k F32P）
    → 其他节点 / Playback
~~~

### 插件接口

| 插件 | 端口 | 配置与职责 |
| --- | --- | --- |
| Convert(input_spec, output_spec) | (1,1) | 支持上述全部格式的转换和图内固定比例重采样，两端声道数须相同 |
| Mixer(rate, channels, inputs) | (N,1) | 相同 F32P 规格显式求和；set_muted(index, bool) 控制单个输入 |
| Matrix(rate, input_channels, output_channels, coefficients, gain) | (1,1) | F32P 声道映射与增益；行对应输出、列对应输入，系数固定；set_gain() 更新增益 |
| Matrix(rate, channels, gain) | (1,1) | 使用恒等声道映射，仅控制增益 |
| Capture(rate, channels, io_period) | (0,1) | 接收外部写入的 F32P 帧，按 tick 向图交付并补足静音 |
| Playback(rate, channels, io_period) | (1,0) | 逐 tick 将图帧写入 F32P 队列，供外部消费者读取 |
| Tone(rate, channels, frequency, amplitude) | (0,1) | 按端口样本时间生成 F32P 正弦波 |

控制接口通过 `aereborn::Error` 报告失败，调用方可用 `code()` 获取 `ErrorCode`。内置插件在构造时验证固定端口与参数，规格错误使用 `InvalidArg`，容量超限使用 `TooLarge`。节点用 `prepare(BlockPeriod)` 准备工作区和处理状态。标准库的分配和线程创建异常，以及自定义节点异常，直接传播给调用方。

图内 Convert 与后端共用 core 的 PCM 编解码和 SincResampler 实现，各自持有处理状态。固定同采样率下，相同规格按字节直通，F32P 与交错 PCM 互转直接读写端口缓冲，两条路径的准备都无需堆分配。同采样率的不同交错 PCM 格式互转共用一块解码缓冲。重采样准备滤波器和历史样本，仅在输入为交错 PCM 时分配解码缓冲，仅在输出为交错 PCM 时分配重采样输出缓冲。

需要 PCM 声道映射时，先 Convert 到 F32P，经过 Matrix，再按需要 Convert 回 PCM。后端在图外完成交错 PCM 编解码和流式重采样，协商出的声道数须与图端口一致。

### 运行控制与缓冲交接

- 图编辑修改草稿。`commit()` 准备并提交新计划。停机时立即生效，运行时等待时钟在块边界接管。旧计划由调用线程释放，此时首个新块的处理可能仍在进行。草稿无变动时直接返回，准备失败时保留当前计划。
- `replace_node()` 要求输入、输出的数量及完整规格相同，布局不同时抛出 `Error(FormatMismatch)`。设备格式变化时重新准备设备侧转换。新包长超出原周期预算时，用同端口规格的新节点替换并提交，保留 NodeId 和图连接。逻辑端口规格变化时修改相应连线。
- `set_paused()` 通过计划移除或恢复节点及相关连接，未改动实例保留状态。暂停导致某个输入失去来源时，该输入得到静音。需要平滑暂停时，先将 Matrix 增益淡出至零，再提交暂停。
- `Matrix::set_gain()` 和 `Mixer::set_muted()` 使用原子变量，可与 `process()` 并发调用。处理块读取当前设置。控制侧从 `Engine::node()` 借用草稿节点指针，须在节点被移除或替换前结束使用，最长有效期到 Engine 析构。
- 图提交并准备端点后，`ActiveBackend::bind(endpoint)` 协商 PCM 规格和单包预算 `io_period()`，`start()` 在工作线程上初始化。`ActiveBackend` 和 `PassiveBackend` 共用 `Backend` 的端点占用与 PCM 转换，并可通过 `Backend&` 统一启停与查询。端点已经被占用时抛出 `Error(Busy)`。绑定失败释放资源和占用。设备启动失败时先回收工作线程，再向控制调用方抛出设备错误。
- `PushSource` 绑定 `Capture`，由应用串行执行 `push(IBBlock)`、控制接口、状态查询和析构。可用单消费者指令队列执行这些操作。PCM 缓冲至少保留到 `push()` 返回。同一流的分片按顺序投递，停止接收旧流数据后再执行停机或重启。`push()` 返回本次接收的输入帧数，后续从该偏移续推。队列空位不足时可能返回零，图侧缺帧时补静音。`stop()` 丢弃未消费的帧并复位重采样器。
- `PullSink` 同样由应用串行调用，`pull(OBBlock)` 读取 `Playback` 中当前可用的 PCM。`UsrPlayback` 由同步播放工作线程消费 `Playback` 队列。分数秒预算在构造 `Playback` 时一次向上取整为微秒，回调使用固定帧数，交付由数据就绪驱动。
- `stop()` 下线并复位 DSP 和漂移，保留绑定和已分配工作区。同步播放先关闭图侧写入，写完已排队帧及 FIR 尾部。同步 I/O 钩子须自行完成操作。切换设备时依次调用旧后端的 `unbind()` 和新后端的 `bind(endpoint)`、`start()`。
- 异步播放补齐设备批次的静音，后端通过 `last_error()` 返回 I/O 终止原因。异步等待和数据交接共用以最后一次 I/O 进展为起点的截止时间。主动停止可唤醒设备等待。测试通过真实的 I/O 工作线程验证设备交接。
- `Engine::stop()` 唤醒时钟并等待在途图处理退出。先停止绑定的后端，再调用 `Engine::reset()`。在移除、替换端点或销毁 Engine 前解绑其后端。派生驱动析构时先调用 `unbind()`。
- 调用方在控制侧串行执行控制接口和析构。同一 Engine 的时钟线程调用控制接口时抛出 `Error(Busy)`。节点需要请求修改引擎时，将操作延后投递到应用的串行执行器并直接返回，例如使用 `asio::post`。实例有效期间可并发读取 `block_period()` 与 `tick_position()`。
- 处理路径尽量避免锁等待，禁止堆分配、释放和调用普通应用回调。异步使用块数据必须在 process() 返回前复制到后端自有缓冲。

### 运行态诊断

链接 `aereborn::diag` 并包含 `diag/inspect.h`，即可在串行控制侧调用 `dump_text()` 或 `dump_dot()`。两者都支持返回字符串或写入输出流。传入需要一起检查的后端，报告会按端点关联生效节点，并列出未进入生效 Plan 的后端。队列水位为近似值，`underrun` 和 `overflow` 分别累计图侧采集缺帧和播放丢帧。`late` 是时钟跳过的周期数，`tick_us` 是最近一拍含时钟收尾的估计耗时。

用 `dot -Tsvg graph.dot -o graph.svg` 渲染信号流图。卡片标题显示端点状态和后端错误短码，橙色标记预填充、排空、跳拍或队列缺帧。多端口节点按插槽接线，Mixer 的静音端口置灰，对应入边用灰色虚线标识。卡片和连线直接显示关键规格，SVG 悬停可查看完整诊断详情。`io.diagnostic_reports` 检查文本和 DOT 输出，`io.endpoint_diagnostics` 检查端点计数、重启及短批次排空。

### 构建与验证

项目使用 C++14。`aereborn::core` 和 `aereborn::backend` 链接 `Threads::Threads`。静态库 `aereborn::backend` 包含 `PushSource`、`PullSink`、`UsrPlayback`、Null 和 RIFF/WAVE 后端。Linux 在查找到 ALSA 开发库时编译 ALSA 后端并定义 `AEREBORN_HAS_ALSA`，Windows 编译 WASAPI 后端。只构建库可设置 `-DBUILD_TESTING=OFF -DBUILD_EXAMPLES=OFF`。

~~~powershell
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build --config Debug --parallel 4
ctest --test-dir build -C Debug --output-on-failure
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure
ctest --test-dir build -C Release -L bus --output-on-failure
~~~

测试目录和 CTest 标签使用 `core`、`dsp`、`bus`、`io`、`regression`。单独运行四声道场景可使用 `ctest --test-dir build -C Release -R '^bus.four_channel_song_archive$' --output-on-failure`。引擎测试使用内置时钟，通过测试节点在块边界与测试控制侧同步。混音、PCM 转换和重采样使用独立字节或数值参照。

`tests/data/` 的两份 48 kHz 双声道 WAV 短片来自《渡口》第 30 秒起的 0.5 秒和 CaliforniaHotel 第 40 秒起的 0.75 秒。四声道测试将两段音乐交错到同一个输入，生成两份 48 kHz 拆分归档和一份 44.1 kHz 混音归档。录音和分段文件在构建目录内创建，正常退出时清理。

`io` 包含后端绑定、设备超时、WAV 文件和时钟漂移检查。Linux 有 ALSA 时运行两种 `plug:null` 采集和播放配置。Windows 默认验证 WASAPI 绑定失败和 Null 接管。设置 `AEREBORN_WASAPI_CAPTURE_ID` 或 `AEREBORN_WASAPI_PLAYBACK_ID` 后，可用 `ctest --test-dir build -C Release -L hardware --output-on-failure` 运行对应实机用例。后端生命周期、异步超时和 ALSA 参数见 [设备后端实施说明](AudioEngine_Backend_Plan.md)。

MSVC Debug 的迭代器代理会在 `noexcept` 构造中分配内存，`regression` 中的分配注入和零分配检查在 Release 执行。示例由默认开启的 `BUILD_EXAMPLES` 控制。

## 8. 实现顺序

1. **离线图核心**：Node、Port、Connection、音频块及 Engine 的准备与执行。用插件节点验证多对多、处理器串联、总线互连、输出分发、环路拒绝。
2. **运行内核**包括内置软件时钟、块边界计划切换、同步提交、插件参数、显式 Mixer/Matrix 和停止屏障。验证调音量时复用图计划，修改连接时保留未变节点的状态。
3. **设备边界与平台闭环。** 用虚拟设备验证 Capture、Playback、重启和漂移补偿。平台驱动已接入，后续实机验收检查短读写、拔插和跨设备恢复。
4. **文件、推入和混音策略**：预读/录制、PlaybackHandle、PushSource、DSP 链、ducking。验证多实例、循环、过载报告和增益包络。
5. **网络**：先 PCM，再 Opus、乱序/抖动缓冲与丢包恢复；验证本地与远程源进入同一 Bus，断网后有界退化并恢复。

各阶段复用同一张图与同一套节点执行机制。

第一步的验收包括 `core.graph_constraints`、`core.commit_failure_and_retry`、`bus.subgroup_and_monitor` 和 `bus.parallel_pcm_algorithm`。路由走实际的 Convert、Mixer 和 Matrix，算法由声明固定 PCM 格式的测试节点提供。

第二步的验收覆盖 `core.clock_boundary_barriers`、`bus.live_input_switch` 和 `regression.render_and_passive_io_without_heap`。可运行 `clocked_graph` 示例观察运行期间的音量更新。

# AEReborn 编程约束

## 1. 命名

**名称用能清楚表达用途的最短写法。** 缩写应当能从组合词或局部上下文直接读懂。需要查注释才能知道名称指什么时，用更明确的词。

| 场景 | 写法 |
| --- | --- |
| 连接 | 单独指一个连接时用 `connection`。组合词可用 `conn`，如 `conn_id`、`conn_count`。 |
| 端口 | 成对的类型使用等长的 `I` / `O` 方向前缀和相同的后缀，例如 `IPort` / `OPort`。 |
| 数据块 | 使用 `I` / `O` 表示方向，`B` / `F` 表示字节视图或浮点视图。字节块为 `IBBlock` / `OBBlock`，平面浮点块为 `IFBlock` / `OFBlock`。 |
| 声道 | 声道循环的索引用 `ch`。声明端口时用 `channels` 表示声道数，用 `input_channels`、`output_channels` 区分方向。 |
| 采样率 | 配置和公开接口用 `sample_rate`。重采样内部可以用常见的 DSP 记号 `src_fs`、`dst_fs`。 |
| 帧、采样点、字节 | 根据单位使用 `frames`、`samples`、`bytes`。含义可能混淆时，用 `frame_offset`、`byte_offset` 或 `period_ms` 写明单位。 |

- **成对的变量保持对称。** 用同一组方向词、相同的后缀和缩写程度，例如 `src_fs` / `dst_fs`、`input_channels` / `output_channels`、`from` / `to`。同一个值在相邻函数中沿用同一术语。
- **成对的类型和接口按长度和结构对齐。** 使用等长的区分词，其余词的位置、写法和后缀一致。例如 `NodeId` / `ConnId` 共用 `Id`，`byte_view()` / `f32p_view()` 共用 `_view`。
- **名称反映实际的访问方式或数据格式。** `byte_view()` 表示按字节访问，`f32p_view()` 明确适用的样本格式。
- **名字反映变量的用途。** `conn_count` 是数量，`conn_index` 是索引。短循环可以用 `i` 和 `ch`，跨多个步骤使用的变量写明角色，例如 `frame_offset`。
- **沿用项目的拼写风格。** 局部变量、参数和函数用 `snake_case`，私有成员变量在末尾加 `_`，如 `frame_position_`。类型和枚举值通常用 `PascalCase`，例如 `ConnId`、`ErrorCode::InvalidPort`。PCM 枚举沿用 `S16LE`、`S24_3LE`、`F32LE` 这样的格式名。

## 2. 类型与接口

- 优先复用现有类型。只有在需要表达独立的含义、约束、所有权或生命周期时才引入新类型。单纯的数量和索引使用现有整数类型。
- 一项规格只保留一个定义来源。采样率和 PCM 格式由 `core/types.h` 提供，样本位深和存储字节数从 `SampleFormat` 推导。端口固定声明采样率、声道数和格式，Engine 只持有推进周期。普通 DSP 插件声明 F32P，特殊模块声明其实际格式，转换由 Convert 完成。
- 函数名和参数顺序应能直接说明调用方向。底层函数、辅助记录和临时状态放在使用它们的实现范围内。对外接口集中表达调用方需要配置、传递或查询的内容。
- 类及其公开接口在声明处使用 `///` 格式的 Doxygen 注释。用 `@brief` 说明职责，按需用 `@param`、`@return`、`@pre` 和 `@note` 记录参数、结果、前置条件及调用约定。涉及借用数据或跨线程调用时，写明有效期和线程约束。
- 保持调用路径直接。抽取能消除重复、集中维护同一约束的逻辑，优先选用普通函数和直接的成员状态。模板用于确有编译期差异的场景，例如固定端口数量。采样率和处理周期作为运行时规格传递。

## 3. 错误处理

- 控制接口用 `aereborn::Error` 报告参数、状态、容量和设备操作失败。调用方用 `Error::code()` 识别失败原因。标准库的分配和线程创建异常，以及自定义节点的异常，直接传播给调用方。
- 后端驱动用 `RetCode` 或 `Result<T>` 报告设备状态。检查成功后再读 `value()`。在绑定和启动的控制边界使用 `or_throw()` 或 `value_or_throw()`，工作线程通过 `last_error()` 报告终止原因。`on_open()` 在控制侧运行，资源准备异常可以传播。
- 工作线程的 I/O 钩子以及实时渲染、DSP、后端停止和解绑使用 `noexcept`。I/O 报告设备错误，DSP 和队列返回处理结果，内部前置条件用断言表达。
- 在建立约束的入口做校验。连接时检查完整端口规格和输入占用，Matrix 构造时检查矩阵尺寸，绑定设备缓冲时检查长度与占用状态。处理路径直接使用已经校验和准备好的数据。
- 资源准备成功后再发布可用状态。失败时保留有效状态，使调用方可以重试。用资源所有权和作用域清理处理失败回滚。

## 4. 音频处理

- 每次时钟触发推进一个固定的引擎周期。节点按自身端口规格写满输出块，连接只读借用上游输出，每个输入只接一个来源。多路混音由 Mixer 完成；Matrix 的行对应输出声道，列对应输入声道。
- 普通 DSP 使用按声道存放的 IEEE float32，PCM 算法使用明确声明的字节格式。Convert 统一承担格式和采样率转换，Matrix 承担声道映射与增益，设备节点只交接数据。同采样率的 float32 保持样本的位表示，只做复制和必要的布局、字节序调整。
- 在 `prepare()` 中分配缓冲并准备滤波等资源。把阻塞 I/O、日志和堆分配放在渲染路径之外，并尽量避免在渲染时等待锁。接口借用缓冲时，应写清谁持有缓冲以及它需要保持有效的时间。

## 5. 修改与验证

- 以业务契约为准，测试负责验证契约。业务接口和分支应有明确的实际调用需求。
- 使用 C++14。修改集中在受影响的接口和实现，沿用周围代码的风格。注释优先说明约束和原因。
- 沿实际调用入口验证改动。优先复用现有测试，在现有测试覆盖不到具体回归时补充用例。音频转换和图处理的边界用实际帧数、声道数和输出值验证。
- 路由测试使用 Tone 或测试源，经 Convert、Mixer、Matrix 和测试收端验证显式图；设备交接使用 Capture / Playback。格式转换使用独立的字节参照，混音和重采样使用独立的数值参照。测试按职责分组、每个场景独立注册到 CTest；共用准备和断言工具，不复制路由驱动逻辑。

===== CODING_GUIDELINES.md =====
# AEReborn 编程约束

## 1. 命名

**名称用能清楚表达用途的最短写法。** 缩写应当能从组合词或局部上下文直接读懂。需要查注释才能知道名称指什么时，用更明确的词。

| 场景 | 写法 |
| --- | --- |
| 连接 | 单独指一个连接时用 `connection`。组合词可用 `conn`，如 `conn_id`、`conn_count`。 |
| 端口 | 成对的类型使用等长的 `I` / `O` 方向前缀和相同的后缀，例如 `IPort` / `OPort`。 |
| 数据块 | 使用 `I` / `O` 表示方向，`B` / `F` 表示字节视图或浮点视图。字节块为 `IBBlock` / `OBBlock`，平面浮点块为 `IFBlock` / `OFBlock`。 |
| 声道 | 声道循环的索引用 `ch`。声明端口时用 `channels` 表示声道数，用 `input_channels`、`output_channels` 区分方向。 |
| 采样率 | 配置和公开接口用 `sample_rate`。重采样内部可以用常见的 DSP 记号 `src_fs`、`dst_fs`。 |
| 帧、采样点、字节 | 根据单位使用 `frames`、`samples`、`bytes`。含义可能混淆时，用 `frame_offset`、`byte_offset` 或 `period_ms` 写明单位。 |

- **成对的变量保持对称。** 用同一组方向词、相同的后缀和缩写程度，例如 `src_fs` / `dst_fs`、`input_channels` / `output_channels`、`from` / `to`。同一个值在相邻函数中沿用同一术语。
- **成对的类型和接口按长度和结构对齐。** 使用等长的区分词，其余词的位置、写法和后缀一致。例如 `NodeId` / `ConnId` 共用 `Id`，`byte_view()` / `f32p_view()` 共用 `_view`。
- **名称反映实际的访问方式或数据格式。** `byte_view()` 表示按字节访问，`f32p_view()` 明确适用的样本格式。
- **名字反映变量的用途。** `conn_count` 是数量，`conn_index` 是索引。短循环可以用 `i` 和 `ch`，跨多个步骤使用的变量写明角色，例如 `frame_offset`。
- **沿用项目的拼写风格。** 局部变量、参数和函数用 `snake_case`，私有成员变量在末尾加 `_`，如 `frame_position_`。类型和枚举值通常用 `PascalCase`，例如 `ConnId`、`ErrorCode::InvalidPort`。PCM 枚举沿用 `S16LE`、`S24_3LE`、`F32LE` 这样的格式名。

## 2. 类型与接口

- 优先复用现有类型。只有在需要表达独立的含义、约束、所有权或生命周期时才引入新类型。单纯的数量和索引使用现有整数类型。
- 一项规格只保留一个定义来源。采样率和 PCM 格式由 `core/types.h` 提供，样本位深和存储字节数从 `SampleFormat` 推导。端口固定声明采样率、声道数和格式，Engine 只持有推进周期。普通 DSP 插件声明 F32P，特殊模块声明其实际格式，转换由 Convert 完成。
- 函数名和参数顺序应能直接说明调用方向。底层函数、辅助记录和临时状态放在使用它们的实现范围内。对外接口集中表达调用方需要配置、传递或查询的内容。
- 类及其公开接口在声明处使用 `///` 格式的 Doxygen 注释。用 `@brief` 说明职责，按需用 `@param`、`@return`、`@pre` 和 `@note` 记录参数、结果、前置条件及调用约定。涉及借用数据或跨线程调用时，写明有效期和线程约束。
- 保持调用路径直接。抽取能消除重复、集中维护同一约束的逻辑，优先选用普通函数和直接的成员状态。模板用于确有编译期差异的场景，例如固定端口数量。采样率和处理周期作为运行时规格传递。

## 3. 错误处理

- 控制接口用 `aereborn::Error` 报告参数、状态、容量和设备操作失败。调用方用 `Error::code()` 识别失败原因。标准库的分配和线程创建异常，以及自定义节点的异常，直接传播给调用方。
- 后端驱动用 `RetCode` 或 `Result<T>` 报告设备状态。检查成功后再读 `value()`。在绑定和启动的控制边界使用 `or_throw()` 或 `value_or_throw()`，工作线程通过 `last_error()` 报告终止原因。`on_open()` 在控制侧运行，资源准备异常可以传播。
- 工作线程的 I/O 钩子以及实时渲染、DSP、后端停止和解绑使用 `noexcept`。I/O 报告设备错误，DSP 和队列返回处理结果，内部前置条件用断言表达。
- 在建立约束的入口做校验。连接时检查完整端口规格和输入占用，Matrix 构造时检查矩阵尺寸，绑定设备缓冲时检查长度与占用状态。处理路径直接使用已经校验和准备好的数据。
- 资源准备成功后再发布可用状态。失败时保留有效状态，使调用方可以重试。用资源所有权和作用域清理处理失败回滚。

## 4. 音频处理

- 每次时钟触发推进一个固定的引擎周期。节点按自身端口规格写满输出块，连接只读借用上游输出，每个输入只接一个来源。多路混音由 Mixer 完成；Matrix 的行对应输出声道，列对应输入声道。
- 普通 DSP 使用按声道存放的 IEEE float32，PCM 算法使用明确声明的字节格式。Convert 统一承担格式和采样率转换，Matrix 承担声道映射与增益，设备节点只交接数据。同采样率的 float32 保持样本的位表示，只做复制和必要的布局、字节序调整。
- 在 `prepare()` 中分配缓冲并准备滤波等资源。把阻塞 I/O、日志和堆分配放在渲染路径之外，并尽量避免在渲染时等待锁。接口借用缓冲时，应写清谁持有缓冲以及它需要保持有效的时间。

## 5. 修改与验证

- 以业务契约为准，测试负责验证契约。业务接口和分支应有明确的实际调用需求。
- 使用 C++14。修改集中在受影响的接口和实现，沿用周围代码的风格。注释优先说明约束和原因。
- 沿实际调用入口验证改动。优先复用现有测试，在现有测试覆盖不到具体回归时补充用例。音频转换和图处理的边界用实际帧数、声道数和输出值验证。
- 路由测试使用 Tone 或测试源，经 Convert、Mixer、Matrix 和测试收端验证显式图；设备交接使用 Capture / Playback。格式转换使用独立的字节参照，混音和重采样使用独立的数值参照。测试按职责分组、每个场景独立注册到 CTest；共用准备和断言工具，不复制路由驱动逻辑。

/// @brief Borrow a contiguous range of elements.
/// @tparam T Type of the elements, including their const qualification.
/// @note Keep the backing storage valid while the view is in use.
template <class T> class View
{
  public:
    /// @brief Construct an empty view with a null data pointer.
    View() noexcept = default;

    /// @brief Borrow a contiguous range.
    /// @param data Address of the range.
    /// @param size Number of elements in the range.
    /// @pre A nonempty range contains at least size valid elements.
    View(T *data, std::size_t size) noexcept : data_(data), size_(size)
    {
    }

    /// @brief Borrow the same range with a compatible element type.
    /// @param other Source view.
    template <class U, typename std::enable_if<std::is_convertible<U (*)[], T (*)[]>::value, int>::type = 0>
    View(View<U> other) noexcept : data_(other.data()), size_(other.size())
    {
    }

    /// @brief Return the stored address of the range.
    T *data() const noexcept
    {
        return data_;
    }

    /// @brief Return the number of elements.
    std::size_t size() const noexcept
    {
        return size_;
    }

    /// @brief Check whether the range is empty.
    bool empty() const noexcept
    {
        return size_ == 0;
    }

    /// @brief Return the start of the range.
    T *begin() const noexcept
    {
        return data_;
    }

    /// @brief Return the end of the range. For an empty range it equals begin().
    T *end() const noexcept
    {
        return size_ == 0 ? data_ : data_ + size_;
    }

    /// @brief Access an element by its zero-based index.
    /// @pre index is less than size().
    T &operator[](std::size_t index) const noexcept
    {
        assert(index < size_);
        return data_[index];
    }

  private:
    T *data_ = nullptr;
    std::size_t size_ = 0;
};

static_assert(sizeof(float) == 4 && std::numeric_limits<float>::is_iec559, "Audio samples require IEEE float32");

/// @brief Borrow a block of planar float samples.
/// @tparam T Use float for writable samples or const float for read-only samples.
/// @note The channel stride may exceed the number of frames in the view.
template <class T> class FloatBlock
{
    static_assert(std::is_same<typename std::remove_const<T>::type, float>::value, "Audio samples must be float");
    template <class> friend class FloatBlock;

  public:
    /// @brief Construct an empty float block.
    FloatBlock() noexcept = default;

    /// @brief Borrow planar samples with an explicit channel stride.
    /// @param data Address of the first channel.
    /// @param channels Number of channels.
    /// @param frames Number of frames in the processing span.
    /// @param channel_stride Distance between channel starts, in samples.
    /// @pre frames is at most channel_stride. The owner keeps the exposed samples valid.
    FloatBlock(T *data, std::size_t channels, std::size_t frames, std::size_t channel_stride) noexcept
        : data_(data), channels_(channels), frames_(frames), channel_stride_(channel_stride)
    {
        assert(frames <= channel_stride);
    }

    /// @brief Borrow the same samples with compatible access.
    /// @param other Source block.
    template <class U, typename std::enable_if<std::is_convertible<U *, T *>::value, int>::type = 0>
    FloatBlock(FloatBlock<U> other) noexcept
        : data_(other.data_), channels_(other.channels_), frames_(other.frames_), channel_stride_(other.channel_stride_)
    {
    }

    /// @brief Return a pointer to the start of a channel.
    /// @param ch Zero-based channel index.
    /// @pre ch is less than channels().
    T *channel(std::size_t ch) const noexcept
    {
        assert(ch < channels_);
        return data_ + ch * channel_stride_;
    }

    /// @brief Return the number of channels.
    std::size_t channels() const noexcept
    {
        return channels_;
    }

    /// @brief Return the number of frames in the processing span.
    std::size_t frames() const noexcept
    {
        return frames_;
    }

    /// @brief Check the view geometry. The caller owns the backing storage.
    bool valid() const noexcept
    {
        constexpr auto limit = std::numeric_limits<std::size_t>::max() / sizeof(float);
        return frames_ == 0 || (data_ && channels_ && frames_ <= channel_stride_ && frames_ <= limit &&
                               channels_ - 1 <= (limit - frames_) / channel_stride_);
    }

    /// @brief Borrow a frame range with the original channel stride.
    /// @pre The requested range lies in this block.
    FloatBlock subblock(std::size_t offset, std::size_t frames) const noexcept
    {
        assert(offset <= frames_ && frames <= frames_ - offset);
        return {data_ ? data_ + offset : nullptr, channels_, frames, channel_stride_};
    }

    /// @brief Zero the processing span of each channel in a writable block.
    template <class U = T, typename std::enable_if<!std::is_const<U>::value, int>::type = 0> void clear() const noexcept
    {
        if (!frames_)
            return;
        for (std::size_t ch = 0; ch < channels_; ++ch)
        {
            std::fill_n(channel(ch), frames_, 0.0f);
        }
    }

  private:
    T *data_ = nullptr;
    std::size_t channels_ = 0;
    std::size_t frames_ = 0;
    std::size_t channel_stride_ = 0;
};

using IFBlock = FloatBlock<const float>;
using OFBlock = FloatBlock<float>;

/// @brief Own a planar float workspace prepared for reuse during processing.
class Buffer
{
  public:
    /// @brief Set the workspace dimensions and zero its samples.
    /// @param channels Number of channels.
    /// @param capacity_frames Frame capacity per channel.
    /// @throws Error InvalidArg for a zero dimension, or TooLarge if storage would exceed its limit.
    /// @note Allocate in prepare(). Allocation failure propagates as an exception.
    void resize(std::size_t channels, std::size_t capacity_frames);

    /// @brief Borrow a writable block using the workspace capacity as the channel stride.
    /// @param frames Number of frames in the processing span.
    /// @pre frames fits the workspace capacity.
    /// @note Borrow a new block after a successful resize. Keep the backing storage alive while using a view.
    OFBlock block(std::size_t frames) noexcept;

    /// @brief Zero all samples in the workspace.
    void clear() noexcept;

  private:
    std::vector<float> samples_;
    std::size_t channels_ = 0;
    std::size_t capacity_frames_ = 0;
};

bool same_ports(View<const PortSpec> a, View<const PortSpec> b) noexcept
{
    return a.size() == b.size() && std::equal(a.begin(), a.end(), b.begin());
}
std::size_t pool_units_per_channel(SampleFormat format, std::size_t frames) noexcept
{
    return format == SampleFormat::F32P ? frames : frames * sample_bytes(format);
}

struct PoolSize
{
    const std::size_t limit;
    std::size_t outputs = 0;
    std::size_t silence = 0;
    std::size_t offset = 0;

    void count(PortSpec spec, BlockPeriod period, bool unconnected)
    {
        const auto units = pool_units_per_channel(spec.format, spec.max_frames(period));
        const auto available = unconnected ? limit - outputs : limit - outputs - silence;
        if (spec.channels > available / units)
            throw Error(ErrorCode::TooLarge);
        const auto size = spec.channels * units;
        if (unconnected)
            silence = std::max(silence, size);
        else
            outputs += size;
    }
};
struct PoolLayout
{
    PoolSize floats;
    PoolSize bytes;
    std::size_t input_count = 0;
    std::size_t output_count = 0;

    PoolSize &for_format(SampleFormat format) noexcept
    {
        return format == SampleFormat::F32P ? floats : bytes;
    }
};

class Engine::Graph
{
  public:
    NodeId add_node(std::unique_ptr<Node> instance)
    {
        if (!instance)
            throw Error(ErrorCode::InvalidArg);
        const auto inputs = instance->inputs();
        const auto outputs = instance->outputs();
        if (inputs.empty() && outputs.empty())
            throw Error(ErrorCode::InvalidArg);
        for (const auto ports : {inputs, outputs})
            for (const auto &port : ports)
                if (!port.valid())
                    throw Error(ErrorCode::InvalidArg);

        std::vector<OPort> links(inputs.size());
        const NodeId id{next_identifier()};
        auto entry = std::make_shared<NodeEntry>(id, std::move(instance), inputs, outputs);
        nodes_.emplace(id, DraftNode{std::move(entry), std::move(links)});
        dirty_ = true;
        return id;
    }

    void remove_node(NodeId id)
    {
        const auto found = find_node(id);
        for (auto it = connections_.begin(); it != connections_.end();)
            if (it->second.from.node == id || it->second.to.node == id)
                it = erase_connection(it);
            else
                ++it;
        dirty_ = true;
        nodes_.erase(found);
    }

    void replace_node(NodeId id, std::unique_ptr<Node> replacement)
    {
        const auto found = find_node(id);
        if (!replacement)
            throw Error(ErrorCode::InvalidArg);
        const auto inputs = replacement->inputs();
        const auto outputs = replacement->outputs();
        auto &current = found->second.entry;
        if (!same_ports(current->inputs, inputs) || !same_ports(current->outputs, outputs))
            throw Error(ErrorCode::FormatMismatch);
        auto entry = std::make_shared<NodeEntry>(id, std::move(replacement), inputs, outputs);
        dirty_ = true;
        current = std::move(entry);
    }

    void set_paused(NodeId id, bool paused)
    {
        const auto found = find_node(id);
        dirty_ |= found->second.paused != paused;
        found->second.paused = paused;
    }

    Node *node(NodeId id)
    {
        const auto found = find_node(id);
        return found->second.entry->node.get();
    }

    ConnId connect(OPort from, IPort to)
    {
        const auto &source = port_owner(from);
        auto &destination = port_owner(to);
        if (source.entry->outputs[from.index] != destination.entry->inputs[to.index])
            throw Error(ErrorCode::FormatMismatch);
        auto &input = destination.inputs[to.index];
        if (input.node)
            throw Error(input == from ? ErrorCode::DuplicateConn : ErrorCode::InputBusy);
        if (would_cycle(from.node, to.node))
            throw Error(ErrorCode::Cycle);
        const ConnId id{next_identifier()};
        connections_.emplace(id, ConnectionPorts{from, to});
        input = from;
        dirty_ = true;
        return id;
    }

    void disconnect(ConnId id)
    {
        const auto found = connections_.find(id);
        if (found == connections_.end())
            throw Error(ErrorCode::UnknownConn);
        erase_connection(found);
        dirty_ = true;
    }

    Topology resolve() const
    {
        Topology topology;
        NodeIndex node_index;
        for (const auto &item : nodes_)
            if (!item.second.paused && item.second.entry->outputs.empty())
                visit(item.second, topology, node_index);

        for (const auto &item : connections_)
        {
            const auto &connection = item.second;
            if (node_index.count(connection.from.node) && node_index.count(connection.to.node))
                topology.connections.push_back({item.first, connection.from, connection.to});
        }
        return topology;
    }

    bool owns(const NodeEntry &entry) const noexcept
    {
        const auto found = nodes_.find(entry.id);
        return found != nodes_.end() && found->second.entry.get() == &entry;
    }

    void reset_nodes() noexcept
    {
        for (const auto &item : nodes_)
            item.second.entry->node->reset();
    }

    bool dirty() const noexcept
    {
        return dirty_;
    }

    void mark_clean() noexcept
    {
        dirty_ = false;
    }

  private:
    struct DraftNode
    {
        std::shared_ptr<NodeEntry> entry;
        std::vector<OPort> inputs;
        bool paused = false;
    };
    struct ConnectionPorts
    {
        OPort from;
        IPort to;
    };
    using Nodes = std::map<NodeId, DraftNode>;
    using Connections = std::map<ConnId, ConnectionPorts>;
    using NodeIndex = std::map<NodeId, std::size_t>;
    Nodes::iterator find_node(NodeId id)
    {
        const auto found = nodes_.find(id);
        if (found == nodes_.end())
            throw Error(ErrorCode::UnknownNode);
        return found;
    }

    template <class Port> DraftNode &port_owner(Port port)
    {
        const auto found = find_node(port.node);
        const auto ports = found->second.entry->ports(port);
        if (port.index >= ports.size())
            throw Error(ErrorCode::InvalidPort);
        return found->second;
    }

    bool would_cycle(NodeId from, NodeId to) const
    {
        std::vector<NodeId> stack{from};
        std::set<NodeId> visited{from};
        while (!stack.empty())
        {
            const auto id = stack.back();
            stack.pop_back();
            if (id == to)
                return true;
            for (const auto input : nodes_.find(id)->second.inputs)
                if (input.node && visited.insert(input.node).second)
                    stack.push_back(input.node);
        }

        return false;
    }

    Connections::iterator erase_connection(Connections::iterator connection) noexcept
    {
        const auto to = connection->second.to;
        nodes_.find(to.node)->second.inputs[to.index] = {};
        return connections_.erase(connection);
    }

    void visit(const DraftNode &draft, Topology &topology, NodeIndex &node_index) const
    {
        if (node_index.count(draft.entry->id))
            return;

        for (const auto input : draft.inputs)
            if (input.node)
            {
                const auto &source = nodes_.find(input.node)->second;
                if (!source.paused)
                    visit(source, topology, node_index);
            }

        node_index.emplace(draft.entry->id, topology.nodes.size());
        topology.nodes.push_back(draft.entry);

        // An absent source is unconnected or was excluded by pause.
        for (const auto input : draft.inputs)
        {
            const auto source = input.node ? node_index.find(input.node) : node_index.end();
            topology.links.push_back(source == node_index.end() ? Link{} : Link{source->second, input.index});
        }
    }

    Nodes nodes_;
    Connections connections_;
    bool dirty_ = true;
};

class Engine::Clock
{
  public:
    ~Clock()
    {
        stop();
    }

    /// @brief Publish a plan under the clock mutex and wait for takeover.
    /// @tparam Plan Type of the render plan exchanged with the clock.
    /// @param submitted Slot that the clock clears after taking the plan.
    /// @param plan New plan. The caller keeps ownership throughout the wait.
    /// @pre The clock is running and the control side is the sole submitter.
    template <class Plan> void submit_and_wait(std::atomic<Plan *> &submitted, Plan *plan)
    {
        std::unique_lock<std::mutex> lock(mutex_);
        submitted.store(plan, std::memory_order_release);
        applied_.wait(lock, [&submitted]() noexcept { return submitted.load(std::memory_order_acquire) == nullptr; });
    }

    /// @brief Launch the worker that drives the engine's ticks.
    /// @param engine Engine to drive, kept alive until the worker joins.
    void start(Engine &engine)
    {
        stopping_ = false;
        const auto interval = std::chrono::milliseconds(static_cast<std::uint32_t>(engine.period_));
        const auto first_deadline = std::chrono::steady_clock::now() + interval;
        thread_ = std::thread([this, &engine, interval, deadline = first_deadline]() mutable {
            clock_engine = &engine;
            std::unique_lock<std::mutex> lock(mutex_);
            while (!changed_.wait_until(lock, deadline, [this] { return stopping_; }))
            {
                lock.unlock();
                const auto started = std::chrono::steady_clock::now();
                const bool swapped = engine.tick();
                lock.lock();
                if (swapped)
                    applied_.notify_one();
                const auto finished = std::chrono::steady_clock::now();
                const auto elapsed = std::chrono::duration_cast<std::chrono::microseconds>(finished - started);
                engine.last_tick_us_.store(elapsed.count(), std::memory_order_relaxed);
                deadline += interval;
                if (finished >= deadline)
                {
                    const auto missed = (finished - deadline) / interval + 1;
                    engine.missed_periods_.fetch_add(missed, std::memory_order_relaxed);
                    deadline += interval * missed;
                }
            }
        });
    }

    void stop() noexcept
    {
        if (!thread_.joinable())
            return;
        {
            const std::lock_guard<std::mutex> lock(mutex_);
            stopping_ = true;
        }
        changed_.notify_one();
        thread_.join();
    }

  private:
    std::mutex mutex_;
    std::condition_variable changed_;
    std::condition_variable applied_;
    bool stopping_ = false;
    std::thread thread_;
};

class Engine::Runner
{
  public:
    void commit(Topology topology, BlockPeriod period, Clock *live_clock)
    {
        auto plan = std::make_unique<Plan>();
        for (const auto &entry : topology.nodes)
            if (!entry->prepared)
            {
                entry->node->prepare(period);
                entry->prepared = true;
            }

        PoolLayout layout{{plan->float_pool.max_size()}, {plan->byte_pool.max_size()}};
        measure_layout(*plan, topology, period, layout);
        bind_blocks(*plan, topology, period, layout);

        plan->node_ids.reserve(topology.nodes.size());
        for (const auto &entry : topology.nodes)
            plan->node_ids.push_back(entry->id);
        plan->connections = std::move(topology.connections);
        plan->owners = std::move(topology.nodes);
        if (live_clock)
            live_clock->submit_and_wait(submitted_, plan.get());
        else
            rendering_ = plan.get();
        current_ = std::move(plan);
    }

    View<const NodeId> nodes() const noexcept
    {
        if (!current_)
            return {};
        return {current_->node_ids.data(), current_->node_ids.size()};
    }

    View<const Connection> connections() const noexcept
    {
        if (!current_)
            return {};
        return {current_->connections.data(), current_->connections.size()};
    }

    const Node *node(NodeId id) const
    {
        if (current_)
            for (const auto &entry : current_->owners)
                if (entry->id == id)
                    return entry->node.get();
        throw Error(ErrorCode::UnknownNode);
    }

    /// @brief Reset nodes held by the current plan after removal or replacement in the draft.
    /// @param draft Graph whose node instances are reset separately.
    /// @pre The clock is stopped.
    void reset(const Graph &draft) noexcept
    {
        if (!current_)
            return;
        for (const auto &entry : current_->owners)
            if (!draft.owns(*entry))
                entry->node->reset();
    }

    bool render(BlockPeriod period, std::uint64_t tick) noexcept
    {
        const auto plan = submitted_.load(std::memory_order_acquire);
        if (plan)
        {
            rendering_ = plan;
            // The control side may now retire the previous plan.
            submitted_.store(nullptr, std::memory_order_release);
        }

        rendering_->render(period, tick);
        return plan != nullptr;
    }

  private:
    struct Step
    {
        Node *node;
        std::size_t first_input;
        std::size_t input_count;
        std::size_t first_output;
        std::size_t output_count;
    };
    struct Plan
    {
        OBBlock block(PortSpec spec, std::size_t frames, std::size_t offset) noexcept
        {
            auto *data = spec.format == SampleFormat::F32P
                             ? reinterpret_cast<std::uint8_t *>(float_pool.data() + offset)
                             : byte_pool.data() + offset;
            return {data, spec, frames};
        }

        void render(BlockPeriod period, std::uint64_t tick) noexcept
        {
            if (has_fractional_ports)
            {
                const auto refresh_frames = [period, tick](auto &block) noexcept {
                    const auto spec = block.spec();
                    block = {block.byte_view().data(), spec, spec.frames(period, tick)};
                };
                for (auto &input : inputs)
                    refresh_frames(input);
                for (auto &output : outputs)
                    refresh_frames(output);
            }

            // Leave slot zero inactive for all inputs without a source.
            std::fill(output_active.begin() + 1, output_active.end(), std::uint8_t{1});
            for (const auto &step : steps)
            {
                for (std::size_t i = step.first_input; i < step.first_input + step.input_count; ++i)
                    input_active[i] = output_active[input_sources[i]];

                step.node->process({period, tick, port_range(inputs.data(), step.first_input, step.input_count),
                                    port_range(outputs.data(), step.first_output, step.output_count),
                                    port_range(input_active.data(), step.first_input, step.input_count),
                                    port_range(output_active.data() + 1, step.first_output, step.output_count)});
            }
        }

        bool has_fractional_ports = false;
        // The zero-filled prefix of each pool is shared by unconnected inputs.
        std::vector<float> float_pool;
        std::vector<std::uint8_t> byte_pool;
        std::vector<IBBlock> inputs;
        std::vector<OBBlock> outputs;
        std::vector<std::uint8_t> input_active;
        std::vector<std::uint8_t> output_active; // Slot zero is shared by inputs without a source.
        std::vector<std::size_t> input_sources;
        std::vector<Step> steps;
        std::vector<std::shared_ptr<NodeEntry>> owners;
        std::vector<NodeId> node_ids;
        std::vector<Connection> connections;
    };

    /// @brief Measure buffer capacity and record each node's port offsets.
    /// @param plan Plan receiving the execution steps and fractional-frame flag.
    /// @param topology Node order and input links used by those steps.
    /// @param period Block duration used to size each port at its maximum frame count.
    /// @param layout Pool limits and accumulated port and storage counts.
    /// @throws Error TooLarge if a step or port table or buffer pool would exceed capacity.
    static void measure_layout(Plan &plan, const Topology &topology, BlockPeriod period, PoolLayout &layout)
    {
        const auto period_ms = static_cast<std::uint32_t>(period);
        const auto fractional = [period_ms](PortSpec spec) {
            return (static_cast<std::uint32_t>(spec.sample_rate) * period_ms) % 1000 != 0;
        };
        if (topology.nodes.size() > plan.steps.max_size())
            throw Error(ErrorCode::TooLarge);
        const auto max_inputs = std::min({plan.inputs.max_size(), plan.input_active.max_size(),
                                          plan.input_sources.max_size()});
        const auto max_outputs = std::min(plan.outputs.max_size(), plan.output_active.max_size() - 1);
        plan.steps.reserve(topology.nodes.size());
        for (const auto &entry : topology.nodes)
        {
            const auto inputs = entry->inputs;
            const auto outputs = entry->outputs;
            if (inputs.size() > max_inputs - layout.input_count || outputs.size() > max_outputs - layout.output_count)
                throw Error(ErrorCode::TooLarge);
            plan.steps.push_back(
                {entry->node.get(), layout.input_count, inputs.size(), layout.output_count, outputs.size()});

            for (const auto spec : outputs)
            {
                layout.for_format(spec.format).count(spec, period, false);
                plan.has_fractional_ports |= fractional(spec);
            }
            for (std::size_t port = 0; port < inputs.size(); ++port)
            {
                if (topology.links[layout.input_count + port].node_index != Link::unconnected)
                    continue;
                const auto spec = inputs[port];
                layout.for_format(spec.format).count(spec, period, true);
                plan.has_fractional_ports |= fractional(spec);
            }
            layout.input_count += inputs.size();
            layout.output_count += outputs.size();
        }
    }

    /// @brief Allocate buffers and bind their input and output views.
    /// @param plan Plan owning the buffers and measured execution steps.
    /// @param topology Input links and port specifications in execution order.
    /// @param period Block duration used to size each bound block.
    /// @param layout Measured capacity and pool offsets advanced during binding.
    /// @pre measure_layout() succeeded for the same plan, topology, and period.
    static void bind_blocks(Plan &plan, const Topology &topology, BlockPeriod period, PoolLayout &layout)
    {
        plan.inputs.resize(layout.input_count);
        plan.outputs.resize(layout.output_count);
        plan.input_active.resize(layout.input_count);
        plan.output_active.resize(layout.output_count + 1);
        plan.input_sources.resize(layout.input_count);
        plan.float_pool.resize(layout.floats.silence + layout.floats.outputs);
        plan.byte_pool.resize(layout.bytes.silence + layout.bytes.outputs);
        layout.floats.offset = layout.floats.silence;
        layout.bytes.offset = layout.bytes.silence;
        // Outputs are bound upstream first. Connected inputs copy the corresponding read-only view.
        for (std::size_t node_index = 0; node_index < topology.nodes.size(); ++node_index)
        {
            const auto &entry = *topology.nodes[node_index];
            const auto &step = plan.steps[node_index];
            for (std::size_t port = 0; port < step.output_count; ++port)
            {
                const auto spec = entry.outputs[port];
                const auto frames = spec.max_frames(period);
                auto &pool = layout.for_format(spec.format);
                plan.outputs[step.first_output + port] = plan.block(spec, frames, pool.offset);
                pool.offset += spec.channels * pool_units_per_channel(spec.format, frames);
            }
            for (std::size_t port = 0; port < step.input_count; ++port)
            {
                const auto input_index = step.first_input + port;
                const auto link = topology.links[input_index];
                if (link.node_index != Link::unconnected)
                {
                    const auto source = plan.steps[link.node_index].first_output + link.port_index;
                    plan.inputs[input_index] = plan.outputs[source];
                    plan.input_sources[input_index] = source + 1;
                }
                else
                {
                    const auto spec = entry.inputs[port];
                    plan.inputs[input_index] = plan.block(spec, spec.max_frames(period), 0);
                }
            }
        }
    }

    std::unique_ptr<Plan> current_;
    std::atomic<Plan *> submitted_{nullptr};
    // Only the clock thread accesses this while running.
    Plan *rendering_ = nullptr;
};

Engine::Engine(BlockPeriod period)
    : period_(checked_period(period)), graph_(std::make_unique<Graph>()), runner_(std::make_unique<Runner>()),
      clock_(std::make_unique<Clock>())
{
}

// The clock is destroyed first and joins before the runner or graph is destroyed.
Engine::~Engine() = default;

void Engine::require_control_thread() const
{
    if (clock_engine == this)
        throw Error(ErrorCode::Busy);
}

bool Engine::tick() noexcept
{
    const auto tick = position_.load(std::memory_order_relaxed);
    const bool swapped = runner_->render(period_, tick);
    position_.store(tick + 1, std::memory_order_release);
    return swapped;
}

    require_control_thread();
    return insert_node(std::move(instance));
}

    graph_->remove_node(id);

    require_control_thread();
    graph_->replace_node(id, std::move(replacement));

{
    require_control_thread();
    graph_->set_paused(id, paused);
}

{
    require_control_thread();
    return graph_->node(id);
}

ConnId Engine::connect(OPort from, IPort to)
{
    require_control_thread();
    return graph_->connect(from, to);
}

void Engine::disconnect(ConnId id)
{
    require_control_thread();
    graph_->disconnect(id);
}

void Engine::commit()
{
    require_control_thread();
    if (!graph_->dirty())
        return;

    runner_->commit(graph_->resolve(), period_, state_ == State::Running ? clock_.get() : nullptr);
    ++plan_generation_;
    graph_->mark_clean();
    if (state_ == State::Unprepared)
        state_ = State::Ready;
}

void Engine::start()
{
    require_control_thread();
    if (state_ == State::Running)
        throw Error(ErrorCode::Busy);
    if (state_ == State::Unprepared)
        throw Error(ErrorCode::NotReady);
    clock_->start(*this);
    state_ = State::Running;
}

void Engine::stop()
{
    require_control_thread();
    if (state_ == State::Running)
    {
        clock_->stop();
        state_ = State::Ready;
    }
}

void Engine::reset()
{
    require_control_thread();
    if (state_ == State::Running)
        throw Error(ErrorCode::Busy);
    runner_->reset(*graph_);
    graph_->reset_nodes();
    position_.store(0, std::memory_order_release);
    missed_periods_.store(0, std::memory_order_relaxed);
    last_tick_us_.store(0, std::memory_order_relaxed);
}

Engine::State Engine::state() const
{
    require_control_thread();
    return state_;
}

bool Engine::dirty() const
{
    require_control_thread();
    return graph_->dirty();
}

{
    require_control_thread();
    return plan_generation_;
}

View<const NodeId> Engine::plan_nodes() const
{
    require_control_thread();
    return runner_->nodes();
}

View<const Connection> Engine::plan_connections() const
{
    require_control_thread();
    return runner_->connections();
}

const Node *Engine::plan_node(NodeId node_id) const
{
    require_control_thread();
    return runner_->node(node_id);
}

{
    return position_.load(std::memory_order_acquire);
}

#ifndef AEREBORN_CORE_ENGINE_H

/// @brief Owns an audio graph and advances it on an internal software clock.
/// @note Serialize control calls, including node lookup, and destruction on the control side.
/// Control calls from this engine's clock thread throw Error with code Busy.
/// Node callbacks must defer control requests and return without waiting for them.
/// block_period() and tick_position() may run concurrently while the Engine is alive.
class Engine
{
  public:
    /// @brief Lifecycle state, as observed on the control side.
    enum class State
    {
        Unprepared,
        Ready,
        Running
    };

    /// @brief Construct an engine with an empty draft graph.
    /// @param block_period Fixed duration of each tick.
    /// @throws Error InvalidArg if the period is unsupported.
    explicit Engine(BlockPeriod block_period);

    /// @brief Stop the clock and release all plans and nodes.
    ~Engine();

    Engine(const Engine &) = delete;
    Engine &operator=(const Engine &) = delete;

    /// @brief Add a node to the draft graph.
    /// @param instance Node to transfer to the engine. The call consumes it on success or failure.
    /// @return The new node ID.
    /// @throws Error InvalidArg for a null node or invalid port layout.
    NodeId add_node(std::unique_ptr<Node> instance);

    /// @brief Construct a node and add it to the draft graph.
    /// @tparam T Concrete node type derived from Node.
    /// @tparam Args Constructor argument types.
    /// @param args Arguments forwarded to the node constructor.
    /// @return The new node ID.
    /// @throws Error As documented for add_node().
    template <class T, class... Args> NodeId emplace_node(Args &&...args)
    {
        require_control_thread();
        return insert_node(std::make_unique<T>(std::forward<Args>(args)...));
    }

    /// @brief Remove a node and its connections from the draft graph.
    /// @param node_id ID of the node to remove.
    /// @throws Error UnknownNode if the draft has no such node.
    void remove_node(NodeId node_id);

    /// @brief Replace a draft node while preserving its ID and connections.
    /// @param node_id ID of the node to replace.
    /// @param replacement New instance with identical port specifications in the same order.
    /// The call consumes it on success or failure.
    /// @throws Error UnknownNode for an absent node, InvalidArg for a null replacement,
    /// or FormatMismatch for a different port layout.
    void replace_node(NodeId node_id, std::unique_ptr<Node> replacement);

    /// @brief Stage a local pause or resume for the next submitted plan.
    /// @param node_id ID of the node to pause or resume.
    /// @param paused True to exclude the node from the next plan, false to make it eligible again.
    /// @throws Error UnknownNode if the draft has no such node.
    void set_paused(NodeId node_id, bool paused);

    /// @brief Look up a node in the draft graph.
    /// @param node_id ID of the node to look up.
    /// @return A borrowed node pointer.
    /// @throws Error UnknownNode if the draft has no such node.
    /// @note The pointer is valid until removal, replacement, or Engine destruction.
    /// Follow the node's own contract for concurrent access during rendering.
    Node *node(NodeId node_id);

    /// @brief Look up a draft node as a requested type.
    /// @tparam T Node type to cast the result to.
    /// @param node_id ID of the node to look up.
    /// @return A borrowed pointer.
    /// @throws Error UnknownNode if the draft has no such node, or InvalidType if the cast fails.
    /// @note The pointer follows the same lifetime and access rules as node(NodeId).
    template <class T> T *node(NodeId node_id)
    {
        auto *typed_node = dynamic_cast<T *>(node(node_id));
        if (!typed_node)
            throw Error(ErrorCode::InvalidType);
        return typed_node;
    }

    /// @brief Connect an output to an input in the draft graph.
    /// @param from Source output port.
    /// @param to Destination input port, which can have only one source.
    /// @return The new connection ID.
    /// @throws Error If graph validation fails.
    /// @note Port specifications must match, and the connection must leave the graph acyclic.
    ConnId connect(OPort from, IPort to);

    /// @brief Remove a connection from the draft graph.
    /// @param conn_id ID returned by connect().
    /// @throws Error UnknownConn if the connection is absent.
    void disconnect(ConnId conn_id);

    /// @brief Prepare the draft and make it the current render plan.
    /// @note Skips an unchanged draft. Validation or preparation failure leaves the current plan in place.
    /// @note While running, wait for block-boundary takeover and release the previous
    /// plan on the calling thread.
    void commit();

    /// @brief Start the software clock with the current plan and tick position.
    /// @throws Error NotReady before the first successful commit, or Busy if already running.
    /// @note Thread creation exceptions propagate and leave the engine ready to retry.
    void start();

    /// @brief Stop the clock and wait for any in-flight block.
    /// @throws Error Busy if called from this engine's clock thread.
    void stop();

    /// @brief Reset nodes and the tick position while stopped.
    /// @throws Error Busy while running.
    /// @note Resets each node instance held by the draft or current plan once and sets the next tick to zero.
    void reset();

    /// @brief Query the fixed block period.
    /// @return The duration supplied to the constructor.
    BlockPeriod block_period() const noexcept
    {
        return period_;
    }

    /// @brief Query the current tick position.
    /// @return The zero-based position of the next tick, advanced after each completed block.
    std::uint64_t tick_position() const noexcept;

    /// @brief Return the current lifecycle state on the serialized control side.
    State state() const;

    /// @brief Report whether the draft needs a commit, including its initial preparation.
    bool dirty() const;

    /// @brief Count published render plans. Failed and unchanged commits leave this unchanged.
    std::uint64_t plan_generation() const;

    /// @brief Count software-clock periods skipped since construction or reset.
    /// @note May be read concurrently with rendering.
    std::uint64_t missed_periods() const noexcept { return missed_periods_.load(std::memory_order_relaxed); }

    /// @brief Estimate the most recent tick time in microseconds, including clock bookkeeping.
    /// @note May be read concurrently with rendering. Zero until sampled after construction or reset.
    std::uint64_t last_tick_us() const noexcept { return last_tick_us_.load(std::memory_order_relaxed); }

    /// @brief Borrow committed node IDs in execution order, or an empty view before commit.
    /// @note Use on the serialized control side until the next plan publication or destruction.
    View<const NodeId> plan_nodes() const;

    /// @brief Borrow committed connections, with the same lifetime as plan_nodes().
    View<const Connection> plan_connections() const;

    /// @brief Borrow a committed node instance, with the same lifetime as plan_nodes().
    /// @throws Error UnknownNode if the node is outside the current plan.
    /// @note Follow the node's own contract for access during rendering.
    const Node *plan_node(NodeId node_id) const;

  private:
    class Graph;
    class Runner;
    class Clock;
    void require_control_thread() const;
    NodeId insert_node(std::unique_ptr<Node> instance);
    bool tick() noexcept;

    const BlockPeriod period_;
    State state_ = State::Unprepared;
    std::atomic<std::uint64_t> position_{0};
    std::uint64_t plan_generation_ = 0;
    std::atomic<std::uint64_t> missed_periods_{0};
    std::atomic<std::uint64_t> last_tick_us_{0};
    std::unique_ptr<Graph> graph_;
    std::unique_ptr<Runner> runner_;
    std::unique_ptr<Clock> clock_;
};

} // namespace aereborn

/// @brief SPSC storage for planar float frames.
/// @note Call write() from one producer and read() from one consumer.
/// @note Prepare and clear with both sides stopped. Query fill from either owning side.
class FrameRing
{
  public:
    /// @brief Allocate storage and clear the queue on success.
    void prepare(std::size_t channels, std::size_t capacity)
    {
        // Buffer's float storage limit also bounds the cursor arithmetic below.
        storage_.resize(channels, capacity);
        capacity_ = capacity;
        clear();
    }

    void clear() noexcept
    {
        read_.store(0, std::memory_order_relaxed);
        write_.store(0, std::memory_order_relaxed);
    }

    std::size_t capacity() const noexcept { return capacity_; }

    std::size_t available() const noexcept
    {
        const auto read = read_.load(std::memory_order_acquire);
        return queued(write_.load(std::memory_order_acquire), read);
    }

    /// @brief Sample queue occupancy from outside the producer and consumer.
    /// @return False if the independently sampled cursors yield an out-of-range result.
    /// @pre Serialize with prepare().
    bool estimate(std::size_t &frames) const noexcept
    {
        frames = available();
        return frames <= capacity_;
    }

    /// @pre The ring is prepared and the input matches its layout.
    std::size_t write(IFBlock input) noexcept
    {
        assert(capacity_ && input.valid() && input.channels() == storage_.block(0).channels());
        const auto write = write_.load(std::memory_order_relaxed);
        const auto frames = std::min(input.frames(), capacity_ - queued(write, read_.load(std::memory_order_acquire)));
        if (frames)
        {
            copy(input, storage_.block(capacity_), write, frames, true);
            write_.store(advance(write, frames), std::memory_order_release);
        }
        return frames;
    }

    /// @pre The ring is prepared and the output matches its layout.
    std::size_t read(OFBlock output) noexcept
    {
        assert(capacity_ && output.valid() && output.channels() == storage_.block(0).channels());
        const auto read = read_.load(std::memory_order_relaxed);
        const auto frames = std::min(output.frames(), queued(write_.load(std::memory_order_acquire), read));
        if (frames)
        {
            copy(storage_.block(capacity_), output, read, frames, false);
            read_.store(advance(read, frames), std::memory_order_release);
        }
        return frames;
    }

  private:
    void copy(IFBlock input, OFBlock output, std::size_t cursor, std::size_t frames, bool writing) noexcept
    {
        // Cursors wrap at twice the capacity.
        const auto offset = cursor < capacity_ ? cursor : cursor - capacity_;
        const auto first = std::min(frames, capacity_ - offset);
        const auto second = frames - first;
        const auto src_first = writing ? std::size_t{0} : offset;
        const auto dst_first = writing ? offset : std::size_t{0};
        const auto src_second = writing ? first : std::size_t{0};
        const auto dst_second = writing ? std::size_t{0} : first;
        for (std::size_t ch = 0; ch < input.channels(); ++ch)
        {
            const auto *src = input.channel(ch);
            auto *dst = output.channel(ch);
            std::memcpy(dst + dst_first, src + src_first, first * sizeof(float));
            if (second)
                std::memcpy(dst + dst_second, src + src_second, second * sizeof(float));
        }
    }

    std::size_t queued(std::size_t write, std::size_t read) const noexcept
    {
        return write >= read ? write - read : 2 * capacity_ + write - read;
    }

    std::size_t advance(std::size_t cursor, std::size_t frames) const noexcept
    {
        const auto next = cursor + frames;
        return next < 2 * capacity_ ? next : next - 2 * capacity_;
    }

    Buffer storage_;
    std::size_t capacity_ = 0;
    std::atomic<std::size_t> read_{0};
    std::atomic<std::size_t> write_{0};
};

/// @brief Graph execution unit with immutable input and output port layouts.
///
/// Keep the port descriptors and their storage valid and unchanged for as long as

class Node
{
  public:
    virtual ~Node() = default;
    Node(const Node &) = delete;
    Node &operator=(const Node &) = delete;

    /// @brief Return a static diagnostic type name. May be called during processing.
    virtual const char *type_name() const noexcept { return "Node"; }

    /// @brief Describe the input ports.
    /// @return A read-only view of the input port specifications in port index order.
    virtual View<const PortSpec> inputs() const noexcept = 0;

    /// @brief Describe the output ports.
    /// @return A read-only view of the output port specifications in port index order.
    virtual View<const PortSpec> outputs() const noexcept = 0;

    /// @brief Prepare the node's processing resources on the control thread.
    /// @param period Block period validated by the engine.
    /// @throws Error If preparation fails.
    /// @note The default implementation succeeds without preparing any resources.
    /// @note The engine may retry after a failure.

    virtual void process(const ProcessContext &context) noexcept = 0;

    /// @pre Reset must be serialized with processing.
    /// @note The engine may reset a node before its first preparation.

    }

template <std::size_t Bytes> std::uint32_t read_le(const std::uint8_t *input) noexcept
{
    std::uint32_t raw = 0;
    for (std::size_t i = 0; i < Bytes; ++i)
    {
        raw |= static_cast<std::uint32_t>(input[i]) << (8 * i);
    }
    return raw;
}

template <std::size_t Bytes> void write_le(std::uint32_t raw, std::uint8_t *output) noexcept
{
    for (std::size_t i = 0; i < Bytes; ++i)
    {
        output[i] = static_cast<std::uint8_t>(raw >> (8 * i));
    }
}

template <unsigned int Bits> float decode_integer(std::uint32_t raw) noexcept
{
    constexpr auto scale = std::int64_t{1} << (Bits - 1);
    const auto value = std::int64_t{raw} & (2 * scale - 1);
    return static_cast<float>(value >= scale ? value - 2 * scale : value) / static_cast<float>(scale);
}

template <unsigned int Bits> std::uint32_t encode_integer(float sample) noexcept
{
    constexpr auto scale = std::int64_t{1} << (Bits - 1);
    const auto normalized = std::isnan(sample) ? 0.0f : std::max(-1.0f, std::min(1.0f, sample));
    const auto rounded = static_cast<std::int64_t>(std::round(static_cast<double>(normalized) * scale));
    const auto value = std::min(scale - 1, rounded);
    return static_cast<std::uint32_t>(value) & static_cast<std::uint32_t>(2 * scale - 1);
}

bool native_f32le() noexcept
{
    const float one = 1.0f;
    constexpr std::uint8_t one_le[] = {0, 0, 0x80, 0x3f};
    return std::memcmp(&one, one_le, sizeof(one)) == 0;
}

void decode_f32le(const std::uint8_t *pcm, OFBlock output) noexcept
{
    if (output.frames() == 0)
        return;
    if (output.channels() == 1 && native_f32le())
    {
        std::memcpy(output.channel(0), pcm, output.frames() * sizeof(float));
        return;
    }
    for (std::size_t frame = 0; frame < output.frames(); ++frame)
    {
        for (std::size_t ch = 0; ch < output.channels(); ++ch, pcm += sizeof(float))
        {
            const auto raw = read_le<sizeof(float)>(pcm);
            std::memcpy(output.channel(ch) + frame, &raw, sizeof(raw));
        }
    }
}

void encode_f32le(IFBlock input, std::uint8_t *pcm) noexcept
{
    if (input.frames() == 0)
        return;
    if (input.channels() == 1 && native_f32le())
    {
        std::memcpy(pcm, input.channel(0), input.frames() * sizeof(float));
        return;
    }
    for (std::size_t frame = 0; frame < input.frames(); ++frame)
    {
        for (std::size_t ch = 0; ch < input.channels(); ++ch, pcm += sizeof(float))
        {
            std::uint32_t raw;
            std::memcpy(&raw, input.channel(ch) + frame, sizeof(raw));
            write_le<sizeof(raw)>(raw, pcm);
        }
    }
}

template <SampleFormat Format> void decode_pcm(const std::uint8_t *source, OFBlock output) noexcept
{
    constexpr auto width = sample_bytes(Format);
    constexpr auto bits = sample_bits(Format);
    for (std::size_t frame = 0; frame < output.frames(); ++frame)
        for (std::size_t ch = 0; ch < output.channels(); ++ch, source += width)
            output.channel(ch)[frame] = decode_integer<bits>(read_le<width>(source));
}

template <SampleFormat Format> void encode_pcm(IFBlock input, std::uint8_t *destination) noexcept
{
    constexpr auto width = sample_bytes(Format);
    constexpr auto bits = sample_bits(Format);
    for (std::size_t frame = 0; frame < input.frames(); ++frame)
        for (std::size_t ch = 0; ch < input.channels(); ++ch, destination += width)
            write_le<width>(encode_integer<bits>(input.channel(ch)[frame]), destination);
}

constexpr std::size_t order = 48;
constexpr std::size_t taps = 2 * order;
constexpr std::uint32_t phase_steps = 100;
constexpr unsigned fraction_bits = 32;
constexpr auto phase_unit = std::uint64_t{1} << fraction_bits;
constexpr double pi = 3.141592653589793;

std::uint64_t step_units(double step) noexcept
{
    return static_cast<std::uint64_t>(step * phase_unit + 0.5);
}

// Window and cutoff ported from AudioDriver's SincInterpolator.
double sinc_kernel(double x, double cutoff) noexcept
{
    if (std::abs(x) >= order)
    {
        return 0.0;
    }
    const auto angle = (2.0 * pi * (x + 1.0 - order)) / (taps - 1);
    const auto window =
        0.3635819 - 0.4891775 * std::cos(angle) + 0.1365995 * std::cos(2 * angle) - 0.0106411 * std::cos(3 * angle);
    const auto sinc_angle = pi * cutoff * x;
    const auto sinc = sinc_angle == 0 ? 1.0 : std::sin(sinc_angle) / sinc_angle;
    return sinc * window;
}

using Coefficients = std::array<float, taps>;

void calc_coffs(const float *kernel, std::size_t phase_index, float phase_frac, Coefficients &coffs) noexcept
{
    const auto *lo_coffs = kernel + phase_index * taps;
    const auto *hi_coffs = lo_coffs + taps;
    for (std::size_t i = 0; i < taps; ++i)
    {
        coffs[i] = lo_coffs[i] + (hi_coffs[i] - lo_coffs[i]) * phase_frac;
    }
}

float interpolate(const float *history, const float *input, std::size_t history_taps,
                  const Coefficients &coffs) noexcept
{
    float sum0 = 0.0f, sum1 = 0.0f, sum2 = 0.0f, sum3 = 0.0f;
    std::size_t i = 0;
    for (; i + 4 <= history_taps; i += 4)
    {
        sum0 += history[i] * coffs[i];
        sum1 += history[i + 1] * coffs[i + 1];
        sum2 += history[i + 2] * coffs[i + 2];
        sum3 += history[i + 3] * coffs[i + 3];
    }
    for (; i < history_taps; ++i)
        sum0 += history[i] * coffs[i];

    const auto input_taps = taps - history_taps;
    const auto *input_coffs = coffs.data() + history_taps;
    i = 0;
    for (; i + 4 <= input_taps; i += 4)
    {
        sum0 += input[i] * input_coffs[i];
        sum1 += input[i + 1] * input_coffs[i + 1];
        sum2 += input[i + 2] * input_coffs[i + 2];
        sum3 += input[i + 3] * input_coffs[i + 3];
    }
    for (; i < input_taps; ++i)
        sum0 += input[i] * input_coffs[i];
    return (sum0 + sum1) + (sum2 + sum3);
}

void prepare_filter(Buffer &history, std::vector<float> &kernel, std::size_t channels, double cutoff)
{
    history.resize(channels, taps);
    kernel.resize((phase_steps + 1) * taps);
    for (std::uint32_t phase = 0; phase <= phase_steps; ++phase)
    {
        auto *coffs = kernel.data() + phase * taps;
        const auto fraction = static_cast<double>(phase) / phase_steps;
        double scale = 0;
        for (std::size_t i = 0; i < taps; ++i)
        {
            coffs[i] = static_cast<float>(sinc_kernel(fraction + order - 1 - i, cutoff));
            scale += coffs[i];
        }
        for (std::size_t i = 0; i < taps; ++i)
            coffs[i] = static_cast<float>(coffs[i] / scale);
    }
}

void filter_frame(OFBlock past, const std::vector<float> &kernel, IFBlock input, OFBlock output, std::size_t out_frame,
                  std::size_t through, std::size_t phase_index, float phase_fraction) noexcept
{
    const auto input_taps = std::min(through, taps);
    const auto input_offset = through - input_taps;
    Coefficients coffs;
    calc_coffs(kernel.data(), phase_index, phase_fraction, coffs);
    for (std::size_t ch = 0; ch < output.channels(); ++ch)
    {
        const auto *history = past.channel(ch) + input_taps;
        const auto *samples = through ? input.channel(ch) + input_offset : nullptr;
        output.channel(ch)[out_frame] = interpolate(history, samples, taps - input_taps, coffs);
    }
}

void remember(Buffer &history, IFBlock input, std::size_t consumed) noexcept
{
    if (!consumed)
        return;
    const auto past = history.block(taps);
    const auto copy_frames = std::min(consumed, taps);
    const auto keep_frames = taps - copy_frames;
    for (std::size_t ch = 0; ch < past.channels(); ++ch)
    {
        auto *history_samples = past.channel(ch);
        std::memmove(history_samples, history_samples + copy_frames, keep_frames * sizeof(float));
        std::copy_n(input.channel(ch) + consumed - copy_frames, copy_frames, history_samples + keep_frames);
    }
}

using DecodeFn = void (*)(const std::uint8_t *, OFBlock);
using EncodeFn = void (*)(IFBlock, std::uint8_t *);

std::pair<DecodeFn, EncodeFn> codec_for(SampleFormat format) noexcept
{
    switch (format)
    {
    case SampleFormat::S16LE:
        return {decode_pcm<SampleFormat::S16LE>, encode_pcm<SampleFormat::S16LE>};
    case SampleFormat::S24_3LE:
        return {decode_pcm<SampleFormat::S24_3LE>, encode_pcm<SampleFormat::S24_3LE>};
    case SampleFormat::S24LE:
        return {decode_pcm<SampleFormat::S24LE>, encode_pcm<SampleFormat::S24LE>};
    case SampleFormat::S32LE:
        return {decode_pcm<SampleFormat::S32LE>, encode_pcm<SampleFormat::S32LE>};
    case SampleFormat::F32LE:
        return {decode_f32le, encode_f32le};
    case SampleFormat::F32P:
        break;
    }
    return {nullptr, nullptr};
}

constexpr auto frame_limit = std::numeric_limits<std::size_t>::max() / 16;

bool valid_offset(double offset) noexcept
{
    return offset >= 0.0 && offset < 0.5;
}

bool needs_filter(SampleRate src_fs, SampleRate dst_fs, double offset) noexcept
{
    return src_fs != dst_fs || offset > 0;
}

double nominal_step(SampleRate src_fs, SampleRate dst_fs) noexcept
{
    return static_cast<double>(static_cast<std::uint32_t>(src_fs)) / static_cast<std::uint32_t>(dst_fs);
}

std::size_t workspace_bound(SampleRate src_fs, SampleRate dst_fs, std::size_t frames, double offset, bool bound_input)
{
    if (!is_sample_rate(src_fs) || !is_sample_rate(dst_fs) || !valid_offset(offset))
        throw Error(ErrorCode::InvalidArg);
    if (frames > frame_limit)
        throw Error(ErrorCode::TooLarge);
    if (!frames || !needs_filter(src_fs, dst_fs, offset))
        return frames;

    const auto nominal = nominal_step(src_fs, dst_fs);
    const auto step = nominal * (bound_input ? 1 + offset : 1 - offset);
    const auto fixed = static_cast<long double>(step_units(step)) / phase_unit;
    // Cover both the nominal rate envelope and the actual quantized stream step.
    const auto edge = bound_input ? std::max<long double>(step, fixed) : std::min<long double>(step, fixed);
    const auto ratio = bound_input ? edge : 1 / edge;
    // After a capped upsampling call the next output may use the last source frame in history.
    const auto history = bound_input ? 0.0L : std::max(0.0L, 1 - edge);
    const auto count = static_cast<long double>(frames) + history;
    auto scaled = count * ratio;
    // For exceptionally large bounds, round outward even when long double has double precision.
    const auto precision_limit = std::ldexp(1.0L, std::numeric_limits<long double>::digits - 3);
    if (count >= precision_limit || scaled >= precision_limit)
    {
        const auto infinity = std::numeric_limits<long double>::infinity();
        scaled = std::nextafter(std::nextafter(count, infinity) * std::nextafter(ratio, infinity), infinity);
    }
    const auto rounded = std::ceil(scaled);
    if (rounded >= static_cast<long double>(frame_limit))
        throw Error(ErrorCode::TooLarge);
    return static_cast<std::size_t>(rounded) + 1;
}
} // namespace

void decode_pcm(IBBlock input, OFBlock output) noexcept
{
    const auto codec = codec_for(input.spec().format).first;
    assert(codec && input.spec().channels == output.channels() && input.frames() == output.frames());
    codec(input.byte_view().data(), output);
}

void encode_pcm(IFBlock input, OBBlock output) noexcept
{
    const auto codec = codec_for(output.spec().format).second;
    assert(codec && output.spec().channels == input.channels() && output.frames() == input.frames());
    codec(input, output.byte_view().data());
}

void SincResampler::Position::advance(std::uint64_t step, std::uint64_t unit) noexcept
{
    const auto next = fraction + step;
    through += static_cast<std::size_t>(next / unit);
    fraction = next % unit;
}

void SincResampler::prepare(std::size_t channels, SampleRate src_fs, SampleRate dst_fs, double offset)
{
    if (!channels || !is_sample_rate(src_fs) || !is_sample_rate(dst_fs) || !valid_offset(offset))
        throw Error(ErrorCode::InvalidArg);

    Buffer history;
    std::vector<float> kernel;
    const auto fir = needs_filter(src_fs, dst_fs, offset);
    const auto nominal = nominal_step(src_fs, dst_fs);
    if (fir)
    {
        const auto cutoff =
            static_cast<double>(static_cast<std::uint32_t>(dst_fs)) / static_cast<std::uint32_t>(src_fs) / (1 + offset);
        prepare_filter(history, kernel, channels, std::min(1.0, cutoff) * 0.98);
    }
    history_ = std::move(history);
    kernel_ = std::move(kernel);
    need_fir_ = fir;
    channels_ = channels;
    src_fs_ = src_fs;
    dst_fs_ = dst_fs;
    nominal_ = nominal;
    max_rate_offset_ = offset;
    position_ = {};
}

std::size_t SincResampler::tail_frames() const noexcept
{
    return need_fir_ ? taps : 0;
}

void SincResampler::reset() noexcept
{
    position_ = {};
    history_.clear();
}

void SincResampler::process_tick(IFBlock input, OFBlock output, BlockPeriod period, std::uint64_t tick) noexcept
{
    assert(channels_ && max_rate_offset_ == 0 && input.channels() == channels_ && output.channels() == channels_);
    const auto src_fs = static_cast<std::uint32_t>(src_fs_);
    const auto dst_fs = static_cast<std::uint32_t>(dst_fs_);
    const auto rounding = [period, tick](std::uint32_t rate) {
        const auto rem = (tick % 1000) * ((std::uint64_t{rate} * static_cast<std::uint32_t>(period)) % 1000) % 1000;
        return static_cast<std::int64_t>((1000 - rem) % 1000);
    };
    const auto phase = (rounding(dst_fs) * src_fs - rounding(src_fs) * dst_fs) / 1000;
    const auto start = static_cast<std::uint64_t>(dst_fs + phase);
    Position position{static_cast<std::size_t>(start / dst_fs), start % dst_fs};
    const auto result = run(input, output, position, src_fs, dst_fs, true);
    assert(result.produced == output.frames());
    (void)result;
}

std::size_t SincResampler::required_input(std::size_t frames, double scale) const noexcept
{
    assert(channels_ && scale >= 1 - max_rate_offset_ && scale <= 1 + max_rate_offset_);
    assert(frames <= frame_limit);
    if (!frames || !need_fir_)
        return frames;

    const auto step = step_units(nominal_ * scale);
    const auto whole = step >> fraction_bits;
    const auto count = static_cast<std::uint64_t>(frames - 1);
    assert(!whole || count <= frame_limit / whole);
    const auto frac = std::uint64_t{static_cast<std::uint32_t>(step)};
    const auto low = position_.fraction + frac * static_cast<std::uint32_t>(count);
    const auto needed = position_.through + count * whole + (count >> fraction_bits) * frac + (low >> fraction_bits);
    assert(needed <= frame_limit);
    return static_cast<std::size_t>(needed);
}

SincResampler::Transfer SincResampler::process(IFBlock input, OFBlock output, double scale) noexcept
{
    assert(channels_ && scale >= 1 - max_rate_offset_ && scale <= 1 + max_rate_offset_);
    assert(input.channels() == channels_ && output.channels() == channels_);
    assert(input.frames() <= frame_limit && output.frames() <= frame_limit);
    assert(input.valid() && output.valid());
    return run(input, output, position_, step_units(nominal_ * scale), phase_unit, false);
}

SincResampler::Transfer SincResampler::run(IFBlock input, OFBlock output, Position &phase, std::uint64_t step,
                                           std::uint64_t unit, bool tick) noexcept
{
    if (!need_fir_)
    {
        const auto frames = std::min(input.frames(), output.frames());
        if (frames)
            for (std::size_t ch = 0; ch < channels_; ++ch)
                std::memcpy(output.channel(ch), input.channel(ch), frames * sizeof(float));
        return {frames, frames};
    }
    if (!output.frames() && !tick)
        return {};

    const auto past = history_.block(taps);
    Transfer result;
    std::size_t last = 0;
    while (result.produced < output.frames() && phase.through <= input.frames())
    {
        last = phase.through;
        const auto phase_pos = phase.fraction * phase_steps;
        const auto index = static_cast<std::size_t>(phase_pos / unit);
        const auto blend = static_cast<float>(phase_pos % unit) / static_cast<float>(unit);
        filter_frame(past, kernel_, input, output, result.produced, last, index, blend);
        ++result.produced;
        phase.advance(step, unit);
    }

    // The graph supplies a new block every tick. A stream keeps unconsumed input with the caller.
    result.consumed = input.frames();
    if (!tick)
    {
        const auto skipped = phase.through ? phase.through - 1 : 0;
        result.consumed = std::min(input.frames(), std::max(last, skipped));
        phase.through -= result.consumed;
    }
    remember(history_, input, result.consumed);
    return result;
}

std::size_t SincResampler::max_output_frames(SampleRate src_fs, SampleRate dst_fs, std::size_t frames, double offset)
{
    return workspace_bound(src_fs, dst_fs, frames, offset, false);
}

std::size_t SincResampler::max_input_frames(SampleRate src_fs, SampleRate dst_fs, std::size_t frames, double offset)
{
    return workspace_bound(src_fs, dst_fs, frames, offset, true);
}

    }

    {
        switch (code_)
        {
        case ErrorCode::Ok:
            return "Success";
        case ErrorCode::InvalidArg:
            return "Invalid argument";
        case ErrorCode::InvalidPort:
            return "Port index is out of range";
        case ErrorCode::InvalidType:

        case ErrorCode::NotReady:
            return "Object is not prepared, committed, or bound";

            return "The current execution context or state prevents this operation";
        case ErrorCode::UnknownNode:
            return "Node does not belong to this engine or was removed";
        case ErrorCode::UnknownConn:
            return "Connection does not exist";
        case ErrorCode::DuplicateConn:
            return "These ports are already connected";
        case ErrorCode::InputBusy:

            return "Formats or port layouts do not match";
        case ErrorCode::IoFailed:
            return "I/O operation failed";

            return "Audio device is no longer available";
        case ErrorCode::EndOfStream:
            return "End of stream";
        case ErrorCode::Cancelled:
            return "I/O operation was cancelled";
        case ErrorCode::Timeout:
            return "I/O operation timed out";
        }
        return "Unknown error code";
    }

    /// @brief Throw Error if this code represents a failure.
    void or_throw() const;

  private:
    ErrorCode code_;
};

  public:
    explicit Error(ErrorCode code) : std::runtime_error(RetCode(code).message()), code_(code) {}
    Error(ErrorCode code, const char *detail) : std::runtime_error(detail), code_(code) {}
    Error(ErrorCode code, const std::string &detail) : std::runtime_error(detail), code_(code) {}

    ErrorCode code() const noexcept { return code_; }

  private:
    ErrorCode code_;
};

inline void RetCode::or_throw() const
{
    if (!*this)
        throw Error(code_);
}

/// @brief Status or value for backend operations. Check the status before reading the value.
template <class T> class Result
{
  public:
    Result(T value) noexcept(std::is_nothrow_move_constructible<T>::value) : value_(std::move(value))
    {
    }
    Result(RetCode code) noexcept(std::is_nothrow_default_constructible<T>::value) : ret_code_(code)
    {
        assert(!code);
    }
    Result(ErrorCode code) noexcept(std::is_nothrow_default_constructible<T>::value) : Result(RetCode(code))
    {
    }
    RetCode ret_code() const noexcept
    {
        return ret_code_;
    }
    explicit operator bool() const noexcept
    {
        return static_cast<bool>(ret_code_);
    }
    T &value() & noexcept
    {
        assert(ret_code_);
        return value_;
    }
    const T &value() const & noexcept
    {
        assert(ret_code_);
        return value_;
    }
    T value() && noexcept(std::is_nothrow_move_constructible<T>::value)
    {
        assert(ret_code_);
        return std::move(value_);
    }

    /// @brief Move out the result or throw Error on failure.
    T value_or_throw() &&
    {
        ret_code_.or_throw();
        return std::move(value_);
    }

  private:
    RetCode ret_code_;
    T value_{};
};

/// @brief Run a non-throwing cleanup when leaving scope unless dismissed.

{
  public:
    explicit ScopeExit(Cleanup cleanup) noexcept(std::is_nothrow_move_constructible<Cleanup>::value)
        : cleanup_(std::move(cleanup))
    {
    }
    ScopeExit(const ScopeExit &) = delete;
    ScopeExit &operator=(const ScopeExit &) = delete;

    ~ScopeExit()
    {
        if (active_)
            cleanup_();
    }

    void dismiss() noexcept { active_ = false; }

  private:
    Cleanup cleanup_;
    bool active_ = true;
};

void Buffer::resize(std::size_t channels, std::size_t capacity_frames)
{
    if (channels == 0 || capacity_frames == 0)
        throw Error(ErrorCode::InvalidArg);
    if (channels > samples_.max_size() / capacity_frames)
        throw Error(ErrorCode::TooLarge);
    const auto sample_count = channels * capacity_frames;
    const auto retained_samples = std::min(samples_.size(), sample_count);
    samples_.resize(sample_count);
    std::fill_n(samples_.begin(), retained_samples, 0.0f);
    channels_ = channels;
    capacity_frames_ = capacity_frames;
}

OFBlock Buffer::block(std::size_t frames) noexcept
{
    return {samples_.data(), channels_, frames, capacity_frames_};
}

void Buffer::clear() noexcept
{
    std::fill(samples_.begin(), samples_.end(), 0.0f);
}

std::size_t PortSpec::max_frames(BlockPeriod period) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    return static_cast<std::size_t>((units + 999) / 1000);
}

std::size_t PortSpec::frames(BlockPeriod period, std::uint64_t tick) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    const auto fraction = units % 1000;
    if (fraction == 0)
        return static_cast<std::size_t>(units / 1000);
    const auto start = (tick % 1000) * fraction;
    return static_cast<std::size_t>(units / 1000 + (start + fraction + 999) / 1000 - (start + 999) / 1000);
}

std::uint64_t PortSpec::frame_position(BlockPeriod period, std::uint64_t tick) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    // Split whole seconds from the remainder to avoid multiplying tick by the sample rate.
    return (tick / 1000) * units + ((tick % 1000) * units + 999) / 1000;
}

/// @brief Sample storage format, including channel layout and byte order.
///
/// F32P stores native planar float32. All other formats store interleaved
/// little-endian PCM.
enum class SampleFormat
{
    F32P,
    S16LE,
    S24_3LE, ///< Signed 24-bit PCM packed into three bytes per sample.
    S24LE,   ///< Signed 24-bit PCM stored in a four-byte slot per sample.
    S32LE,
    F32LE
};

constexpr bool is_sample_rate(SampleRate sample_rate) noexcept
{
    switch (sample_rate)
    {
    case SampleRate::Hz8000:
    case SampleRate::Hz11025:
    case SampleRate::Hz16000:
    case SampleRate::Hz22050:
    case SampleRate::Hz24000:
    case SampleRate::Hz32000:
    case SampleRate::Hz44100:
    case SampleRate::Hz48000:
    case SampleRate::Hz88200:
    case SampleRate::Hz96000:
        return true;
    }
    return false;
}
constexpr bool is_block_period(BlockPeriod period) noexcept
{
    return period == BlockPeriod::Ms02 || period == BlockPeriod::Ms05 || period == BlockPeriod::Ms10 ||
           period == BlockPeriod::Ms20 || period == BlockPeriod::Ms40;
}
constexpr unsigned int sample_bits(SampleFormat format) noexcept
{
    switch (format)
    {
    case SampleFormat::S16LE:
        return 16;
    case SampleFormat::S24_3LE:
    case SampleFormat::S24LE:
        return 24;
    case SampleFormat::F32P:
    case SampleFormat::S32LE:
    case SampleFormat::F32LE:
        return 32;
    }
    return 0;
}
constexpr std::size_t sample_bytes(SampleFormat format) noexcept
{
    return format == SampleFormat::S24LE ? 4 : sample_bits(format) / 8;
}

/// @brief Fixed sample rate, channel count, and format declared by a port.
///
/// Connections require all three fields to match. Each frame contains one sample
/// per channel.
struct PortSpec
{
    /// @brief Construct an empty placeholder with no valid rate or channel count.
    constexpr PortSpec() noexcept = default;

    /// @brief Specify the sample layout of one port.
    /// @param sample_rate Port sample rate in hertz.
    /// @param channels Number of channels per frame.
    /// @param format Sample representation and layout.
    constexpr PortSpec(SampleRate sample_rate, std::size_t channels, SampleFormat format) noexcept
        : channels(channels), sample_rate(sample_rate), format(format)
    {
    }
    constexpr bool valid() const noexcept
    {
        return is_sample_rate(sample_rate) && channels > 0 && sample_bytes(format) != 0;
    }
    constexpr bool operator==(const PortSpec &other) const noexcept
    {
        return sample_rate == other.sample_rate && channels == other.channels && format == other.format;
    }
    constexpr bool operator!=(const PortSpec &other) const noexcept
    {
        return !(*this == other);
    }

    /// @brief Return the maximum frame count in one block for buffer sizing.
    /// @param period Duration of the engine tick.

    /// @brief Return the actual frame count for a tick.
    /// @param period Duration of the engine tick.
    /// @param tick Zero-based tick position.
    /// @note The count is the difference between two consecutive frame positions.
    std::size_t frames(BlockPeriod period, std::uint64_t tick) const noexcept;

    /// @brief Return the zero-based frame position at the start of a tick.
    /// @param period Duration of the engine tick.
    /// @param tick Zero-based tick position.

    std::uint64_t frame_position(BlockPeriod period, std::uint64_t tick) const noexcept;

    std::size_t channels = 0;
    SampleRate sample_rate{};
    SampleFormat format{};

/// @brief Borrow audio through a byte view carrying the port specification and frame count.
/// @tparam Byte Use std::uint8_t for writable bytes or const std::uint8_t for read-only bytes.
/// @note The port specification determines how to interpret the samples.
///
/// The render plan owns the storage provided to a node. Use its views only for the
/// duration of the process call.
template <class Byte> class ByteBlock
{
    template <class> friend class ByteBlock;
    using Float = typename std::conditional<std::is_const<Byte>::value, const float, float>::type;

  public:
    ByteBlock() noexcept = default;

    /// @brief Interpret a borrowed buffer according to the port specification.
    /// @param data Address of the buffer.
    /// @param spec Sample rate, channel count, and format of the buffer.
    /// @param frames Number of frames available in the buffer for this block.
    /// @pre A nonempty block refers to storage large enough for the specified frames.
    ByteBlock(Byte *data, PortSpec spec, std::size_t frames) noexcept : data_(data), spec_(spec), frames_(frames)
    {
    }
    template <class OtherByte, typename std::enable_if<std::is_convertible<OtherByte *, Byte *>::value, int>::type = 0>
    ByteBlock(ByteBlock<OtherByte> other) noexcept : data_(other.data_), spec_(other.spec_), frames_(other.frames_)
    {
    }
    PortSpec spec() const noexcept
    {
        return spec_;
    }
    std::size_t frames() const noexcept
    {
        return frames_;
    }
    View<Byte> byte_view() const noexcept
    {
        return {data_, frames_ * spec_.channels * sample_bytes(spec_.format)};
    }
    FloatBlock<Float> f32p_view() const noexcept
    {
        assert(spec_.format == SampleFormat::F32P);
        return {reinterpret_cast<Float *>(data_), spec_.channels, frames_, frames_};
    }
  private:
    Byte *data_ = nullptr;
    PortSpec spec_;
    std::size_t frames_ = 0;
};

    : NodeT({input}, {output}), same_spec_(input == output)

void Convert::prepare(BlockPeriod period)
{
    if (!is_block_period(period))
        throw Error(ErrorCode::InvalidArg);
    if (same_spec_)
        return;
    const auto input = inputs()[0], output = outputs()[0];
    const auto in_pcm = is_interleaved_pcm(input.format), out_pcm = is_interleaved_pcm(output.format);
    const auto fir = input.sample_rate != output.sample_rate;
    Buffer decoded, resampled;
    if (in_pcm && (fir || out_pcm))
        decoded.resize(input.channels, input.max_frames(period));
    if (fir)
    {
        if (out_pcm)
            resampled.resize(output.channels, output.max_frames(period));
        resampler_.prepare(input.channels, input.sample_rate, output.sample_rate);
    }
    decoded_ = std::move(decoded);
    resampled_ = std::move(resampled);
    tail_remaining_ = 0;
}

void Convert::process(const ProcessContext &context) noexcept
{
    const auto input = context.inputs[0];
    const auto output = context.outputs[0];
    const bool active = context.has_input(0);
    if (!active && tail_remaining_ == 0)
    {
        context.set_output_active(0, false);
        const auto bytes = output.byte_view();
        if (!bytes.empty())
            std::memset(bytes.data(), 0, bytes.size());
        return;
    }
    context.set_output_active(0, true);

    if (same_spec_)
    {
        // The byte copy preserves float bit patterns and PCM padding.
        const auto bytes = input.byte_view();
        if (!bytes.empty())
            std::memcpy(output.byte_view().data(), bytes.data(), bytes.size());
        return;
    }

    const auto in_pcm = is_interleaved_pcm(input.spec().format);
    const auto out_pcm = is_interleaved_pcm(output.spec().format);
    const auto fir = resampler_.needs_fir();
    IFBlock source;
    if (in_pcm)
    {
        const auto decoded = fir || out_pcm ? decoded_.block(input.frames()) : output.f32p_view();
        decode_pcm(input, decoded);
        source = decoded;
    }
    else
        source = input.f32p_view();

    if (fir)
    {
        // The block that finishes the flush may still contain tail samples.
        tail_remaining_ =
            active ? resampler_.tail_frames() : tail_remaining_ - std::min(tail_remaining_, input.frames());
        const auto dest = out_pcm ? resampled_.block(output.frames()) : output.f32p_view();
        resampler_.process_tick(source, dest, context.block_period, context.tick_position);
        source = dest;
    }
    if (out_pcm)
        encode_pcm(source, output);
}

void Convert::reset() noexcept
{
    resampler_.reset();
    tail_remaining_ = 0;
}

constexpr unsigned graph_open = 1u;
constexpr unsigned graph_active = 2u;

PortSpec endpoint_spec(SampleRate rate, std::size_t channels, std::chrono::microseconds io_period)
{
    const PortSpec spec(rate, channels, SampleFormat::F32P);
    if (!spec.valid() || io_period.count() <= 0)
        throw Error(ErrorCode::InvalidArg, "Invalid endpoint port or I/O period");
    return spec;
}

void prepare_ring(FrameRing &ring, PortSpec spec, BlockPeriod period, std::chrono::microseconds io_period,
                  BlockPeriod &prepared_period, bool in_use)
{
    if (!is_block_period(period))
        throw Error(ErrorCode::InvalidArg);
    if (period == prepared_period)
        return;
    if (in_use)
        throw Error(ErrorCode::Busy);
    const auto graph_frames = spec.max_frames(period);
    const auto rate = static_cast<std::uint32_t>(spec.sample_rate);
    const auto us = static_cast<std::uint64_t>(io_period.count());
    if (us > std::numeric_limits<std::uint64_t>::max() / rate)
        throw Error(ErrorCode::TooLarge);
    // Round up at the slowest allowed device clock to cover the largest logical batch.
    constexpr auto effective_second = 1000000 - max_clock_drift_ppm;
    const auto units = us * rate;
    const auto device_frames = units / effective_second + (units % effective_second != 0);
    const auto capacity = std::max<std::uint64_t>(8 * graph_frames, 2 * device_frames + 4 * graph_frames);
    if (capacity > std::numeric_limits<std::size_t>::max())
        throw Error(ErrorCode::TooLarge);
    ring.prepare(spec.channels, static_cast<std::size_t>(capacity));
    prepared_period = period;
}

bool enter_graph(std::atomic<unsigned> &state) noexcept
{
    auto expected = graph_open;
    return state.compare_exchange_strong(expected, graph_open | graph_active, std::memory_order_acquire,
                                         std::memory_order_relaxed);
}

void close_graph_gate(std::atomic<unsigned> &state) noexcept
{
    state.fetch_and(~graph_open, std::memory_order_acq_rel);
    // Only the caller outside the graph waits, until the current queue access ends.
    while (state.load(std::memory_order_acquire) & graph_active)
    {
    }
}

void open_graph_gate(std::atomic<unsigned> &state, std::atomic<bool> &primed, bool prefill) noexcept
{
    primed.store(!prefill, std::memory_order_relaxed);
    state.store(graph_open, std::memory_order_release);
}

bool prefill_ready(const FrameRing &ring, std::atomic<bool> &primed, std::size_t target_frames) noexcept
{
    if (primed.load(std::memory_order_relaxed))
        return true;
    if (ring.available() < target_frames)
        return false;
    primed.store(true, std::memory_order_release);
    return true;
}
} // namespace

Capture::Capture(SampleRate rate, std::size_t channels, std::chrono::microseconds io_period)
    : NodeT({}, {endpoint_spec(rate, channels, io_period)}), io_period_(io_period)
{
}

void Capture::prepare(BlockPeriod period)
{
    prepare_ring(ring_, spec(), period, io_period_, period_, bound());
}

void Capture::process(const ProcessContext &context) noexcept
{
    const auto output = context.outputs[0].f32p_view();
    std::size_t frames = 0;
    if (enter_graph(graph_state_))
    {
        if (prefill_ready(ring_, primed_, target_frames()))
        {
            frames = ring_.read(output);
            if (frames < output.frames())
                underrun_frames_.fetch_add(output.frames() - frames, std::memory_order_relaxed);
        }
        graph_state_.fetch_and(~graph_active, std::memory_order_release);
    }
    output.subblock(frames, output.frames() - frames).clear();
    context.set_output_active(0, frames != 0);
}

bool Capture::online() const noexcept
{
    return (graph_state_.load(std::memory_order_acquire) & graph_open) != 0;
}

void Capture::open(bool prefill) noexcept
{
    underrun_frames_.store(0, std::memory_order_relaxed);
    open_graph_gate(graph_state_, primed_, prefill);
}

void Capture::close() noexcept
{
    close_graph_gate(graph_state_);
    ring_.clear();
    primed_.store(false, std::memory_order_release);
}

Playback::Playback(SampleRate rate, std::size_t channels, std::chrono::microseconds io_period)
    : NodeT({endpoint_spec(rate, channels, io_period)}, {}), io_period_(io_period)
{
}

void Playback::prepare(BlockPeriod period)
{
    prepare_ring(ring_, spec(), period, io_period_, period_, bound());
}

void Playback::process(const ProcessContext &context) noexcept
{
    if (enter_graph(graph_state_))
    {
        const auto input = context.inputs[0].f32p_view();
        const auto written = ring_.write(input);
        if (written < input.frames())
            overflow_frames_.fetch_add(input.frames() - written, std::memory_order_relaxed);
        graph_state_.fetch_and(~graph_active, std::memory_order_release);
    }
}

bool Playback::online() const noexcept
{
    return (graph_state_.load(std::memory_order_acquire) & graph_open) != 0;
}

void Playback::open(bool prefill) noexcept
{
    overflow_frames_.store(0, std::memory_order_relaxed);
    open_graph_gate(graph_state_, primed_, prefill);
}

void Playback::close_graph() noexcept

    close_graph_gate(graph_state_);
}

    close_graph();
    ring_.clear();
    primed_.store(false, std::memory_order_release);
}

template <bool Accumulate> void write_scaled(float &dst, const float &src, float gain) noexcept
{
    if (Accumulate)
        dst += src * gain;
    else
        dst = src * gain;
}

template <bool Accumulate> void apply_steady_gain(float *dst, const float *src, std::size_t frames, float gain) noexcept
{
    if (Accumulate && gain == 0)
        return;
    for (std::size_t frame = 0; frame < frames; ++frame)
        write_scaled<Accumulate>(dst[frame], src[frame], gain);
}

template <bool Accumulate> void write_ramp_sample(float &dst, const float &src, float gain) noexcept
{
    if (gain != 0)
        write_scaled<Accumulate>(dst, src, gain);
    else if (!Accumulate)
        dst = 0.0f;
}

template <bool Accumulate>
void apply_ramping_gain(float *dst, const float *src, std::size_t frames, float coefficient, float start, float target,
                        double scale) noexcept
{
    const auto last = frames - 1;
    const auto begin = static_cast<double>(start);
    const auto end = static_cast<double>(target);
    for (std::size_t frame = 0; frame < last; ++frame)
    {
        // Scale after adding the weighted endpoints so exact crossings stay zero with fused multiply-add.
        const auto gain = static_cast<float>((begin * (last - frame) + end * (frame + 1)) * scale);
        write_ramp_sample<Accumulate>(dst[frame], src[frame], Accumulate ? coefficient * gain : gain);
    }
    write_ramp_sample<Accumulate>(dst[last], src[last], Accumulate ? coefficient * target : target);
}
} // namespace

Matrix::Matrix(SampleRate rate, std::size_t channels, float gain)
    : NodeT({PortSpec(rate, channels, SampleFormat::F32P)}, {PortSpec(rate, channels, SampleFormat::F32P)}),
      target_(gain), gain_(gain)
{
    if (!inputs()[0].valid() || !std::isfinite(gain))
        throw Error(ErrorCode::InvalidArg, "Invalid matrix specification");
}
Matrix::Matrix(SampleRate rate, std::size_t input_channels, std::size_t output_channels, View<const float> coefficients,
               float gain)
    : NodeT({PortSpec(rate, input_channels, SampleFormat::F32P)},
            {PortSpec(rate, output_channels, SampleFormat::F32P)}),
      target_(gain), gain_(gain)
{
    if (!inputs()[0].valid() || !outputs()[0].valid() || !std::isfinite(gain))
        throw Error(ErrorCode::InvalidArg, "Invalid matrix specification");
    if (output_channels > coefficients_.max_size() / input_channels)
        throw Error(ErrorCode::TooLarge, "Channel matrix exceeds supported size");
    if (coefficients.size() != input_channels * output_channels)
        throw Error(ErrorCode::InvalidArg, "Channel matrix dimensions do not match coefficients");
    for (const auto value : coefficients)
        if (!std::isfinite(value))
            throw Error(ErrorCode::InvalidArg, "Matrix coefficients must be finite");
    coefficients_.assign(coefficients.begin(), coefficients.end());
}
Matrix::Matrix(SampleRate rate, std::size_t input_channels, std::size_t output_channels,
               std::initializer_list<float> coefficients, float gain)
    : Matrix(rate, input_channels, output_channels, {coefficients.begin(), coefficients.size()}, gain)
{
}
void Matrix::set_gain(float gain)
{
    if (!std::isfinite(gain))
        throw Error(ErrorCode::InvalidArg);
    target_.store(gain, std::memory_order_release);
}
float Matrix::gain() const noexcept
{
    return target_.load(std::memory_order_acquire);
}
void Matrix::prepare(BlockPeriod)
{
    reset();
}
void Matrix::reset() noexcept
{
    gain_ = target_.load(std::memory_order_acquire);
}
void Matrix::process(const ProcessContext &context) noexcept
{
    const auto &output_block = context.outputs[0];
    const auto output = output_block.f32p_view();
    const auto frames = output.frames();
    if (frames == 0)
        return;
    const auto target = target_.load(std::memory_order_acquire);
    const bool steady = gain_ == target;
    const bool active = context.has_input(0) && !(steady && target == 0.0f);
    context.set_output_active(0, active);
    if (!active)
    {
        output.clear();
        gain_ = target;
        return;
    }
    const auto &input_block = context.inputs[0];
    const auto input = input_block.f32p_view();
    const auto scale = steady ? 0.0 : 1.0 / frames;
    if (coefficients_.empty())
    {
        if (steady && target == 1.0f)
        {
            const auto bytes = input_block.byte_view();
            std::memcpy(output_block.byte_view().data(), bytes.data(), bytes.size());
            return;
        }
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
        {
            auto *dst = output.channel(ch);
            const auto *src = input.channel(ch);
            if (steady)
                apply_steady_gain<false>(dst, src, frames, target);
            else
                apply_ramping_gain<false>(dst, src, frames, 1.0f, gain_, target, scale);
        }
    }
    else
    {
        output.clear();
        const auto input_channels = input.channels();
        for (std::size_t dst_ch = 0; dst_ch < output.channels(); ++dst_ch)
        {
            auto *dst = output.channel(dst_ch);
            const auto *row = coefficients_.data() + dst_ch * input_channels;
            for (std::size_t src_ch = 0; src_ch < input_channels; ++src_ch)
            {
                const auto coefficient = row[src_ch];
                if (coefficient == 0)
                    continue;
                const auto *src = input.channel(src_ch);
                if (steady)
                    apply_steady_gain<true>(dst, src, frames, coefficient * target);
                else
                    apply_ramping_gain<true>(dst, src, frames, coefficient, gain_, target, scale);
            }
        }
    }
    gain_ = target;
}

    /// @param input_channels Number of columns.
    /// @param output_channels Number of rows.
    /// @param coefficients Finite coefficients in output-channel order, one row per output.
    /// @param gain Initial finite linear gain.

    /// @throws Error InvalidArg For invalid port specs, mismatched dimensions, or nonfinite coefficients or gain.

    Matrix(SampleRate rate, std::size_t input_channels, std::size_t output_channels,

        throw Error(ErrorCode::InvalidPort);

void Mixer::process(const ProcessContext &context) noexcept
{
    const auto output = context.outputs[0].f32p_view();
    const auto frames = output.frames();
    if (frames == 0)
        return;
    output.clear();
    bool active = false;
    for (std::size_t i = 0; i < inputs_.size(); ++i)
    {
        if (muted_[i].load(std::memory_order_acquire) || !context.has_input(i))
            continue;
        active = true;
        const auto input = context.inputs[i].f32p_view();
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
        {
            auto *dst = output.channel(ch);
            const auto *src = input.channel(ch);
            for (std::size_t frame = 0; frame < frames; ++frame)
                dst[frame] += src[frame];
        }
    }
    context.set_output_active(0, active);
}

Result<PortSpec> AlsaBackend::configure_pcm(snd_pcm_t *handle, bool mmap, PortSpec logical,
                                            std::chrono::microseconds duration) noexcept
{
    const auto access = mmap ? SND_PCM_ACCESS_MMAP_INTERLEAVED : SND_PCM_ACCESS_RW_INTERLEAVED;
    snd_pcm_hw_params_t *hw;
    snd_pcm_hw_params_alloca(&hw);
    if (snd_pcm_hw_params_any(handle, hw) < 0 ||
        snd_pcm_hw_params_set_access(handle, hw, access) < 0 ||
        snd_pcm_hw_params_set_channels(handle, hw, static_cast<unsigned>(logical.channels)) < 0)
        return ErrorCode::FormatMismatch;

    const std::pair<snd_pcm_format_t, SampleFormat> formats[] = {
        {SND_PCM_FORMAT_FLOAT_LE, SampleFormat::F32LE}, {SND_PCM_FORMAT_S32_LE, SampleFormat::S32LE},
        {SND_PCM_FORMAT_S24_3LE, SampleFormat::S24_3LE}, {SND_PCM_FORMAT_S24_LE, SampleFormat::S24LE},
        {SND_PCM_FORMAT_S16_LE, SampleFormat::S16LE}};
    SampleFormat format{};
    for (const auto &entry : formats)
        if (snd_pcm_hw_params_set_format(handle, hw, entry.first) >= 0)
        {
            format = entry.second;
            break;
        }

    auto hz = static_cast<unsigned>(logical.sample_rate);
    if (!is_interleaved_pcm(format) || snd_pcm_hw_params_set_rate_near(handle, hw, &hz, nullptr) < 0 ||
        !is_sample_rate(static_cast<SampleRate>(hz)))
        return ErrorCode::FormatMismatch;
    const auto rate = static_cast<SampleRate>(hz);
    const auto budget = frames_in_period(rate, duration);
    if (!budget)
        return budget.ret_code();

    auto period = static_cast<snd_pcm_uframes_t>(budget.value());
    int period_dir = -1;
    if (snd_pcm_hw_params_set_period_size_near(handle, hw, &period, &period_dir) < 0)
        return ErrorCode::FormatMismatch;

    // Keep the period constraints for the buffer-size fallback.
    snd_pcm_hw_params_t *buffer_params;
    snd_pcm_hw_params_alloca(&buffer_params);
    snd_pcm_hw_params_copy(buffer_params, hw);
    unsigned periods = 2;
    if (snd_pcm_hw_params_set_periods_near(handle, hw, &periods, nullptr) < 0)
    {
        if (period > std::numeric_limits<snd_pcm_uframes_t>::max() / 2)
            return ErrorCode::TooLarge;
        auto buffer_frames = 2 * period;
        hw = buffer_params;
        if (snd_pcm_hw_params_set_buffer_size_near(handle, hw, &buffer_frames) < 0)
            return ErrorCode::FormatMismatch;
    }
    const auto rc = snd_pcm_hw_params(handle, hw);
    if (rc == -EINVAL || rc == -ENOSYS || rc == -EOPNOTSUPP)
        return ErrorCode::FormatMismatch;
    if (rc < 0)
        return alsa_error(rc);
    set_device_max_frames(std::min<std::size_t>(period, budget.value()));
    return PortSpec{rate, logical.channels, format};
}

Result<PortSpec> AlsaBackend::on_open(bool capture, PortSpec logical, std::chrono::microseconds duration)
{
    if (logical.channels > std::numeric_limits<unsigned>::max())
        return ErrorCode::TooLarge;
    snd_pcm_t *handle = nullptr;
    const auto rc = snd_pcm_open(&handle, device_.c_str(), capture ? SND_PCM_STREAM_CAPTURE : SND_PCM_STREAM_PLAYBACK,
                                 SND_PCM_NONBLOCK);
    if (rc < 0)
        return alsa_error(rc);
    std::unique_ptr<snd_pcm_t, decltype(&snd_pcm_close)> pcm(handle, snd_pcm_close);

    auto mmap = use_mmap_;
    auto spec = configure_pcm(handle, mmap, logical, duration);
    if (mmap && spec.ret_code() == ErrorCode::FormatMismatch)
    {
        mmap = false;
        spec = configure_pcm(handle, mmap, logical, duration);
    }
    if (!spec)
        return spec;

    const auto frames = device_max_frames();
    snd_pcm_sw_params_t *sw;
    snd_pcm_sw_params_alloca(&sw);
    if (snd_pcm_sw_params_current(handle, sw) < 0 || snd_pcm_sw_params_set_avail_min(handle, sw, frames) < 0)
        return ErrorCode::IoFailed;
    if (!capture)
    {
        snd_pcm_uframes_t boundary = 0;
        if (snd_pcm_sw_params_set_start_threshold(handle, sw, frames) < 0 ||
            snd_pcm_sw_params_set_silence_threshold(handle, sw, 0) < 0 ||
            snd_pcm_sw_params_get_boundary(sw, &boundary) < 0 ||
            snd_pcm_sw_params_set_silence_size(handle, sw, boundary) < 0)
            return ErrorCode::IoFailed;
    }
    if (snd_pcm_sw_params(handle, sw) < 0)
        return ErrorCode::IoFailed;

    const auto count = snd_pcm_poll_descriptors_count(handle);
    if (count <= 0)
        return ErrorCode::IoFailed;
    std::vector<pollfd> descriptors(static_cast<std::size_t>(count) + 1);
    if (snd_pcm_poll_descriptors(handle, descriptors.data(), count) != count)
        return ErrorCode::IoFailed;
    const auto wake = eventfd(0, EFD_NONBLOCK | EFD_CLOEXEC);
    if (wake < 0)
        return ErrorCode::IoFailed;

    descriptors.back() = {wake, POLLIN, 0};
    poll_ = std::move(descriptors);
    mmap_ = mmap;
    pcm_ = pcm.release();
    return spec;
}

RetCode AlsaBackend::on_start() noexcept
{
    std::uint64_t signal = 0;
    ssize_t bytes;
    do
        bytes = ::read(poll_.back().fd, &signal, sizeof(signal));
    while (bytes < 0 && errno == EINTR);
    if (bytes < 0 && errno != EAGAIN)
        return ErrorCode::IoFailed;
    return prepare_stream();
}

RetCode AlsaBackend::prepare_stream() noexcept
{
    auto rc = snd_pcm_prepare(pcm_);
    if (rc >= 0 && is_capture())
    {
        rc = snd_pcm_start(pcm_);
        if (rc < 0)
            snd_pcm_drop(pcm_);
    }
    return rc < 0 ? alsa_error(rc) : RetCode{};
}

void AlsaBackend::on_stop() noexcept
{
    snd_pcm_drop(pcm_);
}

void AlsaBackend::on_cancel() noexcept
{
    constexpr std::uint64_t signal = 1;
    ssize_t bytes;
    do
        bytes = ::write(poll_.back().fd, &signal, sizeof(signal));
    while (bytes < 0 && errno == EINTR);
}

void AlsaBackend::on_close() noexcept
{
    if (!pcm_)
        return;
    ::close(poll_.back().fd);
    poll_.clear();
    snd_pcm_close(pcm_);
    pcm_ = nullptr;
}

RetCode AlsaBackend::recover(int error) noexcept
{
    if (error == -ESTRPIPE)
    {
        pollfd cancel{poll_.back().fd, POLLIN, 0};
        constexpr unsigned resume_attempts = 10;
        for (unsigned attempt = 1; ; ++attempt)
        {
            const auto resumed = snd_pcm_resume(pcm_);
            if (resumed >= 0)
                return {};
            if (resumed == -ENODEV || resumed == -ENXIO)
                return ErrorCode::DeviceLost;
            if (resumed != -EAGAIN || attempt == resume_attempts)
                break;

            int rc;
            do
                rc = ::poll(&cancel, 1, std::min(50, remaining_io_ms()));
            while (rc < 0 && errno == EINTR);
            if (rc < 0)
                return ErrorCode::IoFailed;
            if (cancel.revents & POLLIN)
                return ErrorCode::Cancelled;
            if (!remaining_io_ms())
                return ErrorCode::Timeout;
        }
    }
    else if (error != -EPIPE)
        return alsa_error(error);
    return prepare_stream();
}

RetCode AlsaBackend::wait_ready() noexcept
{
    for (;;)
    {
        const auto timeout = remaining_io_ms();
        if (!timeout)
            return ErrorCode::Timeout;
        const auto rc = ::poll(poll_.data(), poll_.size(), timeout);
        if (!rc)
            return ErrorCode::Timeout;
        if (rc < 0)
        {
            if (errno == EINTR)
                continue;
            return ErrorCode::IoFailed;
        }
        if (poll_.back().revents & POLLIN)
            return ErrorCode::Cancelled;
        unsigned short events = 0;
        const auto code = snd_pcm_poll_descriptors_revents(pcm_, poll_.data(), poll_.size() - 1, &events);
        if ((events & (POLLHUP | POLLNVAL)) ||
            ((code < 0 || (events & POLLERR)) && snd_pcm_state(pcm_) == SND_PCM_STATE_DISCONNECTED))
            return ErrorCode::DeviceLost;
        if (code < 0)
            return alsa_error(code);
        if (events & (POLLIN | POLLOUT | POLLERR))
            return {};
    }
}

Result<std::size_t> AlsaBackend::on_read(OBBlock output) noexcept
{
    const auto read_frames = mmap_ ? snd_pcm_mmap_readi : snd_pcm_readi;
    for (;;)
    {
        const auto ready = wait_ready();
        if (!ready)
            return ready;
        const auto rc = read_frames(pcm_, output.byte_view().data(), output.frames());
        if (rc > 0)
            return static_cast<std::size_t>(rc);
        if (rc < 0 && rc != -EAGAIN && rc != -EINTR)
        {
            const auto code = recover(static_cast<int>(rc));
            if (!code)
                return code;
        }
    }
}

Result<std::size_t> AlsaBackend::on_wait_writable() noexcept
{
    for (;;)
    {
        const auto ready = wait_ready();
        if (!ready)
            return ready;
        const auto frames = snd_pcm_avail_update(pcm_);
        if (frames > 0)
            return std::min<std::size_t>(frames, device_max_frames());
        if (frames < 0 && frames != -EAGAIN && frames != -EINTR)
        {
            const auto code = recover(static_cast<int>(frames));
            if (!code)
                return code;
        }
    }
}

RetCode AlsaBackend::on_write(IBBlock input) noexcept
{
    const auto width = input.spec().channels * sample_bytes(input.spec().format);
    const auto *bytes = input.byte_view().data();
    std::size_t written = 0;
    auto count = input.frames();
    const auto write_frames = mmap_ ? snd_pcm_mmap_writei : snd_pcm_writei;
    for (;;)
    {
        const auto rc = write_frames(pcm_, bytes + written * width, count);
        if (rc > 0)
        {
            written += static_cast<std::size_t>(rc);
            if (written == input.frames())
                return {};
        }
        else if (rc < 0 && rc != -EAGAIN && rc != -EINTR)
        {
            const auto code = recover(static_cast<int>(rc));
            if (!code)
                return code;
        }

        const auto next = on_wait_writable();
        if (!next)
            return next.ret_code();
        count = std::min(next.value(), input.frames() - written);
    }
}

template <class Endpoint> void Backend::claim_endpoint(Endpoint &endpoint, Endpoint *&slot)
{
    if (capture_ || playback_)
        throw Error(ErrorCode::Busy);
    if (!endpoint.capacity())
        throw Error(ErrorCode::NotReady);
    if (endpoint.backend_bound_.exchange(true, std::memory_order_acq_rel))
        throw Error(ErrorCode::Busy);
    slot = &endpoint;
}

void Backend::validate_channels(std::size_t logical_channels, std::size_t device_channels)
{
    if (device_channels != logical_channels)
        throw Error(ErrorCode::FormatMismatch);
}

void Backend::prepare(PortSpec logical, SampleRate device_rate, double max_rate_offset)
{
    const auto frames = device_max_frames_;
    const auto capture = is_capture();
    const auto src_fs = capture ? device_rate : logical.sample_rate;
    const auto dst_fs = capture ? logical.sample_rate : device_rate;
    const auto logical_frames = capture ? SincResampler::max_output_frames(src_fs, dst_fs, frames, max_rate_offset)
                                        : SincResampler::max_input_frames(src_fs, dst_fs, frames, max_rate_offset);
    if (logical_frames > target_frames())
        throw Error(ErrorCode::TooLarge);

    resampler_.prepare(logical.channels, src_fs, dst_fs, max_rate_offset);
    if (resampler_.needs_fir())
        device_planar_.resize(logical.channels, frames);
    logical_planar_.resize(logical.channels, logical_frames);
    logical_frames_ = logical_frames;
}

void Backend::reset_workspace() noexcept
{
    device_spec_ = {};
    device_max_frames_ = 0;
    logical_frames_ = 0;
    resampler_ = {};
    device_planar_ = {};
    logical_planar_ = {};
}

void Backend::release_endpoint() noexcept
{
    assert(!bound() && (capture_ || playback_));
    auto &occupied = capture_ ? capture_->backend_bound_ : playback_->backend_bound_;
    occupied.store(false, std::memory_order_release);
    capture_ = nullptr;
    playback_ = nullptr;
}

void Backend::release() noexcept
{
    reset_workspace();
    release_endpoint();
}

void Backend::open_queue(bool prefill) noexcept
{
    if (capture_)
        capture_->open(prefill);
    else
        playback_->open(prefill);
}

void Backend::close_queue() noexcept
{
    if (capture_)
        capture_->close();
    else
        playback_->close();
    resampler_.reset();
}

void Backend::close_playback_graph() noexcept
{
    playback_->close_graph();
}

const Node *Backend::endpoint_node() const noexcept
{
    if (!bound())
        return nullptr;
    if (capture_)
        return capture_;
    return playback_;
}

PortSpec Backend::logical_spec() const noexcept
{
    if (capture_)
        return capture_->spec();
    return playback_ ? playback_->spec() : PortSpec{};
}

std::chrono::microseconds Backend::endpoint_period() const noexcept
{
    return capture_ ? capture_->io_period() : playback_->io_period();
}

bool Backend::steady() const noexcept
{
    return capture_ ? capture_->steady() : playback_->steady();
}

std::size_t Backend::available() const noexcept
{
    return capture_ ? capture_->available() : playback_->available();
}

std::size_t Backend::target_frames() const noexcept
{
    return capture_ ? capture_->target_frames() : playback_->target_frames();
}

std::size_t Backend::capture_free_frames() const noexcept
{
    return capture_->capacity() - capture_->available();
}

void Backend::decode_to_capture(IBBlock input, double scale) noexcept
{
    const auto fir = resampler_.needs_fir();
    const auto planar = (fir ? device_planar_ : logical_planar_).block(input.frames());
    decode_pcm(input, planar);
    if (fir)
        emit_capture(planar, scale);
    else
        capture_->write(planar);
}

void Backend::flush_capture_tail(std::size_t frames) noexcept
{
    const auto input = device_planar_.block(frames);
    input.clear();
    emit_capture(input, 1.0);
}

void Backend::emit_capture(IFBlock input, double scale) noexcept
{
    const auto output = logical_block(logical_frames_);
    const auto result = resampler_.process(input, output, scale);
    assert(result.consumed == input.frames());
    capture_->write(output.subblock(0, result.produced));
}

std::size_t Backend::read_playback(OFBlock output) noexcept
{
    // A zero-frame batch must leave the playback prefill gate untouched.
    return output.frames() ? playback_->read(output) : 0;
}

OBBlock Backend::encode_from_playback(IFBlock input, OBBlock output, double scale) noexcept
{
    auto source = input;
    if (resampler_.needs_fir())
    {
        const auto device = device_planar_.block(output.frames());
        const auto result = resampler_.process(input, device, scale);
        assert(result.consumed == input.frames());
        source = device.subblock(0, result.produced);
    }

    assert(source.frames() <= output.frames());
    const OBBlock encoded(output.byte_view().data(), output.spec(), source.frames());
    if (encoded.frames())
        encode_pcm(source, encoded);
    return encoded;
}

Result<std::size_t> Backend::frames_in_period(SampleRate rate, std::chrono::microseconds period) noexcept
{
    constexpr std::uint64_t micros_per_second = 1000000;
    const auto hz = static_cast<std::uint32_t>(rate);
    const auto micros = static_cast<std::uint64_t>(period.count());
    const auto frames = (micros / micros_per_second) * hz + (micros % micros_per_second) * hz / micros_per_second;
    if (frames > std::numeric_limits<std::size_t>::max())
        return ErrorCode::TooLarge;
    if (!frames)
        return ErrorCode::InvalidArg;
    return static_cast<std::size_t>(frames);
}

        throw Error(ErrorCode::Busy);

        return;
    close_queue();
    running_ = false;
}

void PassiveBackend::unbind() noexcept

    if (!bound())
        return;

    release();
}

    bind_endpoint(endpoint);

    bind_endpoint(endpoint);

template <class Endpoint> void ActiveBackend::bind_endpoint(Endpoint &endpoint)
{
    claim(endpoint);
    const auto cleanup = [this]() noexcept {
        reset_workspace();
        on_close();
        release_endpoint();
    };
    ScopeExit<decltype(cleanup)> rollback(cleanup);

    const auto logical = endpoint.spec();
    const auto period = endpoint_period();
    const auto device = on_open(is_capture(), logical, period).value_or_throw();
    const auto frames = device_max_frames();
    if (!valid_pcm_spec(device) || !frames)
        throw Error(ErrorCode::InvalidArg);
    validate_channels(logical.channels, device.channels);
    if (frames > frames_in_period(device.sample_rate, period).value_or_throw())
        throw Error(ErrorCode::TooLarge);

    prepare(logical, device.sample_rate, async_ ? max_asrc_correction : 0.0);
    const auto width = sample_bytes(device.format);
    if (frames > device_bytes_.max_size() / device.channels / width)
        throw Error(ErrorCode::TooLarge);
    // Allocate the byte buffer last. A failed resize leaves it empty.
    device_bytes_.resize(frames * device.channels * width);

    complete_binding(device);
    last_error_.store({}, std::memory_order_release);
    rollback.dismiss();
}

bool ActiveBackend::running() const noexcept
{
    return state() != State::Stopped;
}

float ActiveBackend::drift_ppm() const noexcept
{
    return static_cast<float>(asrc_.correction.load(std::memory_order_relaxed) * ppm_per_unit);
}

Milliseconds ActiveBackend::io_timeout() const noexcept
{
    // Ten periods, rounded up to the wait API's millisecond resolution.
    const auto us = endpoint_period().count();
    const auto ms = us / 100 + (us % 100 != 0);
    return Milliseconds(std::max<std::int64_t>(500, std::min<std::int64_t>(ms, std::numeric_limits<int>::max())));
}

int ActiveBackend::remaining_io_ms() const noexcept
{
    const auto remaining = io_deadline_ - Clock::now();
    if (remaining <= Clock::duration::zero())
        return 0;
    const auto ms = std::chrono::duration_cast<Milliseconds>(remaining);
    return static_cast<int>(ms.count() + (ms < remaining));
}

void ActiveBackend::start()
{
    if (!bound())
        throw Error(ErrorCode::NotReady);
    if (running())
        throw Error(ErrorCode::Busy);
    if (worker_.joinable())
        worker_.join();
    last_error_.store({}, std::memory_order_release);

    RetCode start_result;
    bool start_done = false;
    worker_ = std::thread([this, &start_result, &start_done]() noexcept {
        if (async_)
            configure_audio_thread(is_capture() ? "ae-capture" : "ae-playback");

        const auto code = on_start();
        if (code)
        {
            open_queue(async_);
            worker_state_.store(State::Running, std::memory_order_release);
        }
        {
            const std::lock_guard<std::mutex> lock(wait_mutex_);
            start_result = code;
            start_done = true;
        }
        wait_cv_.notify_one();
        if (code)
            run();
    });

    std::unique_lock<std::mutex> lock(wait_mutex_);
    wait_cv_.wait(lock, [&] { return start_done; });
    lock.unlock();
    if (!start_result)
        worker_.join();
    start_result.or_throw();
}

void ActiveBackend::stop() noexcept
{
    if (!worker_.joinable())
        return;
    if (running())
    {
        const auto drain = !async_ && !is_capture();
        if (drain)
            close_playback_graph();

        bool stopping;
        {
            const std::lock_guard<std::mutex> lock(wait_mutex_);
            auto expected = State::Running;
            stopping = worker_state_.compare_exchange_strong(expected, drain ? State::Draining : State::Stopping,
                                                             std::memory_order_acq_rel);
        }
        if (stopping)
        {
            wait_cv_.notify_one();
            if (!drain)
                on_cancel();
        }
    }
    worker_.join();
}

void ActiveBackend::unbind() noexcept
{
    if (!bound())
        return;
    stop();
    on_close();
    std::vector<std::uint8_t>().swap(device_bytes_);
    release();
}

void ActiveBackend::go_offline(RetCode error) noexcept
{
    close_queue();
    asrc_.reset();
    has_input_ = false;
    record_io_error(error);
}

void ActiveBackend::record_io_error(RetCode error) noexcept
{
    if (!error && error != ErrorCode::Cancelled)
        last_error_.store(error, std::memory_order_release);
}

Result<std::size_t> ActiveBackend::on_read(OBBlock) noexcept
{
    return ErrorCode::InvalidArg;
}

RetCode ActiveBackend::on_write(IBBlock) noexcept
{
    return ErrorCode::InvalidArg;
}

RetCode ActiveBackend::on_write_silence(OBBlock scratch) noexcept
{
    const auto bytes = scratch.byte_view();
    std::memset(bytes.data(), 0, bytes.size());
    return on_write(scratch);
}

void ActiveBackend::wait_backpressure() noexcept
{
    const auto wait = std::max(Microseconds(200), std::min(Microseconds(2000), endpoint_period() / 2));
    std::unique_lock<std::mutex> lock(wait_mutex_);
    wait_cv_.wait_for(lock, wait, [this] { return worker_state_.load(std::memory_order_acquire) != State::Running; });
}

void ActiveBackend::ASRC::reset() noexcept
{
    filtered_error = 0;
    integral = 0;
    correction.store(0.0, std::memory_order_relaxed);
}

void ActiveBackend::ASRC::update(std::size_t queued_before, std::size_t queued_after, std::size_t target_frames,
                           SampleRate logical_rate, std::size_t device_frames, SampleRate device_rate) noexcept
{
    constexpr double filter_seconds = 0.25;
    constexpr double proportional_gain = 0.5;
    constexpr double integral_gain = 0.06;

    const auto batch_seconds = static_cast<double>(device_frames) / static_cast<std::uint32_t>(device_rate);
    const auto fill_frames = (static_cast<double>(queued_before) + static_cast<double>(queued_after)) * 0.5;
    const auto error_seconds =
        (fill_frames - static_cast<double>(target_frames)) / static_cast<std::uint32_t>(logical_rate);
    filtered_error += -std::expm1(-batch_seconds / filter_seconds) * (error_seconds - filtered_error);
    const auto proportional = proportional_gain * filtered_error;
    const auto next_integral = integral + integral_gain * filtered_error * batch_seconds;
    const auto requested_correction = proportional + next_integral;
    if (std::abs(requested_correction) <= max_asrc_correction || requested_correction * filtered_error < 0)
        integral = next_integral;
    const auto bounded = std::max(-max_asrc_correction, std::min(max_asrc_correction, proportional + integral));
    correction.store(bounded, std::memory_order_relaxed);
}

OBBlock ActiveBackend::device_block(std::size_t frames) noexcept
{
    return {device_bytes_.data(), device_spec(), frames};
}

RetCode ActiveBackend::transfer_capture(std::size_t &device_frames) noexcept
{
    const auto batch = device_block(device_max_frames());
    const auto read = on_read(batch);
    if (!read)
        return read.ret_code();
    device_frames = read.value();
    if (device_frames > batch.frames())
        return ErrorCode::IoFailed;
    if (!device_frames)
        return {};

    has_input_ = true;
    const auto primed = async_ && steady();
    const auto queued_before = primed ? available() : 0;
    decode_to_capture(device_block(device_frames), asrc_.scale());
    if (primed)
        asrc_.update(queued_before, available(), target_frames(), logical_spec().sample_rate,
                     device_frames, batch.spec().sample_rate);
    return {};
}

Result<std::size_t> ActiveBackend::next_playback_batch() noexcept
{
    const auto batch = on_wait_writable();
    if (!batch)
        return batch;
    const auto frames = batch.value();
    if (!frames || frames > device_max_frames())
        return ErrorCode::IoFailed;
    return batch;
}

RetCode ActiveBackend::emit_playback(IFBlock input, std::size_t device_frames, double scale) noexcept
{
    const auto batch = device_block(device_frames);
    const auto samples = encode_from_playback(input, batch, scale);
    if (!samples.frames())
        return async_ ? on_write_silence(batch) : RetCode{};

    if (async_ && samples.frames() < device_frames)
    {
        const auto bytes = batch.byte_view();
        const auto encoded = samples.byte_view().size();
        std::memset(bytes.data() + encoded, 0, bytes.size() - encoded);
        return on_write(batch);
    }
    return on_write(samples);
}

RetCode ActiveBackend::transfer_playback_async(std::size_t &device_frames) noexcept
{
    const auto batch = next_playback_batch();
    if (!batch)
        return batch.ret_code();
    device_frames = batch.value();
    const auto scale = asrc_.scale();
    const auto requested = required_input(device_frames, scale);
    const auto primed = steady();
    const auto queued_before = primed ? available() : 0;
    const auto logical = logical_block(requested);
    const auto received = read_playback(logical);
    const auto result = received || (!requested && primed)
                            ? emit_playback(logical.subblock(0, received), device_frames, scale)
                            : on_write_silence(device_block(device_frames));
    if (result && primed)
        asrc_.update(queued_before, available(), target_frames(), logical_spec().sample_rate,
                     device_frames, device_spec().sample_rate);
    return result;
}

RetCode ActiveBackend::run_sync_capture() noexcept
{
    while (worker_state_.load(std::memory_order_acquire) == State::Running)
    {
        if (capture_free_frames() < logical_frames())
        {
            wait_backpressure();
            continue;
        }
        std::size_t frames = 0;
        const auto result = transfer_capture(frames);
        if (!result)
            return result == ErrorCode::EndOfStream ? drain_capture() : result;
        if (!frames)
            wait_backpressure();
    }
    return {};
}

RetCode ActiveBackend::drain_capture() noexcept
{
    auto tail = has_input_ ? tail_frames() : 0;
    while (worker_state_.load(std::memory_order_acquire) == State::Running)
    {
        if (!tail && !available())
            return ErrorCode::EndOfStream;
        if (tail && capture_free_frames() >= logical_frames())
        {
            const auto frames = std::min(tail, device_max_frames());
            flush_capture_tail(frames);
            tail -= frames;
        }
        else
            wait_backpressure();
    }
    return {};
}

RetCode ActiveBackend::run_sync_playback() noexcept
{
    while (worker_state_.load(std::memory_order_acquire) == State::Running)
    {
        const auto batch = next_playback_batch();
        if (!batch)
            return batch.ret_code();
        const auto requested = required_input(batch.value());

        while (available() < requested && worker_state_.load(std::memory_order_acquire) == State::Running)
            wait_backpressure();
        if (worker_state_.load(std::memory_order_acquire) != State::Running)
            break;

        const auto logical = logical_block(requested);
        const auto received = read_playback(logical);
        assert(received == requested);
        has_input_ |= received != 0;
        const auto result = emit_playback(logical, batch.value(), 1.0);
        if (!result)
            return result;
    }
    return worker_state_.load(std::memory_order_acquire) == State::Draining ? drain_playback() : RetCode{};
}

RetCode ActiveBackend::drain_playback() noexcept
{
    auto tail = has_input_ || available() ? tail_frames() : 0;
    for (;;)
    {
        if (!tail && !available())
        {
            // Upsampling can still have output at the current phase after consuming the last input frame.
            if (required_input(1))
                return {};
        }
        const auto batch = next_playback_batch();
        if (!batch)
            return batch.ret_code();
        const auto requested = required_input(batch.value());
        const auto logical = logical_block(requested);
        const auto received = read_playback(logical);
        const auto padding = std::min(tail, requested - received);
        if (padding)
        {
            logical.subblock(received, padding).clear();
            tail -= padding;
        }
        const auto result = emit_playback(logical.subblock(0, received + padding), batch.value(), 1.0);
        if (!result)
            return result;
    }
}

RetCode ActiveBackend::run_async() noexcept
{
    const auto timeout = io_timeout();
    io_deadline_ = Clock::now() + timeout;
    while (worker_state_.load(std::memory_order_acquire) == State::Running)
    {
        std::size_t frames = 0;
        const auto result = is_capture() ? transfer_capture(frames) : transfer_playback_async(frames);
        if (!result)
            return result;

        const auto now = Clock::now();
        if (now >= io_deadline_)
            return ErrorCode::Timeout;
        if (frames)
            io_deadline_ = now + timeout;
    }
    return {};
}

void ActiveBackend::run() noexcept
{
    auto error = async_ ? run_async() : (is_capture() ? run_sync_capture() : run_sync_playback());
    on_stop();
    if (worker_state_.load(std::memory_order_acquire) == State::Stopping)
        error = {};
    go_offline(error);
    worker_state_.store(State::Stopped, std::memory_order_release);
}

/// @brief Owns endpoint occupation and the PCM workspace for external I/O.
/// @note Unbind or destroy the backend before removing its endpoint or destroying Engine.
/// Serialize diagnostic queries with backend lifecycle calls and destruction.
class Backend
{
  public:
    virtual ~Backend();
    Backend(const Backend &) = delete;
    Backend &operator=(const Backend &) = delete;

    virtual void start() = 0;
    virtual void stop() noexcept = 0;
    virtual void unbind() noexcept = 0;

    /// @brief Return a static diagnostic name for the backend and its bound direction, when known.
    virtual const char *type_name() const noexcept { return "Backend"; }

    /// @brief Report whether the endpoint and all working buffers are ready.
    bool bound() const noexcept { return device_spec_.channels != 0; }
    virtual bool running() const noexcept = 0;
    /// @brief Return the runtime I/O status. Passive calls report errors directly.
    virtual RetCode last_error() const noexcept { return {}; }
    /// @brief Return the negotiated PCM specification, or an empty specification when unbound.
    PortSpec device_spec() const noexcept { return device_spec_; }
    /// @brief Return the device batch limit, including the provisional value set by on_open().
    std::size_t device_max_frames() const noexcept { return device_max_frames_; }

    /// @brief Borrow the bound graph endpoint, or return null when unbound.
    /// @note Use until unbind or destruction, subject to the endpoint lifetime contract.
    const Node *endpoint_node() const noexcept;

    /// @brief Return the endpoint layout, or an empty specification when no endpoint is claimed.
    PortSpec logical_spec() const noexcept;

    /// @brief Report whether the binding uses FIR resampling.
    bool uses_resampler() const noexcept { return needs_fir(); }

  protected:
    Backend() = default;

    void claim(Capture &endpoint);
    void claim(Playback &endpoint);
    // The adapter has validated the device rate, channels, and batch size.
    void prepare(PortSpec logical, SampleRate device_rate, double max_rate_offset);
    // Publish only after the adapter has prepared all of its resources.
    void complete_binding(PortSpec device) noexcept { device_spec_ = device; }

    // Keep endpoint occupation through driver rollback, even after clearing the workspace.
    void reset_workspace() noexcept;
    void release_endpoint() noexcept;
    void release() noexcept;

    void open_queue(bool prefill) noexcept;
    void close_queue() noexcept;
    void close_playback_graph() noexcept;

    bool is_capture() const noexcept { return capture_ != nullptr; }
    std::chrono::microseconds endpoint_period() const noexcept;
    void set_device_max_frames(std::size_t frames) noexcept { device_max_frames_ = frames; }

    bool steady() const noexcept;
    std::size_t available() const noexcept;
    std::size_t target_frames() const noexcept;
    std::size_t capture_free_frames() const noexcept;
    std::size_t logical_frames() const noexcept { return logical_frames_; }
    bool needs_fir() const noexcept { return resampler_.needs_fir(); }
    std::size_t tail_frames() const noexcept { return resampler_.tail_frames(); }

    void decode_to_capture(IBBlock input, double scale) noexcept;
    void flush_capture_tail(std::size_t frames) noexcept;

    std::size_t required_input(std::size_t frames, double scale = 1.0) const noexcept
    {
        return resampler_.required_input(frames, scale);
    }
    OFBlock logical_block(std::size_t frames) noexcept { return logical_planar_.block(frames); }
    std::size_t read_playback(OFBlock output) noexcept;
    OBBlock encode_from_playback(IFBlock input, OBBlock output, double scale) noexcept;

    static constexpr bool valid_pcm_spec(PortSpec spec) noexcept
    {
        return is_sample_rate(spec.sample_rate) && spec.channels && is_interleaved_pcm(spec.format);
    }
    static Result<std::size_t> frames_in_period(SampleRate rate, std::chrono::microseconds period) noexcept;
    static void validate_channels(std::size_t logical_channels, std::size_t device_channels);

  private:
    template <class Endpoint> void claim_endpoint(Endpoint &endpoint, Endpoint *&slot);
    void emit_capture(IFBlock input, double scale) noexcept;

    Capture *capture_ = nullptr;
    Playback *playback_ = nullptr;
    PortSpec device_spec_;
    std::size_t device_max_frames_ = 0;
    std::size_t logical_frames_ = 0;
    SincResampler resampler_;
    Buffer device_planar_;
    Buffer logical_planar_;
};

/// @brief Caller-driven I/O without its own worker thread.
/// @note Serialize all calls, including queries and destruction, on the calling side.
class PassiveBackend : public Backend
{
  public:
    void start() final;
    void stop() noexcept final;
    void unbind() noexcept final;
    bool running() const noexcept final { return running_; }

  protected:
    ~PassiveBackend() override { unbind(); }

    template <class Endpoint> void bind_pcm(Endpoint &endpoint, PortSpec device)
    {
        claim(endpoint);
        const auto cleanup = [this]() noexcept { release(); };
        ScopeExit<decltype(cleanup)> rollback(cleanup);

        // Bound scratch size and the queue threshold for large endpoints.
        const auto period = std::min(endpoint_period(), std::chrono::microseconds(10000));
        set_device_max_frames(frames_in_period(device.sample_rate, period).value_or_throw());
        const auto logical = endpoint.spec();
        validate_channels(logical.channels, device.channels);
        prepare(logical, device.sample_rate, 0.0);
        complete_binding(device);
        rollback.dismiss();
    }

  private:
    bool running_ = false;
};

/// @brief Pumps PCM on a worker thread between an endpoint and a device, file, or callback.
/// @note Serialize binding, lifecycle calls, and destruction on the control side.
///       Query binding state and device specifications on that side.
/// @note Derived destructors must call unbind() before destroying resources used by I/O hooks.
class ActiveBackend : public Backend
{
  public:
    /// @brief I/O worker lifecycle state.
    enum class State { Stopped, Running, Draining, Stopping };

    /// @brief Open the source via on_open(), prepare DSP buffers, and bind to a prepared Capture node.
    /// @throws Error If the endpoint is unprepared, occupied, or negotiation fails.
    void bind(Capture &endpoint);
    /// @brief Open the sink via on_open(), prepare DSP buffers, and bind to a prepared Playback node.
    /// @throws Error If the endpoint is unprepared, occupied, or negotiation fails.
    void bind(Playback &endpoint);

    /// @brief Launch the I/O worker, wait for on_start(), and bring the endpoint online.
    /// @throws Error If unbound, already running, or on_start() reports an error.
    /// @note Thread creation exceptions propagate and leave the backend bound for retry.
    void start() final;
    /// @brief Stop I/O, take the endpoint offline, and reset DSP/drift state.
    /// @note Sync playback closes graph writes and drains queued frames and the FIR tail before stopping.
    /// @note Keeps the endpoint bound and prepared buffers intact for fast restart.
    void stop() noexcept final;
    /// @brief Stop I/O, release resources via on_close(), reset workspace, and detach the endpoint.
    void unbind() noexcept final;

    /// @brief Report whether I/O is running, draining, or stopping.
    bool running() const noexcept final;
    RetCode last_error() const noexcept final { return last_error_.load(std::memory_order_acquire); }

    /// @brief Read the current I/O worker state.
    State state() const noexcept { return worker_state_.load(std::memory_order_acquire); }

    /// @brief Report whether the worker follows an independent device clock with ASRC.
    bool is_async() const noexcept { return async_; }

    /// @brief Read the latest ASRC correction in ppm. Zero before correction or while offline.
    float drift_ppm() const noexcept;

  protected:
    /// @param async True for independent hardware clocks, false for graph-clocked I/O.
    explicit ActiveBackend(bool async) noexcept : async_(async) {}

    /// @brief Publish an I/O failure for last_error().
    /// @pre Call from the worker or during control-side cleanup after it joins.
    void record_io_error(RetCode error) noexcept;

    /// @brief Return the rounded-up time left for the current async I/O batch, or zero at its deadline.
    /// @pre Call from an async I/O hook on the worker thread.
    int remaining_io_ms() const noexcept;

    /// @brief Open the device or file and return its negotiated interleaved PCM specification.
    /// @note Call set_device_max_frames() before returning success.
    /// @note Runs on the control thread. Setup exceptions propagate after on_close() rolls back the open.
    virtual Result<PortSpec> on_open(bool capture, PortSpec logical, std::chrono::microseconds target_period) = 0;

    /// @brief Start the stream and acquire thread-affine resources on the I/O worker.
    /// @note Synchronized with start(); on failure, roll back before returning the error.
    virtual RetCode on_start() noexcept { return {}; }

    /// @brief Stop the stream and release worker resources after a successful on_start().
    virtual void on_stop() noexcept {}

    /// @brief Wake blocked I/O hooks promptly so they return Cancelled. Idempotent and non-blocking.
    /// @note Called only from control-side stop() while bound; must remain safe until on_close().
    virtual void on_cancel() noexcept {}

    /// @brief Release handles acquired in on_open() on the control thread after the worker has joined.
    /// @note Also called after a failed on_open(). Handle partial setup and unopened resources.
    virtual void on_close() noexcept {}

    /// @brief Read one batch of interleaved PCM frames (capture backends override this).
    virtual Result<std::size_t> on_read(OBBlock output) noexcept;

    /// @brief Wait until writable and return next batch size in [1, device_max_frames()].
    virtual Result<std::size_t> on_wait_writable() noexcept { return device_max_frames(); }

    /// @brief Write one batch of interleaved PCM frames (playback backends override this).
    virtual RetCode on_write(IBBlock input) noexcept;

    /// @brief Write a silent batch. The block provides scratch space for backends that need PCM bytes.
    virtual RetCode on_write_silence(OBBlock scratch) noexcept;

  private:
    struct ASRC
    {
        double filtered_error = 0;
        double integral = 0;
        std::atomic<double> correction{0.0};

        double scale() const noexcept { return 1.0 + correction.load(std::memory_order_relaxed); }
        void reset() noexcept;
        void update(std::size_t queued_before, std::size_t queued_after, std::size_t target_frames,
                    SampleRate logical_rate, std::size_t device_frames, SampleRate device_rate) noexcept;
    };

    template <class Endpoint> void bind_endpoint(Endpoint &endpoint);
    std::chrono::milliseconds io_timeout() const noexcept;
    void wait_backpressure() noexcept;
    void go_offline(RetCode error) noexcept;

    OBBlock device_block(std::size_t frames) noexcept;
    RetCode transfer_capture(std::size_t &device_frames) noexcept;
    Result<std::size_t> next_playback_batch() noexcept;
    RetCode emit_playback(IFBlock input, std::size_t device_frames, double scale) noexcept;
    RetCode transfer_playback_async(std::size_t &device_frames) noexcept;

    void run() noexcept;
    RetCode run_async() noexcept;
    RetCode run_sync_capture() noexcept;
    RetCode run_sync_playback() noexcept;
    RetCode drain_capture() noexcept;
    RetCode drain_playback() noexcept;

    const bool async_;
    std::vector<std::uint8_t> device_bytes_;
    ASRC asrc_;
    std::mutex wait_mutex_;
    std::condition_variable wait_cv_;
    bool has_input_ = false;
    std::chrono::steady_clock::time_point io_deadline_;
    std::thread worker_;
    std::atomic<State> worker_state_{State::Stopped};
    std::atomic<RetCode> last_error_{RetCode{}};
};

{
    if (!valid_pcm_spec(output_spec_))
        throw Error(ErrorCode::InvalidArg, "PullSink requires a valid interleaved PCM PortSpec");
}

void PullSink::bind(Playback &endpoint)
{
    bind_pcm(endpoint, output_spec_);
}

std::size_t PullSink::pull(OBBlock output)
{
    if (output.spec() != output_spec_)
        throw Error(ErrorCode::FormatMismatch, "PullSink output spec mismatch");
    const auto total_frames = output.frames();
    if (!total_frames)
        return 0;
    auto *bytes = output.byte_view().data();
    if (!bytes)
        throw Error(ErrorCode::InvalidArg, "PullSink output data is null");
    if (!running())
        return 0;

    const auto frame_bytes = output_spec_.channels * sample_bytes(output_spec_.format);
    const auto max_frames = device_max_frames();
    std::size_t produced = 0;
    while (produced < total_frames)
    {
        const auto queued = available();
        const auto frames = std::min(total_frames - produced, max_frames);
        const auto requested = required_input(frames);
        if (queued < requested && (frames == 1 || queued < required_input(1)))
            break;

        const auto logical = logical_block(std::min(requested, queued));
        const auto received = read_playback(logical);
        const OBBlock destination(bytes + produced * frame_bytes, output_spec_, frames);
        const auto written = encode_from_playback(logical.subblock(0, received), destination, 1.0).frames();
        produced += written;
        if (written < frames)
            break;
    }
    return produced;
}

} // namespace aereborn

#include "push_source.h"

PushSource::PushSource(PortSpec input_spec) : input_spec_(input_spec)
{
    if (!valid_pcm_spec(input_spec_))
        throw Error(ErrorCode::InvalidArg, "PushSource requires a valid interleaved PCM PortSpec");
}

void PushSource::bind(Capture &endpoint)
{
    bind_pcm(endpoint, input_spec_);
}

std::size_t PushSource::push(IBBlock input)
{
    if (input.spec() != input_spec_)
        throw Error(ErrorCode::FormatMismatch, "PushSource input spec mismatch");
    const auto total_frames = input.frames();
    if (!total_frames)
        return 0;
    const auto *bytes = input.byte_view().data();
    if (!bytes)
        throw Error(ErrorCode::InvalidArg, "PushSource input data is null");
    if (!running())
        return 0;

    const auto frame_bytes = input_spec_.channels * sample_bytes(input_spec_.format);
    const auto max_frames = device_max_frames();
    const auto fir = needs_fir();
    // FIR output depends on stream phase. Reserve room for the entire prepared output bound.
    const auto min_free_frames = fir ? logical_frames() : std::size_t{1};

    std::size_t accepted = 0;
    while (accepted < total_frames)
    {
        const auto free_frames = capture_free_frames();
        if (free_frames < min_free_frames)
            break;
        const auto limit = std::min(total_frames - accepted, max_frames);
        const auto frames = fir ? limit : std::min(limit, free_frames);
        decode_to_capture({bytes + accepted * frame_bytes, input_spec_, frames}, 1.0);
        accepted += frames;
    }
    return accepted;
}

} // namespace aereborn

struct ReleaseInterface

    void operator()(void *ptr) const noexcept { CoTaskMemFree(ptr); }

struct CloseEvent

class ComApartment
{
  public:
    explicit ComApartment(DWORD mode) noexcept : result(CoInitializeEx(nullptr, mode)) {}
    ~ComApartment() { if (SUCCEEDED(result) && active) CoUninitialize(); }

RetCode record_failure(WasapiBackend::Failure &failure, const char *operation, HRESULT error) noexcept
{
    failure = {operation, static_cast<std::int32_t>(error)};
    if (error == AUDCLNT_E_WRONG_ENDPOINT_TYPE)
        return ErrorCode::InvalidArg;
    if (error == AUDCLNT_E_UNSUPPORTED_FORMAT)
        return ErrorCode::FormatMismatch;
    if (error == AUDCLNT_E_DEVICE_INVALIDATED || error == HRESULT_FROM_WIN32(ERROR_NOT_FOUND))
        return ErrorCode::DeviceLost;
    return ErrorCode::IoFailed;
}

RetCode activate(const std::wstring &id, EDataFlow direction, Interface<IAudioClient> &client,
                 std::wstring *resolved, WasapiBackend::Failure &failure)
{
    IMMDeviceEnumerator *enumerator_ptr = nullptr;
    auto rc = CoCreateInstance(__uuidof(MMDeviceEnumerator), nullptr, CLSCTX_ALL,
                               IID_PPV_ARGS(&enumerator_ptr));
    if (FAILED(rc))
        return record_failure(failure, "CoCreateInstance(MMDeviceEnumerator)", rc);
    const Interface<IMMDeviceEnumerator> enumerator(enumerator_ptr);

    IMMDevice *device_ptr = nullptr;
    rc = id.empty() ? enumerator->GetDefaultAudioEndpoint(direction, eConsole, &device_ptr)
                    : enumerator->GetDevice(id.c_str(), &device_ptr);
    if (FAILED(rc))
        return record_failure(failure, id.empty() ? "GetDefaultAudioEndpoint" : "GetDevice", rc);
    const Interface<IMMDevice> device(device_ptr);
    if (resolved)
    {
        if (id.empty())
        {
            LPWSTR id_ptr = nullptr;
            rc = device->GetId(&id_ptr);
            if (FAILED(rc))
                return record_failure(failure, "IMMDevice::GetId", rc);
            const std::unique_ptr<wchar_t, FreeComBuffer> device_id(id_ptr);
            resolved->assign(device_id.get());
        }
        else
        {
            IMMEndpoint *endpoint_ptr = nullptr;
            rc = device->QueryInterface(IID_PPV_ARGS(&endpoint_ptr));
            if (FAILED(rc))
                return record_failure(failure, "QueryInterface(IMMEndpoint)", rc);
            const Interface<IMMEndpoint> endpoint(endpoint_ptr);
            EDataFlow flow;
            rc = endpoint->GetDataFlow(&flow);
            if (FAILED(rc))
                return record_failure(failure, "IMMEndpoint::GetDataFlow", rc);
            if (flow != direction)
                return record_failure(failure, "WASAPI endpoint direction", AUDCLNT_E_WRONG_ENDPOINT_TYPE);
            *resolved = id;
        }
    }
    IAudioClient *client_ptr = nullptr;
    rc = device->Activate(__uuidof(IAudioClient), CLSCTX_ALL, nullptr, reinterpret_cast<void **>(&client_ptr));
    if (FAILED(rc))
        return record_failure(failure, "IMMDevice::Activate(IAudioClient)", rc);
    client.reset(client_ptr);
    return {};
}

SampleFormat sample_format(const WAVEFORMATEX &format) noexcept
{
    auto tag = format.wFormatTag;
    if (tag == WAVE_FORMAT_EXTENSIBLE)
    {
        if (format.cbSize < sizeof(WAVEFORMATEXTENSIBLE) - sizeof(WAVEFORMATEX))
            return {};
        const auto &ext = reinterpret_cast<const WAVEFORMATEXTENSIBLE &>(format);
        constexpr GUID pcm{1, 0, 0x0010, {0x80, 0, 0, 0xaa, 0, 0x38, 0x9b, 0x71}};
        constexpr GUID floating{3, 0, 0x0010, {0x80, 0, 0, 0xaa, 0, 0x38, 0x9b, 0x71}};
        if (IsEqualGUID(ext.SubFormat, pcm))
            tag = WAVE_FORMAT_PCM;
        else if (IsEqualGUID(ext.SubFormat, floating))
            tag = WAVE_FORMAT_IEEE_FLOAT;
        else
            return {};
    }
    if (tag == WAVE_FORMAT_IEEE_FLOAT && format.wBitsPerSample == 32)
        return SampleFormat::F32LE;
    if (tag == WAVE_FORMAT_PCM)
    {
        switch (format.wBitsPerSample)
        {
        case 16: return SampleFormat::S16LE;
        case 24: return SampleFormat::S24_3LE;
        case 32: return SampleFormat::S32LE;
        }
    }
    return {};
}

Result<UINT32> initialize(IAudioClient &client, const WAVEFORMATEX &format, WasapiBackend::Failure &failure) noexcept
{
    auto rc = client.Initialize(AUDCLNT_SHAREMODE_SHARED, AUDCLNT_STREAMFLAGS_EVENTCALLBACK,
                                0, 0, &format, nullptr);
    if (FAILED(rc))
        return record_failure(failure, "IAudioClient::Initialize", rc);
    UINT32 capacity = 0;
    rc = client.GetBufferSize(&capacity);
    if (FAILED(rc))
        return record_failure(failure, "IAudioClient::GetBufferSize", rc);
    return capacity;
}

Result<PortSpec> WasapiBackend::on_open(bool capture, PortSpec logical, std::chrono::microseconds period)
{
    failure_ = {};
    ComApartment com(COINIT_APARTMENTTHREADED);
    if (FAILED(com.result) && com.result != RPC_E_CHANGED_MODE)
        return record_failure(failure_, "CoInitializeEx", com.result);

    Interface<IAudioClient> probe;
    std::wstring resolved;
    const auto code = activate(device_, capture ? eCapture : eRender, probe, &resolved, failure_);
    if (!code)
        return code;
    WAVEFORMATEX *format_ptr = nullptr;
    const auto rc = probe->GetMixFormat(&format_ptr);
    if (FAILED(rc))
        return record_failure(failure_, "IAudioClient::GetMixFormat", rc);
    const std::unique_ptr<WAVEFORMATEX, FreeComBuffer> format(format_ptr);
    const PortSpec spec{static_cast<SampleRate>(format->nSamplesPerSec), format->nChannels, sample_format(*format)};
    if (!valid_pcm_spec(spec) || logical.channels != spec.channels ||
        format->nBlockAlign != spec.channels * sample_bytes(spec.format) ||
        sizeof(*format) + format->cbSize > format_.size())
        return ErrorCode::FormatMismatch;
    const auto budget = frames_in_period(spec.sample_rate, period);
    if (!budget)
        return budget.ret_code();

    const auto initialized = initialize(*probe, *format, failure_);
    if (!initialized)
        return initialized.ret_code();
    const auto capacity = initialized.value();
    std::vector<std::uint8_t> packet;
    if (capture)
    {
        if (capacity > packet.max_size() / format->nBlockAlign)
            return ErrorCode::TooLarge;
        packet.resize(static_cast<std::size_t>(capacity) * format->nBlockAlign);
    }

    std::unique_ptr<void, CloseEvent> ready(CreateEventW(nullptr, FALSE, FALSE, nullptr));
    if (!ready)
        return record_failure(failure_, "CreateEventW(ready)", HRESULT_FROM_WIN32(GetLastError()));
    std::unique_ptr<void, CloseEvent> cancelled(CreateEventW(nullptr, TRUE, FALSE, nullptr));
    if (!cancelled)
        return record_failure(failure_, "CreateEventW(cancelled)", HRESULT_FROM_WIN32(GetLastError()));

    static_assert(sizeof(WAVEFORMATEXTENSIBLE) == 40, "Unexpected WAVEFORMATEXTENSIBLE layout");
    format_.fill(0);
    std::memcpy(format_.data(), format.get(), sizeof(*format) + format->cbSize);
    device_id_ = std::move(resolved);
    packet_ = std::move(packet);
    ready_ = ready.release();
    cancelled_ = cancelled.release();
    set_device_max_frames(std::min<std::size_t>(budget.value(), capacity));
    return spec;
}

void WasapiBackend::on_close() noexcept
{
    if (!ready_)
        return;
    CloseHandle(cancelled_);
    CloseHandle(ready_);
    cancelled_ = ready_ = nullptr;
    device_id_.clear();
    std::vector<std::uint8_t>().swap(packet_);
}

RetCode WasapiBackend::on_start() noexcept
{
    failure_ = {};
    if (!ResetEvent(ready_) || !ResetEvent(cancelled_))
        return record_failure(failure_, "ResetEvent", HRESULT_FROM_WIN32(GetLastError()));
    const auto source = is_capture();
    ComApartment com(COINIT_MULTITHREADED);
    if (FAILED(com.result))
        return record_failure(failure_, "CoInitializeEx", com.result);
    Interface<IAudioClient> client;
    const auto code = activate(device_id_, source ? eCapture : eRender, client, nullptr, failure_);
    if (!code)
        return code;
    WAVEFORMATEXTENSIBLE format;
    std::memcpy(&format, format_.data(), sizeof(format));
    const auto initialized = initialize(*client, format.Format, failure_);
    if (!initialized)
        return initialized.ret_code();
    const auto capacity = initialized.value();
    if (source && capacity > packet_.size() / format.Format.nBlockAlign)
        return ErrorCode::TooLarge;
    auto rc = client->SetEventHandle(ready_);
    if (FAILED(rc))
        return record_failure(failure_, "IAudioClient::SetEventHandle", rc);

    IAudioCaptureClient *capture = nullptr;
    IAudioRenderClient *render = nullptr;
    rc = source ? client->GetService(IID_PPV_ARGS(&capture)) : client->GetService(IID_PPV_ARGS(&render));
    if (FAILED(rc))
        return record_failure(failure_, "IAudioClient::GetService", rc);
    Interface<IAudioCaptureClient> capture_service(capture);
    Interface<IAudioRenderClient> render_service(render);
    if (render_service)
    {
        // Prime the endpoint buffer before the audio engine starts consuming it.
        const auto primed = write(*render_service, capacity, {});
        if (!primed)
            return primed;
    }
    rc = client->Start();
    if (FAILED(rc))
        return record_failure(failure_, "IAudioClient::Start", rc);

    packet_offset_ = packet_size_ = 0;
    capacity_ = capacity;
    client_ = client.release();
    capture_ = capture_service.release();
    render_ = render_service.release();
    com.active = false;
    return {};
}

void WasapiBackend::on_stop() noexcept
{
    client_->Stop();
    if (capture_)
        capture_->Release();
    else
        render_->Release();
    client_->Release();
    capture_ = nullptr;
    render_ = nullptr;
    client_ = nullptr;
    CoUninitialize();
}

void WasapiBackend::on_cancel() noexcept
{
    SetEvent(cancelled_);
}

RetCode WasapiBackend::wait() noexcept
{
    const HANDLE handles[] = {cancelled_, ready_};
    const auto timeout = remaining_io_ms();
    if (!timeout)
        return ErrorCode::Timeout;
    switch (WaitForMultipleObjects(2, handles, FALSE, static_cast<DWORD>(timeout)))
    {
    case WAIT_OBJECT_0: return ErrorCode::Cancelled;
    case WAIT_OBJECT_0 + 1: return {};
    case WAIT_TIMEOUT: return ErrorCode::Timeout;
    case WAIT_FAILED:
        return record_failure(failure_, "WaitForMultipleObjects", HRESULT_FROM_WIN32(GetLastError()));
    default: return ErrorCode::IoFailed;
    }
}

Result<std::size_t> WasapiBackend::on_read(OBBlock output) noexcept
{
    const auto width = output.spec().channels * sample_bytes(output.spec().format);
    const auto dest = output.byte_view();
    while (packet_offset_ == packet_size_)
    {
        BYTE *bytes = nullptr;
        UINT32 frames = 0;
        DWORD flags = 0;
        auto rc = capture_->GetBuffer(&bytes, &frames, &flags, nullptr, nullptr);
        if (FAILED(rc))
            return record_failure(failure_, "IAudioCaptureClient::GetBuffer", rc);
        if (!frames)
        {
            // No packet needs releasing when GetBuffer reports zero frames.
            const auto ready = wait();
            if (!ready)
                return ready;
            continue;
        }

        assert(frames <= capacity_);
        const auto received = std::min<std::size_t>(frames, output.frames());
        const auto copied = received * width;
        const auto remaining = (frames - received) * width;
        if (flags & AUDCLNT_BUFFERFLAGS_SILENT)
        {
            std::memset(dest.data(), 0, copied);
            if (remaining)
                std::memset(packet_.data(), 0, remaining);
        }
        else
        {
            std::memcpy(dest.data(), bytes, copied);
            if (remaining)
                std::memcpy(packet_.data(), bytes + copied, remaining);
        }
        rc = capture_->ReleaseBuffer(frames);
        if (FAILED(rc))
            return record_failure(failure_, "IAudioCaptureClient::ReleaseBuffer", rc);
        if (remaining)
        {
            packet_offset_ = 0;
            packet_size_ = remaining;
        }
        return received;
    }

    const auto size = std::min(dest.size(), packet_size_ - packet_offset_);
    std::memcpy(dest.data(), packet_.data() + packet_offset_, size);
    packet_offset_ += size;
    return size / width;
}

Result<std::size_t> WasapiBackend::on_wait_writable() noexcept
{
    for (;;)
    {
        UINT32 used = 0;
        const auto rc = client_->GetCurrentPadding(&used);
        if (FAILED(rc))
            return record_failure(failure_, "IAudioClient::GetCurrentPadding", rc);
        if (used < capacity_)
            return std::min<std::size_t>(capacity_ - used, device_max_frames());
        const auto ready = wait();
        if (!ready)
            return ready;
    }
}

RetCode WasapiBackend::on_write(IBBlock input) noexcept
{
    return write(*render_, static_cast<UINT32>(input.frames()), input.byte_view());
}

RetCode WasapiBackend::on_write_silence(OBBlock scratch) noexcept
{
    return write(*render_, static_cast<UINT32>(scratch.frames()), {});
}

RetCode WasapiBackend::write(IAudioRenderClient &render, std::uint32_t frames, View<const std::uint8_t> bytes) noexcept
{
    BYTE *dest = nullptr;
    auto rc = render.GetBuffer(frames, &dest);
    if (FAILED(rc))
        return record_failure(failure_, "IAudioRenderClient::GetBuffer", rc);
    const auto silent = bytes.empty();
    if (!silent)
        std::memcpy(dest, bytes.data(), bytes.size());
    rc = render.ReleaseBuffer(frames, silent ? AUDCLNT_BUFFERFLAGS_SILENT : 0);
    return FAILED(rc) ? record_failure(failure_, "IAudioRenderClient::ReleaseBuffer", rc) : RetCode{};
}

Result<PortSpec> WavCapture::on_open(bool capture, PortSpec, std::chrono::microseconds period)

    if (!capture)
        return ErrorCode::InvalidArg;
    const auto opened = file_.open_read(path_);
    if (!opened)
        return opened;
    const auto spec = file_.spec();
    const auto count = frames_in_period(spec.sample_rate, period);
    if (!count)
        return count.ret_code();

    repeats_left_ = repeats_;
    set_device_max_frames(count.value());
    return spec;
}

void WavCapture::on_close() noexcept
{
    file_.close();
}

Result<std::size_t> WavCapture::on_read(OBBlock output) noexcept
{
    const auto spec = output.spec();
    const auto width = spec.channels * sample_bytes(spec.format);
    auto *dest = output.byte_view().data();
    std::size_t frames = 0;
    while (frames < output.frames())
    {
        if (file_.tell() == file_.frame_count())
        {
            if (!file_.frame_count() || (!loop_ && !repeats_left_))
                break;
            const auto code = file_.seek(0);
            if (!code)
                return code;
            if (!loop_)
                --repeats_left_;
        }
        const auto read = file_.read({dest + frames * width, spec, output.frames() - frames});
        if (!read)
            return read;
        frames += read.value();
    }
    if (!frames)
        return ErrorCode::EndOfStream;
    return frames;
}

WavPlayback::WavPlayback(std::string path, SampleFormat format, std::chrono::seconds segment_duration)
    : ActiveBackend(false), path_(std::move(path)), format_(format), segment_duration_(segment_duration)
{
    if (segment_duration_.count() < 0)
        throw Error(ErrorCode::InvalidArg);
    if (!WavFile::supports_write_format(format_))
        throw Error(ErrorCode::FormatMismatch);
}

Result<PortSpec> WavPlayback::on_open(bool capture, PortSpec logical, std::chrono::microseconds period)
{
    if (capture)
        return ErrorCode::InvalidArg;
    const auto count = frames_in_period(logical.sample_rate, period);
    if (!count)
        return count.ret_code();
    logical.format = format_;
    if (segment_duration_.count())
    {
        const auto limit = WavFile::max_write_frames(logical);
        if (!limit)
            return limit.ret_code();
        const auto hz = static_cast<std::uint32_t>(logical.sample_rate);
        const auto seconds = static_cast<std::uint64_t>(segment_duration_.count());
        if (seconds > limit.value() / hz)
            return ErrorCode::TooLarge;
        segment_frames_ = static_cast<std::size_t>(seconds * hz);

        segment_path_ = path_;
        const auto separator = path_.find_last_of("/\\");
        const auto name_start = separator == std::string::npos ? 0 : separator + 1;
        if (name_start == path_.size())
            return ErrorCode::InvalidArg;
        auto extension = path_.find_last_of('.');
        if (extension == std::string::npos || extension <= name_start)
        {
            extension = segment_path_.size();
            segment_path_ += ".wav";
        }
        segment_path_.insert(extension, 1, '-');
        segment_number_offset_ = extension + 1;
        segment_path_.insert(segment_number_offset_, segment_number_width, '0');
        segment_index_ = 0;
    }
    const auto opened = open_file(logical);
    if (!opened)
        return opened;
    set_device_max_frames(count.value());
    return logical;
}

RetCode WavPlayback::on_start() noexcept
{
    const auto state = file_.status();
    return state == ErrorCode::NotReady ? open_file(device_spec()) : state;
}

void WavPlayback::on_stop() noexcept
{
    const auto flushed = file_.flush();
    if (flushed != ErrorCode::NotReady)
        record_io_error(flushed);
}

RetCode WavPlayback::open_file(PortSpec spec) noexcept
{
    if (!segment_frames_)
        return file_.open_write(path_, spec, WavFile::WriteMode::Truncate);
    for (;;)
    {
        if (segment_index_ == std::numeric_limits<std::uint32_t>::max())
            return ErrorCode::TooLarge;
        auto index = ++segment_index_;
        for (auto pos = segment_number_offset_ + segment_number_width; pos != segment_number_offset_; index /= 10)
            segment_path_[--pos] = static_cast<char>('0' + index % 10);
        const auto opened = file_.open_write(segment_path_, spec, WavFile::WriteMode::Exclusive);
        if (opened != ErrorCode::Busy)
            return opened;
    }
}

void WavPlayback::on_close() noexcept
{
    const auto result = file_.close();
    if (last_error())
        record_io_error(result);
}

RetCode WavPlayback::on_write(IBBlock input) noexcept
{
    if (!segment_frames_)
        return file_.write(input);

    const auto spec = input.spec();
    const auto width = spec.channels * sample_bytes(spec.format);
    const auto *bytes = input.byte_view().data();
    std::size_t written = 0;
    while (written < input.frames())
    {
        if (file_.frame_count() == segment_frames_)
        {
            const auto closed = file_.close();
            if (!closed)
                return closed;
            const auto opened = open_file(spec);
            if (!opened)
                return opened;
        }
        const auto count = std::min(input.frames() - written, segment_frames_ - file_.frame_count());
        const auto code = file_.write({bytes + written * width, spec, count});
        if (!code)
            return code;
        written += count;
    }
    return {};
}

constexpr std::uint16_t pcm_tag = 1;
constexpr std::uint16_t float_tag = 3;

void append_u16(unsigned char *&out, std::uint16_t value) noexcept
{
    *out++ = static_cast<unsigned char>(value);
    *out++ = static_cast<unsigned char>(value >> 8);
}

void append_u32(unsigned char *&out, std::uint32_t value) noexcept
{
    append_u16(out, static_cast<std::uint16_t>(value));
    append_u16(out, static_cast<std::uint16_t>(value >> 16));
}

std::uint32_t wav_header_size(SampleFormat format) noexcept
{
    return format == SampleFormat::F32LE ? 58 : 44;
}

bool write_header(std::FILE *file, PortSpec spec, std::uint32_t data_size) noexcept
{
    const auto width = static_cast<std::uint16_t>(spec.channels * sample_bytes(spec.format));
    const auto rate = static_cast<std::uint32_t>(spec.sample_rate);
    const auto floating = spec.format == SampleFormat::F32LE;
    std::array<unsigned char, 58> header;
    auto *out = header.data();
    const auto append_tag = [&out](const char *tag) {
        std::memcpy(out, tag, 4);
        out += 4;
    };
    append_tag("RIFF");
    append_u32(out, wav_header_size(spec.format) - 8 + data_size + (data_size & 1));
    append_tag("WAVE");
    append_tag("fmt ");
    append_u32(out, floating ? 18 : 16);
    append_u16(out, floating ? float_tag : pcm_tag);
    append_u16(out, static_cast<std::uint16_t>(spec.channels));
    append_u32(out, rate);
    append_u32(out, rate * width);
    append_u16(out, width);
    append_u16(out, static_cast<std::uint16_t>(sample_bits(spec.format)));
    if (floating)
    {
        append_u16(out, 0);
        append_tag("fact");
        append_u32(out, 4);
        append_u32(out, data_size / width);
    }
    append_tag("data");
    append_u32(out, data_size);
    const auto size = static_cast<std::size_t>(out - header.data());
    return std::fwrite(header.data(), 1, size, file) == size && std::ferror(file) == 0;
}

struct WaveData
{
    PortSpec spec;
    std::uint64_t offset = 0;
    std::size_t size = 0;
    std::size_t frame_bytes = 0;
};

std::uint16_t read_u16(const unsigned char *p) noexcept
{
    return static_cast<std::uint16_t>(p[0] | (p[1] << 8));
}

std::uint32_t read_u32(const unsigned char *p) noexcept
{
    return read_u16(p) | (static_cast<std::uint32_t>(read_u16(p + 2)) << 16);
}

bool read_bytes(std::FILE *file, unsigned char *bytes, std::size_t size) noexcept
{
    return std::fread(bytes, 1, size, file) == size;
}

SampleFormat wav_format(std::uint16_t tag, std::uint16_t bits) noexcept
{
    if (tag == float_tag && (bits == 32 || bits == 64))
        return SampleFormat::F32LE;
    if (tag == pcm_tag)
    {
        switch (bits)
        {
        case 8: return SampleFormat::F32LE;
        case 16: return SampleFormat::S16LE;
        case 24: return SampleFormat::S24_3LE;
        case 32: return SampleFormat::S32LE;
        }
    }
    return {};
}

bool parse_format(std::FILE *file, std::uint32_t size, WaveData &data)
{
    std::array<unsigned char, 40> fmt{};
    const auto read_size = std::min<std::uint32_t>(size, fmt.size());
    if (read_size < 16 || !read_bytes(file, fmt.data(), read_size))
        return false;
    auto tag = read_u16(fmt.data());
    if (tag == 0xfffe) // WAVE_FORMAT_EXTENSIBLE
    {
        constexpr unsigned char subtype_suffix[] = {0, 0, 0, 0, 0x10, 0, 0x80, 0, 0, 0xaa, 0, 0x38, 0x9b, 0x71};
        const auto extension_size = read_u16(fmt.data() + 16);
        if (read_size < fmt.size() || extension_size < 22 || extension_size > size - 18 ||
            std::memcmp(fmt.data() + 26, subtype_suffix, sizeof(subtype_suffix)))
            return false;
        tag = read_u16(fmt.data() + 24);
    }
    const auto bits = read_u16(fmt.data() + 14);
    data.spec = {static_cast<SampleRate>(read_u32(fmt.data() + 4)), read_u16(fmt.data() + 2), wav_format(tag, bits)};
    data.frame_bytes = read_u16(fmt.data() + 12);
    return data.spec.format != SampleFormat::F32P && data.spec.valid() &&
           data.frame_bytes == data.spec.channels * (bits / 8);
}

RetCode parse_wav(std::FILE *file, WaveData &data)
{
    unsigned char header[12];
    if (!read_bytes(file, header, sizeof(header)) || std::memcmp(header, "RIFF", 4) ||
        std::memcmp(header + 8, "WAVE", 4))
        return ErrorCode::FormatMismatch;
    const auto limit = std::int64_t{8} + read_u32(header + 4);
    if (limit < 12 || !seek_bytes(file, 0, SEEK_END) || tell_bytes(file) < limit)
        return ErrorCode::IoFailed;

    bool have_format = false;
    for (std::int64_t pos = 12; pos + 8 <= limit; )
    {
        unsigned char chunk[8];
        if (!seek_bytes(file, pos, SEEK_SET) || !read_bytes(file, chunk, sizeof(chunk)))
            return ErrorCode::IoFailed;
        const auto size = read_u32(chunk + 4);
        const auto payload = pos + 8;
        pos = payload + size + (size & 1);
        if (pos > limit)
            return ErrorCode::IoFailed;
        if (!have_format && !std::memcmp(chunk, "fmt ", 4))
        {
            if (!parse_format(file, size, data))
                return ErrorCode::FormatMismatch;
            have_format = true;
        }
        else if (!data.offset && !std::memcmp(chunk, "data", 4))
        {
            data.offset = payload;
            data.size = size;
        }
        if (have_format && data.offset)
        {
            if (data.size % data.frame_bytes)
                return ErrorCode::FormatMismatch;
            return seek_bytes(file, data.offset, SEEK_SET) ? RetCode{} : RetCode{ErrorCode::IoFailed};
        }
    }
    return ErrorCode::FormatMismatch;
}

float read_f64(const unsigned char *bytes) noexcept
{
    static_assert(sizeof(double) == 8 && std::numeric_limits<double>::is_iec559, "WAV requires IEEE binary64");
    const auto bits = std::uint64_t{read_u32(bytes)} | (std::uint64_t{read_u32(bytes + 4)} << 32);
    double sample;
    std::memcpy(&sample, &bits, sizeof(sample));
    if (std::abs(sample) > std::numeric_limits<float>::max())
        return std::signbit(sample) ? -std::numeric_limits<float>::infinity() : std::numeric_limits<float>::infinity();
    return static_cast<float>(sample);
}

void convert_to_f32le(const unsigned char *src, std::size_t sample_bytes, std::size_t samples,
                      unsigned char *dst) noexcept
{
    for (std::size_t i = 0; i < samples; ++i, src += sample_bytes)
    {
        const auto sample = sample_bytes == 1 ? (static_cast<int>(*src) - 128) / 128.0f : read_f64(src);
        std::uint32_t bits;
        std::memcpy(&bits, &sample, sizeof(bits));
        for (unsigned shift = 0; shift < 32; shift += 8)
            *dst++ = static_cast<unsigned char>(bits >> shift);
    }
}

} // namespace

WavFile::~WavFile()
{
    close();
}

RetCode WavFile::open_read(const std::string &path) noexcept
{
    if (file_ && writing_)
        return ErrorCode::Busy;
    const auto close_input = [](std::FILE *file) noexcept { std::fclose(file); };
    std::unique_ptr<std::FILE, decltype(close_input)> file(open_file(path.c_str(), "rb"), close_input);
    if (!file)
        return ErrorCode::IoFailed;
    WaveData data;
    const auto parsed = parse_wav(file.get(), data);
    if (!parsed)
        return parsed;
    const auto closed = close();
    if (!closed)
        return closed;

    file_ = file.release();
    spec_ = data.spec;
    data_offset_ = data.offset;
    file_frame_bytes_ = data.frame_bytes;
    frame_count_ = data.size / data.frame_bytes;
    return {};
}

bool WavFile::supports_write_format(SampleFormat format) noexcept
{
    return format == SampleFormat::S16LE || format == SampleFormat::S24_3LE ||
           format == SampleFormat::S32LE || format == SampleFormat::F32LE;
}

Result<std::size_t> WavFile::max_write_frames(PortSpec spec) noexcept
{
    const auto format = spec.format;
    if (!supports_write_format(format))
        return ErrorCode::FormatMismatch;
    if (!spec.valid())
        return ErrorCode::InvalidArg;
    const auto sample_width = sample_bytes(format);
    const auto rate = static_cast<std::uint32_t>(spec.sample_rate);
    constexpr auto max_bytes = std::numeric_limits<std::uint32_t>::max();
    if (spec.channels > std::numeric_limits<std::uint16_t>::max() / sample_width ||
        spec.channels > max_bytes / sample_width / rate)
        return ErrorCode::TooLarge;

    // Leave room for the RIFF header and the pad byte of an odd data chunk.
    const auto limit = (max_bytes - (wav_header_size(format) - 8)) & ~std::uint32_t{1};
    return limit / (spec.channels * sample_width);
}

RetCode WavFile::open_write(const std::string &path, PortSpec spec, WriteMode mode) noexcept
{
    if (file_)
        return ErrorCode::Busy;
    const auto limit = max_write_frames(spec);
    if (!limit)
        return limit.ret_code();
    const auto exclusive = mode == WriteMode::Exclusive;
    auto *file = open_file(path.c_str(), exclusive ? "wbx" : "wb");
    if (!file)
        return exclusive && errno == EEXIST ? ErrorCode::Busy : ErrorCode::IoFailed;

    if (!write_header(file, spec, 0) || std::fflush(file) != 0)
    {
        std::fclose(file);
        return ErrorCode::IoFailed;
    }

    file_ = file;
    writing_ = true;
    spec_ = spec;
    data_offset_ = wav_header_size(spec.format);
    file_frame_bytes_ = spec.channels * sample_bytes(spec.format);
    write_limit_ = limit.value();
    return {};
}

RetCode WavFile::close() noexcept
{
    if (!file_)
        return {};
    const auto prior_ok = std::ferror(file_) == 0;
    bool finalized = true;
    if (writing_ && frame_count_)
    {
        const auto size = static_cast<std::uint32_t>(frame_count_ * file_frame_bytes_);
        std::clearerr(file_);
        if (size & 1)
            finalized = seek_bytes(file_, data_offset_ + size, SEEK_SET) && std::fputc(0, file_) != EOF;
        finalized = finalized && seek_bytes(file_, 0, SEEK_SET) && write_header(file_, spec_, size);
    }
    const auto closed = std::fclose(file_);
    file_ = nullptr;
    writing_ = false;
    spec_ = {};
    frame_count_ = position_ = 0;
    return prior_ok && finalized && closed == 0 ? RetCode{} : RetCode{ErrorCode::IoFailed};
}

RetCode WavFile::flush() noexcept
{
    if (!writing_)
        return ErrorCode::NotReady;
    return std::fflush(file_) != 0 || std::ferror(file_) ? RetCode{ErrorCode::IoFailed} : RetCode{};
}

RetCode WavFile::status() const noexcept
{
    if (!file_)
        return ErrorCode::NotReady;
    return std::ferror(file_) ? RetCode{ErrorCode::IoFailed} : RetCode{};
}

RetCode WavFile::seek(std::size_t frame) noexcept
{
    if (!file_)
        return ErrorCode::NotReady;
    if (frame > frame_count_)
        return ErrorCode::InvalidArg;
    // Allow readers to retry while preserving any write error for close().
    if (!writing_)
        std::clearerr(file_);
    if (!seek_bytes(file_, data_offset_ + frame * file_frame_bytes_, SEEK_SET))
        return ErrorCode::IoFailed;
    position_ = frame;
    return {};
}

Result<std::size_t> WavFile::read(OBBlock output) noexcept
{
    if (!file_ || writing_)
        return ErrorCode::NotReady;
    if (output.spec() != spec_)
        return ErrorCode::FormatMismatch;
    const auto frames = std::min(output.frames(), frame_count_ - position_);
    if (!frames)
        return frames;

    auto *dst = output.byte_view().data();
    if (file_frame_bytes_ == spec_.channels * sample_bytes(spec_.format))
    {
        if (!read_bytes(file_, dst, frames * file_frame_bytes_))
            return ErrorCode::IoFailed;
    }
    else
    {
        // Convert extra on-disk formats in bounded groups of interleaved samples.
        std::array<unsigned char, 4096> scratch;
        const auto sample_width = file_frame_bytes_ / spec_.channels;
        auto samples = frames * spec_.channels;
        while (samples)
        {
            const auto count = std::min(samples, scratch.size() / sample_width);
            if (!read_bytes(file_, scratch.data(), count * sample_width))
                return ErrorCode::IoFailed;
            convert_to_f32le(scratch.data(), sample_width, count, dst);
            samples -= count;
            dst += count * sizeof(float);
        }
    }
    position_ += frames;
    return frames;
}

RetCode WavFile::write(IBBlock input) noexcept
{
    if (!writing_)
        return ErrorCode::NotReady;
    if (input.spec() != spec_)
        return ErrorCode::FormatMismatch;
    if (std::ferror(file_))
        return ErrorCode::IoFailed;
    if (input.frames() > write_limit_ - position_)
        return ErrorCode::TooLarge;
    if (!input.frames())
        return {};

    if (std::fwrite(input.byte_view().data(), file_frame_bytes_, input.frames(), file_) != input.frames() ||
        std::ferror(file_))
        return ErrorCode::IoFailed;
    position_ += input.frames();
    frame_count_ = std::max(frame_count_, position_);
    return {};
}

#ifndef AEREBORN_BACKEND_WAV_FILE_H
#define AEREBORN_BACKEND_WAV_FILE_H

#include "core/types.h"
#include <cstdio>
#include <string>

namespace aereborn
{

/// @brief Read or write one RIFF/WAVE file using frame offsets.
/// @note Serialize access. Unsigned 8-bit PCM and 64-bit float are read as F32LE.
class WavFile
{
  public:
    enum class WriteMode { Truncate, Exclusive };

    WavFile() = default;
    ~WavFile();
    WavFile(const WavFile &) = delete;
    WavFile &operator=(const WavFile &) = delete;

    /// @brief Open a WAV file at frame zero. Invalid input leaves the current reader usable.
    RetCode open_read(const std::string &path) noexcept;
    /// @brief Open a file for writing. Exclusive returns Busy for an existing path.
    /// @pre Close the current file before opening an output.
    RetCode open_write(const std::string &path, PortSpec spec, WriteMode mode) noexcept;
    /// @brief Close the file and finalize the header when writing.
    RetCode close() noexcept;
    /// @brief Flush buffered output to the operating system and report any write error.
    RetCode flush() noexcept;
    /// @brief Report an I/O error or NotReady if there is no open file.
    RetCode status() const noexcept;
    /// @brief Report whether the sample format is supported for RIFF/WAVE output.
    static bool supports_write_format(SampleFormat format) noexcept;
    /// @brief Return the RIFF frame limit for a supported output specification.
    static Result<std::size_t> max_write_frames(PortSpec spec) noexcept;

    /// @brief Return the interleaved PCM specification used for I/O.
    PortSpec spec() const noexcept { return spec_; }
    /// @brief Return the number of frames in the open file.
    std::size_t frame_count() const noexcept { return frame_count_; }
    /// @brief Return the zero-based index of the next frame to read or write.
    std::size_t tell() const noexcept { return position_; }
    /// @brief Seek to an existing frame or to the end of the data.
    RetCode seek(std::size_t frame) noexcept;
    /// @brief Read up to output.frames() frames, returning zero at EOF.
    Result<std::size_t> read(OBBlock output) noexcept;
    /// @brief Write an interleaved block at the current frame position.
    RetCode write(IBBlock input) noexcept;

  private:
    std::FILE *file_ = nullptr;
    bool writing_ = false;
    PortSpec spec_;
    std::uint64_t data_offset_ = 0;
    std::size_t file_frame_bytes_ = 0;
    std::size_t frame_count_ = 0;
    std::size_t position_ = 0;
    std::size_t write_limit_ = 0;
};

} // namespace aereborn

#endif
