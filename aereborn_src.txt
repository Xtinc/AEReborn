
===== AudioEngine_Outline.md =====
# AEReborn：音频引擎框架草案

项目使用 C++14。Engine 由内置软件时钟线程推进。设备、文件和网络后端沿用本稿定义的运行边界。
命名空间统一为 `aereborn`。命名规则见 [编程约束](CODING_GUIDELINES.md#1-命名)。
图处理和虚拟 PCM 使用同一套渲染逻辑。API、运行约定和构建方法见第 7 节。

## 1. 参考与取舍

下面区分成熟引擎已有的设计，以及本项目据此作出的选择。参考设计思路，不引入这些引擎作为依赖。

| 官方参考 | 可借鉴的设计 | 本项目的选择 |
| --- | --- | --- |
| [JUCE AudioProcessorGraph](https://docs.juce.com/master/classjuce_1_1AudioProcessorGraph.html) | 处理器组成节点图，通过通道连接；提供图重建机制 | 统一 Node/Port/Connection，将图描述编译为执行计划 |
| [JACK 实时处理回调](https://jackaudio.org/api/group__ClientCallbacks.html) | 处理回调禁止内存分配及可能阻塞的 I/O、锁和等待 | 音频执行路径只处理已准备的数据，外部工作通过有界队列交换 |
| [PipeWire 图运行](https://docs.pipewire.org/devel/page_running.html)、[调度](https://docs.pipewire.org/page_scheduling.html)、[时钟](https://docs.pipewire.org/page_man_pipewire-props_7.html) | 调度组选择 driver；配置与数据处理分离；区分设备时钟并适配 | 每个 Engine 由一条软件时钟线程驱动，设备通过边界适配 |
| [FMOD 混音与连接](https://www.fmod.com/docs/2.04/api/mixing-and-routing-in-the-core-api.html)、[DSPConnection](https://www.fmod.com/docs/2.04/api/core-api-dspconnection.html) | 总线分组、子混音、效果处理；连接持有增益和声道矩阵 | Connection 只读共享同规格端口的数据；Mixer 混音，Matrix 处理声道矩阵与增益，Convert 转换格式与采样率 |

第一版不做多进程共享图、节点并行调度、插件宿主或完整 DAW 自动化系统。先实现能运行、能恢复、能验证的单进程引擎。

## 2. 核心概念与节点实现

Engine 只处理 Node、Port、Connection 三个核心概念。它拥有节点和连接，校验图、准备缓冲并按依赖顺序执行节点；不需要识别节点的具体业务角色。

```text
Node A 的 OPort ── Connection ──> Node B 的 IPort
```

| 对象 | 定位 |
| --- | --- |
| Node | 具有输入/输出端口的执行单元 |
| Port | 节点上的多声道音频入口或出口，固定声明采样率、声道数和格式 |
| Connection | 将上游输出零拷贝地借给同规格的下游输入，只读 |

`IPort` 和 `OPort` 用节点 ID 和从零开始的下标定位端口。`PortSpec` 固定声明采样率、声道数和 `SampleFormat`。连接两端必须完全一致，否则返回 `FormatMismatch`；需要转换时显式插入 Convert。一个输入端口只能接一个来源，重复占用返回 `InputConnected`，多路求和使用 Mixer 的不同输入。没有连接的输入得到该格式的零值静音。
一个 Port 表示一组声道，声道间的选择、复制和合并由 Matrix 表达。
`NodeId` 标识图中的节点，替换节点实例时 ID 继续有效。`ConnId` 标识一次连接，重新连接相同端口会生成新的 ID。原型采用进程内不复用的唯一 ID。Node 不持有其他 Node 的共享所有权，也不各自维护连接列表或调度循环。

Source、Processor、Mixer、Sink 是具体节点的用途。`plugins/` 中的 Capture、Playback 是设备缓冲交接节点，Convert 是格式与采样率转换节点。Mixer、Matrix 和 Tone 是只支持 planar float 的普通插件；算法节点可以声明自己需要的 PCM 格式。

| 用途 | 职责 | 当前实现 |
| --- | --- | --- |
| Source | 向图提供音频 | `Capture`、`Tone` |
| Processor | 处理输入并产生输出 | `Convert`、`Matrix`、用户算法节点 |
| Mixer | 显式合并多个相同规格的输入 | `Mixer` |
| Sink | 消费音频并交给设备 | `Playback` |

PCM 适配器和固定端口数量的自定义节点通常继承 `NodeT<I, O>`，由它保存端口描述。具体节点实现 `prepare(BlockPeriod)`，按周期准备资源，无需准备资源时直接返回成功。节点在 `process()` 中从上下文读取周期，数据规格来自自身端口。端口数量由运行时决定的节点可以直接继承 `Node`，通过 `inputs()/outputs()` 提供固定的端口描述。引擎持有节点期间借用这些描述，节点负责保持描述及其存储有效。
后续设备、文件、网络、滤波等节点遵循同一边界。Bus 表示 Mixer 与效果节点构成的应用层总线，不是新的核心基类。

### 从输出创建输入：直接复用端口

任何 `OPort` 都能继续连接到其他节点。Bus 可提供 PreEffects、PostEffects、PostFader 等命名输出位置，第一版先提供最终输出。
需要取得总线音频时，从相应输出连接普通 Sink；需要其他数据规格时连接 Convert，再由算法节点或 Playback 消费结果。图核心不提供独立的端口订阅机制。
编译器保证一个节点每个渲染块只执行一次，同一输出供多个下游只读使用；需要修改数据的下游使用自己的工作缓冲。

这支持“输出作为另一个输入”，并且不依赖物理设备是否在线。系统全局回环录音则作为独立 CaptureSource 能力接入。
第一版拒绝所有图内反馈环，校验同时覆盖音频与侧链依赖。

## 3. 引擎骨架

core 提供 Node、端口描述、只读/可写块视图和 Engine。plugins 提供按功能命名的 Convert、Mixer、Matrix、Capture、Playback、Tone。

Engine 持有编辑图和渲染计划。`commit()` 按依赖排序，从无输出的 Sink 遍历可达节点；未连接到 Sink 的分支不执行。每个可达节点每周期只执行一次。

引擎按各端口的最大周期帧数分配两块连续缓冲池，分别存放 F32P 的 float 对象和交错 PCM 的字节。连接输入只读借用上游输出；未连接的输入按存储类型共享缓冲池开头的只读零区间。所有缓冲和块视图由 Engine 管理。

`ProcessContext` 提供 `block_period`、`tick_position`、`inputs` 和 `outputs`。`IPortBlock` 只读，`OPortBlock` 可写，两者都携带缓冲地址、端口规格和本周期实际帧数。`byte_view()` 按原格式借用字节，适用于所有格式。`f32p_view()` 用于 F32P 端口，返回 `IFBlock` 或 `OFBlock`，声道步长为本周期的实际帧数。`FloatBlock` 也可借用插件工作区的分声道浮点样本，此时声道步长可以大于实际帧数。端口提供的视图只在 `process()` 调用内有效，节点必须写满自己的输出。

渲染计划用两个连续数组保存已绑定的输入、输出视图，每个节点按端口范围访问。包含分数帧端口的计划在每个 tick 更新实际帧数，全整数帧计划使用预先绑定的帧数。缓冲和节点引用由计划统一持有。

控制侧 `commit()` 完成分配和节点准备。运行时，时钟线程在块边界从原子槽接管计划，控制侧等待接管后同步释放旧计划及仅由旧计划持有的节点。沿用的节点实例保留 DSP 状态。

## 4. 执行与时钟

每个运行中的 Engine 由一条内置软件时钟线程串行执行渲染。设备通过边界适配器交换数据。当前 Capture / Playback 每次交接一个基础周期的数据，后端负责将实际硬件收发整理为这个粒度。跨周期拼拆包留待后续实现。

Engine(BlockPeriod) 固定推进周期。调用方可用 block_period() 查询周期，节点可从 ProcessContext 读取周期。tick_position() 返回已完成的周期数，停止后重启继续计数，reset() 归零。每个 process() 收到本周期开始时的 tick_position。

端口只支持 `SampleRate` 枚举中的采样率，单位为 Hz。当前为 8000、11025、16000、22050、24000、32000、44100、48000、88200 和 96000。SampleFormat::F32P 是原生 planar float32；S16LE、S24_3LE、S24LE、S32LE、F32LE 是交错小端 PCM。连接匹配包含采样率、声道数、样本格式及其布局，不做自动协商或隐式转换。

每个端口按累计时间的向上取整差值计算本周期实际帧数。44.1 kHz / 5 ms 为 221、220 帧交替，11.025 kHz 等规格也不逐周期独立取整；PortSpec::max_frames() 用于容量，frames() 和 frame_position() 用于实际块与该端口的样本时间。不同采样率端口仍由同一个基础周期驱动。Convert 将分数相位对齐到共享 tick，运行中新增或替换节点不会另起采样时钟。

内置时钟用 steady_clock 和 condition_variable::wait_until 调度，包括空图在内的每个 tick 都执行一个完整周期。延误时跳过过期的唤醒期限，逻辑时间按实际执行的 tick 前进。

从设备与引擎时钟不一致时，在边界做缓冲与自适应重采样。即使标称采样率相同，也不能默认两个设备共享时钟。

### 控制与实时处理的边界

应用负责串行执行 Engine 的控制操作。应用可以用 Asio strand 承载控制命令，也可以独立使用 Asio 协调网络 I/O、设备事件和恢复定时。
设备打开/关闭、文件访问、编解码和应用回调都在非渲染路径完成。设备必要的实时缓冲交付由平台后端封装。
音频路径只读写已准备的缓冲，避免堆操作、锁等待、日志和应用回调。

```text
应用串行控制执行器 ──> 计划/参数 ──> 渲染路径
从设备 / 网络 / 文件 ──> 有界队列 ──> 音频入口节点
音频出口节点 ──> 有界队列 ──> 从设备 / 网络 / 文件
音频出口节点 ──> 有界队列 ──> 用户回调执行器
```

队列预先明确单/多生产者归属、容量和满队列行为。活跃数据流不允许无限堆积；慢回调只影响自身输出分支，录音写入跟不上时由后端报告数据缺口。
第 3 阶段在插件层实现可复用的有界无锁 SPSC 队列和字节流环形缓冲，供设备、推入和回调后端共用。
Engine 停止会等待图处理退出。后端负责等待自己的 I/O 与应用回调退出；不能仅取消定时器就释放仍在使用的对象。

## 5. 外部资源与恢复

逻辑端点长期存在，物理句柄归 DeviceSession。DeviceService 分开维护设备清单、选择策略与运行会话。
选择可以是固定设备、跟随系统默认、优先某类设备；不在收到任意插入事件后立即抢占当前设备。
设备身份使用平台稳定标识及匹配规则，不依赖枚举序号永久不变。

```text
逻辑意图：Running / Paused / Stopped
资源状态：WaitingDevice -> Opening -> Ready -> Recovering / Failed
```

两组状态分别维护：恢复完成仍要服从用户当前意图。
掉线期间保留图、音量和连接；缺失采集数据补静音并由后端记录缺口，输出设备不可用时丢弃该设备数据，总线及其他下游继续处理。
可就地恢复的欠载由后端处理；需重开、等待设备、不可恢复的配置错误由统一恢复策略区分。
重试带退避和取消，主动定期重开也是同一策略的选项。会话代际编号屏蔽过期打开结果与旧设备数据。

同一设备的兼容逻辑端点共享 DeviceSession。播放侧明确汇入该设备的最终混音节点，再交给唯一设备写入者；独占或格式冲突明确报错。
设备协商格式与逻辑音频格式分离，恢复不改变应用看到的端口布局；适配不了时报告端点失败。

网络与文件复用相同入口/出口节点机制：

- NetworkSource：会话识别、乱序整理、按播放期限解码/FEC/PLC，再交付音频。NetworkSink：排队、编码、发送。先 PCM，后 Opus；协议独立版本化。
- FileSource：工作线程预读，独立 PlaybackHandle 管理循环、暂停和停止。FileSink：排队写入，支持分段保存。
- PushSource：应用显式推入带格式、帧时间和连续性信息的音频，接口报告接收数量或队列满。
- 回调输出：普通 Sink 接收图内 float，或由 Convert 转换为所需 PCM。后端通过有界队列异步调用用户函数，负责数据所有权、缺口报告和停止屏障。

## 6. 混音策略归属

Mixer 显式求和，Matrix 负责声道映射与增益。两者都只支持 F32P，采样率由构造参数固定，并不要求整张图使用同一采样率。Mixer 每个输入与输出的规格相同；Matrix 的输入、输出声道数可不同，采样率保持一致。

Matrix 的行是目标声道，列是源声道，系数可用于选取、复制、合并和相位反转。全局增益与矩阵在同一遍采样处理中完成。Mixer 对每个输入独立静音。增益和静音在下一个有帧的处理块读取，并在该块内线性过渡到目标值，零增益或零系数跳过源样本，避免未使用的 NaN / Inf 污染输出。

总线可以由 Mixer、Matrix 和效果节点组成，不增加核心基类。Voice、Music、Alert 等抑制策略由后续插件产生增益目标，Engine 不识别角色或策略。

## 7. 时钟运行 API

应用创建 Engine，加入节点、连接端口、调用 `commit()`，再用 `start()` 启动时钟。示例演示 Tone → Mixer → Matrix → 电平 Sink，以及运行中修改 Matrix 增益。[时钟运行示例](examples/clocked_graph.cpp)

### 固定能力与连接检查

插件通过不可变的 inputs()/outputs() 声明实际端口规格。Mixer、Matrix、Tone 构造函数只生成 F32P 端口；普通插件直接编写 float 算法。特殊算法声明其支持的固定 PCM 规格，Engine 在 connect() 时检查两端，准备阶段验证时序和资源。本版不增加动态能力列表或格式协商协议。

每个输入最多一个来源；同一输出可供多个下游只读使用。需要多路混音必须显式创建 Mixer 的多个输入。连接不包含增益、静音或矩阵，也不增加转换器。

下面的链路可以直接用 connect() 表达：

~~~text
Tone / BUS（48k F32P）
    → Convert（48k F32P → 16k S16LE）
    → 算法（固定 16k S16LE）
    → Convert（16k S16LE → 48k F32P）
    → 其他节点 / Playback
~~~

### 插件接口

| 插件 | 端口 | 配置与职责 |
| --- | --- | --- |
| Convert(input_spec, output_spec) | (1,1) | 支持上述全部格式的转换和固定比例重采样，要求两端声道数相同 |
| Mixer(rate, channels, inputs) | (N,1) | 相同 F32P 规格显式求和；set_muted(index, bool) 控制单个输入 |
| Matrix(rate, input_channels, output_channels, coefficients, gain) | (1,1) | F32P 声道映射与增益；行对应输出、列对应输入，系数固定；set_gain() 更新增益 |
| Matrix(rate, channels, gain) | (1,1) | 使用恒等声道映射，仅控制增益 |
| Capture(spec) | (0,1) | 将后端绑定的一周期字节复制进 Engine 输出缓冲；缺少数据时输出静音 |
| Playback(spec) | (1,0) | 将输入复制进后端绑定的一周期缓冲；无缓冲时丢弃数据 |
| Tone(rate, channels, frequency, amplitude) | (0,1) | 按端口样本时间生成 F32P 正弦波 |

内置插件在构造时校验固定端口和参数，规格错误抛出 `std::invalid_argument`，静态配置超出容量抛出 `std::length_error`。`Engine::commit()` 先校验周期，再开始构建计划。节点的 `prepare(BlockPeriod)` 接收已校验的周期，检查自身的平台和资源条件，并准备运行状态及工作区。应用也可通过 `Engine::add_node()` 加入自定义节点，引擎继续校验端口声明。

相同规格的 Convert 按字节直通，无需转换状态或工作区；同采样率 PCM → F32P 直接写入 Engine 输出，不经中间 float 缓冲。其余路径只准备实际转换需要的工作区。

需要 PCM 声道映射时，先 Convert 到 F32P，经过 Matrix，再按需要 Convert 回 PCM。Convert 不负责声道矩阵，Capture / Playback 不负责转换。

### 运行控制与缓冲交接

- 图编辑修改草稿。`commit()` 返回 `RetCode`。停机时新计划立即生效。运行时，成功返回表示时钟已在块边界接管新计划，旧计划已由调用线程释放。首个新块的处理可能仍在进行。草稿未改动时直接返回成功，准备失败保留当前计划。
- replace_node() 要求输入、输出的数量及完整规格相同，否则返回 FormatMismatch。改变设备格式时，显式替换相应设备节点与 Convert 并重建连接，可用一次 `commit()` 共同提交；稳定的下游 float 节点继续运行。
- set_paused() 通过计划移除或恢复节点及相关连接，未改动实例保留状态。暂停导致某个输入失去来源时，该输入得到静音。需要平滑暂停时，先淡出 Matrix 增益或静音 Mixer 输入，再提交暂停。
- `Matrix::set_gain()` 和 `Mixer::set_muted()` 使用原子目标，可与 `process()` 并发调用。处理块读取最新目标。控制侧从 `Engine::node()` 借用草稿节点指针，须在节点被移除或替换前结束使用，最长有效期到 Engine 析构。
- Capture / Playback 在节点准备完成后接受 bind(bytes, tick_position)，字节数必须恰好等于该 tick 的端口帧数乘声道数和样本宽度。已有绑定时返回 BufferFull；绑定和 reset 与处理串行，借用内存在指定 tick 结束前保持有效。未来 tick 的绑定保留到该 tick，过期数据不再输出。重新准备不同周期时释放已有绑定。
- 控制侧可在启动之前绑定单周期缓冲。运行时的跨线程供给由后端队列负责。
- `stop()` 唤醒时钟并等待在途处理退出。`reset()` 在停机时归零 tick 并重置节点。
- 调用方在控制侧串行执行控制接口和析构。同一 Engine 的时钟线程同步调用控制接口时返回 `Busy`。节点需要请求修改引擎时，将操作延后投递到应用的串行执行器并直接返回，例如使用 `asio::post`。实例有效期间可并发读取 `block_period()` 与 `tick_position()`。
- 处理路径尽量避免锁等待，禁止堆分配、释放和调用普通应用回调。异步使用块数据必须在 process() 返回前复制到后端自有缓冲。

### 构建与验证

项目使用 C++14，core 通过 CMake 链接 Threads::Threads。应用链接 aereborn::plugins，单独使用核心可链接 aereborn::core。

测试按 core、runtime、routing、convert、resampling、mix、device、tone、allocation、example 分组。引擎测试使用内置时钟，通过测试节点在块边界与测试控制侧同步。混音、格式转换和重采样使用独立字节或数值参照；完整算法链验证不同格式节点直接连线。覆盖分数帧、格式拒绝、禁止隐式混音、只读共享、参数斜坡、计划切换、停止屏障、失败恢复和实时路径无堆操作。

## 8. 实现顺序

1. **离线图核心**：Node、Port、Connection、音频块及 Engine 的准备与执行。用插件节点验证多对多、处理器串联、总线互连、输出分发、环路拒绝。
2. **运行内核**包括内置软件时钟、块边界计划切换、同步提交、插件参数、显式 Mixer/Matrix 和停止屏障。验证调音量时复用图计划，修改连接时保留未变节点的状态。
3. **一个平台的设备闭环**包括多设备边界适配、DeviceSession、热插拔与恢复。验证通过缓冲交付音频，拔插期间其他连接继续处理，再接入另一个平台。
4. **文件、推入和混音策略**：预读/录制、PlaybackHandle、PushSource、DSP 链、ducking。验证多实例、循环、过载报告和增益包络。
5. **网络**：先 PCM，再 Opus、乱序/抖动缓冲与丢包恢复；验证本地与远程源进入同一 Bus，断网后有界退化并恢复。

各阶段复用同一张图与同一套节点执行机制。

第一步的验收用例包括 `core.audio_block_layout`、`core.commit_retry`、`routing.explicit_mix_and_fanout`、`routing.algorithm_chain`、`routing.silence_and_pruning` 和 `core.feedback_rejection`。路由走实际的 Convert、Mixer 和 Matrix，算法由声明固定 PCM 格式的测试节点提供。

第二步的验收覆盖 `runtime` 用例、`allocation.render_uses_prepared_buffers` 和 `example.clocked_graph`。

# AEReborn 编程约束

## 1. 命名

**名称用能清楚表达用途的最短写法。** 缩写应当能从组合词或局部上下文直接读懂。需要查注释才能知道名称指什么时，用更明确的词。

| 场景 | 写法 |
| --- | --- |
| 连接 | 单独指一个连接时用 `connection`。组合词可用 `conn`，如 `conn_id`、`conn_count`。 |
| 端口 | 成对的类型使用等长的 `I` / `O` 方向前缀和相同的后缀，例如 `IPort` / `OPort`、`IPortBlock` / `OPortBlock`。 |
| 声道 | 声道循环的索引用 `ch`。声明端口时用 `channels` 表示声道数，用 `input_channels`、`output_channels` 区分方向。 |
| 采样率 | 配置和公开接口用 `sample_rate`。重采样内部可以用常见的 DSP 记号 `src_fs`、`dst_fs`。 |
| 帧、采样点、字节 | 根据单位使用 `frames`、`samples`、`bytes`。含义可能混淆时，用 `frame_offset`、`byte_offset` 或 `period_ms` 写明单位。 |

- **成对的变量保持对称。** 用同一组方向词、相同的后缀和缩写程度，例如 `src_fs` / `dst_fs`、`input_channels` / `output_channels`、`from` / `to`。同一个值在相邻函数中沿用同一术语。
- **成对的类型和接口按长度和结构对齐。** 使用等长的区分词，其余词的位置、写法和后缀一致。例如 `NodeId` / `ConnId` 共用 `Id`，`byte_view()` / `f32p_view()` 共用 `_view`。
- **名称反映实际的访问方式或数据格式。** `byte_view()` 表示按字节访问，`f32p_view()` 明确适用的样本格式。
- **名字反映变量的用途。** `conn_count` 是数量，`conn_index` 是索引。短循环可以用 `i` 和 `ch`，跨多个步骤使用的变量写明角色，例如 `frame_offset`。
- **沿用项目的拼写风格。** 局部变量、参数和函数用 `snake_case`，私有成员变量在末尾加 `_`，如 `frame_position_`。类型和枚举值通常用 `PascalCase`，例如 `ConnId`、`ErrorCode::InvalidPort`。PCM 枚举沿用 `S16LE`、`S24_3LE`、`F32LE` 这样的格式名。

## 2. 类型与接口

- 优先复用现有类型。只有在需要表达独立的含义、约束、所有权或生命周期时才引入新类型。单纯的数量和索引使用现有整数类型。
- 一项规格只保留一个定义来源。采样率和 PCM 格式由 `core/types.h` 提供，样本位深和存储字节数从 `SampleFormat` 推导。端口固定声明采样率、声道数和格式，Engine 只持有推进周期。普通 DSP 插件声明 F32P，特殊模块声明其实际格式，转换由 Convert 完成。
- 函数名和参数顺序应能直接说明调用方向。底层函数、辅助记录和临时状态放在使用它们的实现范围内。对外接口集中表达调用方需要配置、传递或查询的内容。
- 类及其公开接口在声明处使用 `///` 格式的 Doxygen 注释。用 `@brief` 说明职责，按需用 `@param`、`@return`、`@pre` 和 `@note` 记录参数、结果、前置条件及调用约定。涉及借用数据或跨线程调用时，写明有效期和线程约束。
- 保持调用路径直接。抽取能消除重复、集中维护同一约束的逻辑，优先选用普通函数和直接的成员状态。模板用于确有编译期差异的场景，例如固定端口数量。采样率和处理周期作为运行时规格传递。

## 3. 错误处理

- 参数、状态和容量校验等可预期的操作失败通过 `RetCode` 返回，需要同时返回结果时用 `Result<T>`。检查成功后再读 `value()`。
- 标准库的分配异常和自定义节点在构造或准备时抛出的异常交由调用方处理。构造函数可以抛异常来维护对象不变量。会分配资源或调用可抛异常代码的控制侧接口允许异常传播，实时 `process()` 保持 `noexcept`。
- 在建立约束的入口做校验。连接时检查完整端口规格和输入占用，Matrix 构造时检查矩阵尺寸，绑定设备缓冲时检查长度与占用状态。处理路径直接使用已经校验和准备好的数据。
- 资源准备成功后再发布可用状态。失败时保留有效状态，使调用方可以重试。内部不变量可以用断言表达。

## 4. 音频处理

- 每次时钟触发推进一个固定的引擎周期。节点按自身端口规格写满输出块，连接只读借用上游输出，每个输入只接一个来源。多路混音由 Mixer 完成；Matrix 的行对应输出声道，列对应输入声道。
- 普通 DSP 使用按声道存放的 IEEE float32，PCM 算法使用明确声明的字节格式。Convert 统一承担格式和采样率转换，Matrix 承担声道映射与增益，设备节点只交接数据。同采样率的 float32 保持样本的位表示，只做复制和必要的布局、字节序调整。
- 在 `prepare()` 中分配缓冲并准备滤波等资源。把阻塞 I/O、日志和堆分配放在渲染路径之外，并尽量避免在渲染时等待锁。接口借用缓冲时，应写清谁持有缓冲以及它需要保持有效的时间。

## 5. 修改与验证

- 以业务契约为准，测试负责验证契约。业务接口和分支应有明确的实际调用需求。
- 使用 C++14。修改集中在受影响的接口和实现，沿用周围代码的风格。注释优先说明约束和原因。
- 沿实际调用入口验证改动。优先复用现有测试，在现有测试覆盖不到具体回归时补充用例。音频转换和图处理的边界用实际帧数、声道数和输出值验证。
- 路由测试使用 Tone 或测试源，经 Convert、Mixer、Matrix 和测试收端验证显式图；设备交接使用 Capture / Playback。格式转换使用独立的字节参照，混音和重采样使用独立的数值参照。测试按职责分组、每个场景独立注册到 CTest；共用准备和断言工具，不复制路由驱动逻辑。

项目的接口、处理流程和构建方法见 [AudioEngine_Outline.md](AudioEngine_Outline.md)。

/// @brief Borrow a contiguous range of elements.
/// @tparam T Type of the elements, including their const qualification.
/// @note Keep the backing storage valid while the view is in use.
template <class T> class View
{
  public:
    /// @brief Construct an empty view with a null data pointer.
    View() noexcept = default;

    /// @brief Borrow a contiguous range.
    /// @param data Address of the range.
    /// @param size Number of elements in the range.
    /// @pre A nonempty range contains at least size valid elements.
    View(T *data, std::size_t size) noexcept : data_(data), size_(size)
    {
    }

    /// @brief Borrow the same range with a compatible element type.
    /// @param other Source view.
    template <class U, typename std::enable_if<std::is_convertible<U (*)[], T (*)[]>::value, int>::type = 0>
    View(View<U> other) noexcept : data_(other.data()), size_(other.size())
    {
    }

    /// @brief Return the stored address of the range.
    T *data() const noexcept
    {
        return data_;
    }

    /// @brief Return the number of elements.
    std::size_t size() const noexcept
    {
        return size_;
    }

    /// @brief Check whether the range is empty.
    bool empty() const noexcept
    {
        return size_ == 0;
    }

    /// @brief Return the start of the range.
    T *begin() const noexcept
    {
        return data_;
    }

    /// @brief Return the end of the range. For an empty range it equals begin().
    T *end() const noexcept
    {
        return size_ == 0 ? data_ : data_ + size_;
    }

    /// @brief Access an element by its zero-based index.
    /// @pre index is less than size().
    T &operator[](std::size_t index) const noexcept
    {
        assert(index < size_);
        return data_[index];
    }

  private:
    T *data_ = nullptr;
    std::size_t size_ = 0;
};

static_assert(sizeof(float) == 4 && std::numeric_limits<float>::is_iec559, "Audio samples require IEEE float32");

/// @brief Borrow a block of planar float samples.
/// @tparam T Use float for writable samples or const float for read-only samples.
/// @note The channel stride may exceed the number of frames in the view.
template <class T> class FloatBlock
{
    static_assert(std::is_same<typename std::remove_const<T>::type, float>::value, "Audio samples must be float");
    template <class> friend class FloatBlock;

  public:
    /// @brief Construct an empty float block.
    FloatBlock() noexcept = default;

    /// @brief Borrow planar samples with an explicit channel stride.
    /// @param data Address of the first channel.
    /// @param channels Number of channels.
    /// @param frames Number of frames in the processing span.
    /// @param channel_stride Distance between channel starts, in samples.
    /// @pre frames is at most channel_stride. The owner keeps the exposed samples valid.
    FloatBlock(T *data, std::size_t channels, std::size_t frames, std::size_t channel_stride) noexcept
        : data_(data), channels_(channels), frames_(frames), channel_stride_(channel_stride)
    {
        assert(frames <= channel_stride);
    }

    /// @brief Borrow the same samples with compatible access.
    /// @param other Source block.
    template <class U, typename std::enable_if<std::is_convertible<U *, T *>::value, int>::type = 0>
    FloatBlock(FloatBlock<U> other) noexcept
        : data_(other.data_), channels_(other.channels_), frames_(other.frames_), channel_stride_(other.channel_stride_)
    {
    }

    /// @brief Return a pointer to the start of a channel.
    /// @param ch Zero-based channel index.
    /// @pre ch is less than channels().
    T *channel(std::size_t ch) const noexcept
    {
        assert(ch < channels_);
        return data_ + ch * channel_stride_;
    }

    /// @brief Return the number of channels.
    std::size_t channels() const noexcept
    {
        return channels_;
    }

    /// @brief Return the number of frames in the processing span.
    std::size_t frames() const noexcept
    {
        return frames_;
    }

    /// @brief Zero the processing span of each channel in a writable block.
    template <class U = T, typename std::enable_if<!std::is_const<U>::value, int>::type = 0> void clear() const noexcept
    {
        for (std::size_t ch = 0; ch < channels_; ++ch)
        {
            std::fill_n(channel(ch), frames_, 0.0f);
        }
    }

  private:
    T *data_ = nullptr;
    std::size_t channels_ = 0;
    std::size_t frames_ = 0;
    std::size_t channel_stride_ = 0;
};

using IFBlock = FloatBlock<const float>;
using OFBlock = FloatBlock<float>;

/// @brief Own a planar float workspace prepared for reuse during processing.
class Buffer

    /// @brief Set the workspace dimensions and zero its samples.
    /// @param channels Number of channels.
    /// @param capacity_frames Frame capacity per channel.
    /// @return Success, InvalidArg for a zero dimension, or TooLarge if the storage limit is exceeded.
    /// @note Allocate in prepare(). Allocation failure propagates as an exception.
    RetCode resize(std::size_t channels, std::size_t capacity_frames);

    /// @brief Borrow a writable block using the workspace capacity as the channel stride.
    /// @param frames Number of frames in the processing span.
    /// @pre frames fits the workspace capacity.
    /// @note Borrow a new block after a successful resize. Keep the backing storage alive while using a view.
    OFBlock block(std::size_t frames) noexcept;

    /// @brief Zero all samples in the workspace.
    void clear() noexcept;

  private:
    std::vector<float> samples_;
    std::size_t channels_ = 0;
    std::size_t capacity_frames_ = 0;
};

bool same_ports(View<const PortSpec> a, View<const PortSpec> b) noexcept
{
    return a.size() == b.size() && std::equal(a.begin(), a.end(), b.begin());
}
std::size_t pool_units_per_channel(SampleFormat format, std::size_t frames) noexcept
{
    return format == SampleFormat::F32P ? frames : frames * sample_bytes(format);
}

struct PoolSize
{
    const std::size_t limit;
    std::size_t outputs = 0;
    std::size_t silence = 0;
    std::size_t offset = 0;

    bool count(PortSpec spec, BlockPeriod period, bool unconnected) noexcept
    {
        const auto units = pool_units_per_channel(spec.format, spec.max_frames(period));
        if (spec.channels > limit / units)
            return false;
        const auto size = spec.channels * units;
        if (unconnected)
            silence = std::max(silence, size);
        else
        {
            if (size > limit - outputs)
                return false;
            outputs += size;
        }
        return silence <= limit - outputs;
    }
};
struct PoolLayout
{
    PoolSize floats;
    PoolSize bytes;

    PoolSize &for_format(SampleFormat format) noexcept
    {
        return format == SampleFormat::F32P ? floats : bytes;
    }
};

class Engine::Graph
{
  public:
    Result<NodeId> add_node(std::unique_ptr<Node> instance)
    {
        if (!instance)
            return ErrorCode::InvalidArg;
        const auto inputs = instance->inputs();
        const auto outputs = instance->outputs();
        if (inputs.empty() && outputs.empty())
            return ErrorCode::InvalidArg;
        for (const auto ports : {inputs, outputs})
            for (const auto &port : ports)
                if (!port.valid())
                    return ErrorCode::InvalidArg;

        std::vector<OPort> links(inputs.size());
        const NodeId id{next_identifier()};
        auto entry = std::make_shared<NodeEntry>(id, std::move(instance), inputs, outputs);
        nodes_.emplace(id, DraftNode{std::move(entry), std::move(links)});
        dirty_ = true;
        return id;
    }

    RetCode remove_node(NodeId id) noexcept
    {
        const auto found = nodes_.find(id);
        if (found == nodes_.end())
            return ErrorCode::UnknownNode;
        for (auto it = connections_.begin(); it != connections_.end();)
            if (it->second.from.node == id || it->second.to.node == id)
                it = erase_connection(it);
            else
                ++it;
        dirty_ = true;
        nodes_.erase(found);
        return {};
    }

    RetCode replace_node(NodeId id, std::unique_ptr<Node> replacement)
    {
        const auto found = nodes_.find(id);
        if (found == nodes_.end())
            return ErrorCode::UnknownNode;
        if (!replacement)
            return ErrorCode::InvalidArg;
        const auto inputs = replacement->inputs();
        const auto outputs = replacement->outputs();
        auto &current = found->second.entry;
        if (!same_ports(current->inputs, inputs) || !same_ports(current->outputs, outputs))
            return ErrorCode::FormatMismatch;
        auto entry = std::make_shared<NodeEntry>(id, std::move(replacement), inputs, outputs);
        dirty_ = true;
        current = std::move(entry);
        return {};
    }

    RetCode set_paused(NodeId id, bool paused)
    {
        const auto found = nodes_.find(id);
        if (found == nodes_.end())
            return ErrorCode::UnknownNode;
        dirty_ |= found->second.paused != paused;
        found->second.paused = paused;
        return {};
    }

    Result<Node *> node(NodeId id) noexcept
    {
        const auto found = nodes_.find(id);
        if (found == nodes_.end())
            return ErrorCode::UnknownNode;
        return found->second.entry->node.get();
    }

    Result<ConnId> connect(OPort from, IPort to)
    {
        const auto source = port_owner(from);
        if (!source)
            return source.ret_code();
        const auto destination = port_owner(to);
        if (!destination)
            return destination.ret_code();
        auto &draft = *destination.value();
        if (source.value()->entry->outputs[from.index] != draft.entry->inputs[to.index])
            return ErrorCode::FormatMismatch;
        auto &input = draft.inputs[to.index];
        if (input.node)
            return input == from ? ErrorCode::DuplicateConn : ErrorCode::InputConnected;
        if (would_cycle(from.node, to.node))
            return ErrorCode::Cycle;
        const ConnId id{next_identifier()};
        connections_.emplace(id, Connection{from, to});
        input = from;
        dirty_ = true;
        return id;
    }

    RetCode disconnect(ConnId id) noexcept
    {
        const auto found = connections_.find(id);
        if (found == connections_.end())
            return ErrorCode::UnknownConn;
        erase_connection(found);
        dirty_ = true;
        return {};
    }

    Topology resolve() const
    {
        Topology topology;
        NodeIndex node_index;
        for (const auto &item : nodes_)
            if (!item.second.paused && item.second.entry->outputs.empty())
                visit(item.second, topology, node_index);

        return topology;
    }

    bool owns(const NodeEntry &entry) const noexcept
    {
        const auto found = nodes_.find(entry.id);
        return found != nodes_.end() && found->second.entry.get() == &entry;
    }

    void reset_nodes() noexcept
    {
        for (const auto &item : nodes_)
            item.second.entry->node->reset();
    }

    bool dirty() const noexcept
    {
        return dirty_;
    }

    void mark_clean() noexcept
    {
        dirty_ = false;
    }

  private:
    struct DraftNode
    {
        std::shared_ptr<NodeEntry> entry;
        std::vector<OPort> inputs;
        bool paused = false;
    };
    struct Connection
    {
        OPort from;
        IPort to;
    };
    using Connections = std::map<ConnId, Connection>;
    using NodeIndex = std::map<NodeId, std::size_t>;
    template <class Port> Result<DraftNode *> port_owner(Port port) noexcept
    {
        const auto found = nodes_.find(port.node);
        if (found == nodes_.end())
            return ErrorCode::UnknownNode;
        const auto ports = found->second.entry->ports(port);
        if (port.index >= ports.size())
            return ErrorCode::InvalidPort;
        return &found->second;
    }

    bool would_cycle(NodeId from, NodeId to) const
    {
        std::vector<NodeId> stack{from};
        std::set<NodeId> visited{from};
        while (!stack.empty())
        {
            const auto id = stack.back();
            stack.pop_back();
            if (id == to)
                return true;
            for (const auto input : nodes_.find(id)->second.inputs)
                if (input.node && visited.insert(input.node).second)
                    stack.push_back(input.node);
        }

        return false;
    }

    Connections::iterator erase_connection(Connections::iterator connection) noexcept
    {
        const auto to = connection->second.to;
        nodes_.find(to.node)->second.inputs[to.index] = {};
        return connections_.erase(connection);
    }

    void visit(const DraftNode &draft, Topology &topology, NodeIndex &node_index) const
    {
        if (node_index.count(draft.entry->id))
            return;

        for (const auto input : draft.inputs)
            if (input.node)
            {
                const auto &source = nodes_.find(input.node)->second;
                if (!source.paused)
                    visit(source, topology, node_index);
            }

        node_index.emplace(draft.entry->id, topology.nodes.size());
        topology.nodes.push_back(draft.entry);

        // An absent source is unconnected or was excluded by pause.
        for (const auto input : draft.inputs)
        {
            const auto source = node_index.find(input.node);
            topology.links.push_back(source == node_index.end() ? Link{} : Link{source->second, input.index});
        }
    }

    std::map<NodeId, DraftNode> nodes_;
    Connections connections_;
    bool dirty_ = true;
};

class Engine::Clock
{
  public:
    ~Clock()
    {
        stop();
    }

    template <class Plan> void submit_and_wait(std::atomic<Plan *> &submitted, Plan *plan)
    {
        std::unique_lock<std::mutex> lock(mutex_);
        submitted.store(plan, std::memory_order_release);
        applied_.wait(lock, [&submitted]() noexcept { return submitted.load(std::memory_order_acquire) == nullptr; });
    }

    void start(Engine &engine)
    {
        stopping_ = false;
        const auto interval = std::chrono::milliseconds(static_cast<std::uint32_t>(engine.period_));
        const auto first_deadline = std::chrono::steady_clock::now() + interval;
        thread_ = std::thread([this, &engine, interval, deadline = first_deadline]() mutable {
            clock_engine = &engine;
            std::unique_lock<std::mutex> lock(mutex_);
            while (!changed_.wait_until(lock, deadline, [this] { return stopping_; }))
            {
                lock.unlock();
                const bool swapped = engine.tick();
                lock.lock();
                if (swapped)
                    applied_.notify_one();
                const auto lateness = std::chrono::steady_clock::now() - deadline;
                deadline += interval * (lateness >= interval ? lateness / interval + 1 : 1);
            }
        });
    }

    void stop() noexcept
    {
        if (!thread_.joinable())
            return;
        {
            const std::lock_guard<std::mutex> lock(mutex_);
            stopping_ = true;
        }
        changed_.notify_one();
        thread_.join();
    }

  private:
    std::mutex mutex_;
    std::condition_variable changed_;
    std::condition_variable applied_;
    bool stopping_ = false;
    std::thread thread_;
};

class Engine::Runner
{
  public:
    RetCode commit(Topology topology, BlockPeriod period, Clock *live_clock)
    {
        auto plan = std::make_unique<Plan>();
        const auto code = build_plan(*plan, topology, period);
        if (!code)
            return code;

        plan->owners = std::move(topology.nodes);
        if (live_clock)
            live_clock->submit_and_wait(submitted_, plan.get());
        else
            rendering_ = plan.get();
        current_ = std::move(plan);
        return {};
    }

    // Reset nodes still held by the plan after a draft edit.
    void reset(const Graph &draft) noexcept
    {
        if (!current_)
            return;
        for (const auto &entry : current_->owners)
            if (!draft.owns(*entry))
                entry->node->reset();
    }

    bool render(BlockPeriod period, std::uint64_t tick) noexcept
    {
        const auto plan = submitted_.load(std::memory_order_acquire);
        if (plan)
        {
            rendering_ = plan;
            // The control side may now retire the previous plan.
            submitted_.store(nullptr, std::memory_order_release);
        }

        rendering_->render(period, tick);
        return plan != nullptr;
    }

  private:
    struct Step
    {
        Node *node;
        std::size_t first_input;
        std::size_t input_count;
        std::size_t first_output;
        std::size_t output_count;
    };
    struct Plan
    {
        OPortBlock block(PortSpec spec, std::size_t frames, std::size_t offset) noexcept
        {
            auto *data = spec.format == SampleFormat::F32P
                             ? reinterpret_cast<std::uint8_t *>(float_pool.data() + offset)
                             : byte_pool.data() + offset;
            return {data, spec, frames};
        }

        void render(BlockPeriod period, std::uint64_t tick) noexcept
        {
            if (has_fractional_ports)
            {
                for (auto &input : inputs)
                    input.set_frames(input.spec().frames(period, tick));
                for (auto &output : outputs)
                    output.set_frames(output.spec().frames(period, tick));
            }

            for (const auto &step : steps)
                step.node->process({period, tick, port_range(inputs, step.first_input, step.input_count),
                                    port_range(outputs, step.first_output, step.output_count)});
        }

        bool has_fractional_ports = false;
        // The zero-filled prefix of each pool is shared by unconnected inputs.
        std::vector<float> float_pool;
        std::vector<std::uint8_t> byte_pool;
        std::vector<IPortBlock> inputs;
        std::vector<OPortBlock> outputs;
        std::vector<Step> steps;
        std::vector<std::shared_ptr<NodeEntry>> owners;
    };

    static RetCode build_plan(Plan &plan, const Topology &topology, BlockPeriod period)
    {
        for (const auto &entry : topology.nodes)
            if (!entry->prepared)
            {
                const auto code = entry->node->prepare(period);
                if (!code)
                    return code;
                entry->prepared = true;
            }

        PoolLayout layout{{plan.float_pool.max_size()}, {plan.byte_pool.max_size()}};
        std::size_t input_count = 0;
        std::size_t output_count = 0;
        const auto period_ms = static_cast<std::uint32_t>(period);
        const auto fractional = [period_ms](PortSpec spec) {
            return (static_cast<std::uint32_t>(spec.sample_rate) * period_ms) % 1000 != 0;
        };
        plan.steps.reserve(topology.nodes.size());
        for (const auto &entry : topology.nodes)
        {
            const auto inputs = entry->inputs;
            const auto outputs = entry->outputs;
            if (inputs.size() > plan.inputs.max_size() - input_count ||
                outputs.size() > plan.outputs.max_size() - output_count)
                return ErrorCode::TooLarge;
            plan.steps.push_back({entry->node.get(), input_count, inputs.size(), output_count, outputs.size()});

            for (const auto spec : outputs)
            {
                if (!layout.for_format(spec.format).count(spec, period, false))
                    return ErrorCode::TooLarge;
                plan.has_fractional_ports |= fractional(spec);
            }
            for (std::size_t port = 0; port < inputs.size(); ++port)
            {
                if (topology.links[input_count + port].node_index != Link::unconnected)
                    continue;
                const auto spec = inputs[port];
                if (!layout.for_format(spec.format).count(spec, period, true))
                    return ErrorCode::TooLarge;
                plan.has_fractional_ports |= fractional(spec);
            }
            input_count += inputs.size();
            output_count += outputs.size();
        }

        plan.inputs.resize(input_count);
        plan.outputs.resize(output_count);
        plan.float_pool.resize(layout.floats.silence + layout.floats.outputs);
        plan.byte_pool.resize(layout.bytes.silence + layout.bytes.outputs);
        layout.floats.offset = layout.floats.silence;
        layout.bytes.offset = layout.bytes.silence;
        // Outputs are bound upstream first. Connected inputs copy the corresponding read-only view.
        for (std::size_t node_index = 0; node_index < topology.nodes.size(); ++node_index)
        {
            const auto &entry = *topology.nodes[node_index];
            const auto &step = plan.steps[node_index];
            for (std::size_t port = 0; port < step.output_count; ++port)
            {
                const auto spec = entry.outputs[port];
                const auto frames = spec.max_frames(period);
                auto &pool = layout.for_format(spec.format);
                plan.outputs[step.first_output + port] = plan.block(spec, frames, pool.offset);
                pool.offset += spec.channels * pool_units_per_channel(spec.format, frames);
            }
            for (std::size_t port = 0; port < step.input_count; ++port)
            {
                const auto input_index = step.first_input + port;
                const auto link = topology.links[input_index];
                if (link.node_index != Link::unconnected)
                    plan.inputs[input_index] = plan.outputs[plan.steps[link.node_index].first_output + link.port_index];
                else
                {
                    const auto spec = entry.inputs[port];
                    plan.inputs[input_index] = plan.block(spec, spec.max_frames(period), 0);
                }
            }
        }

        return {};
    }

    std::unique_ptr<Plan> current_;
    std::atomic<Plan *> submitted_{nullptr};
    // Only the clock thread accesses this while running.
    Plan *rendering_ = nullptr;
};

Engine::Engine(BlockPeriod period)
    : period_(period), graph_(std::make_unique<Graph>()), runner_(std::make_unique<Runner>()),
      clock_(std::make_unique<Clock>())
{
}

// The clock is destroyed first and joins before the runner or graph is destroyed.
Engine::~Engine() = default;

bool Engine::on_clock_thread() const noexcept
{
    return clock_engine == this;
}

bool Engine::tick() noexcept
{
    const auto tick = position_.load(std::memory_order_relaxed);
    const bool swapped = runner_->render(period_, tick);
    position_.store(tick + 1, std::memory_order_release);
    return swapped;
}

RetCode Engine::commit()
{
    if (on_clock_thread())
        return ErrorCode::Busy;
    if (!is_block_period(period_))
        return ErrorCode::InvalidArg;
    if (!graph_->dirty())
        return {};

    const auto code = runner_->commit(graph_->resolve(), period_, state_ == State::Running ? clock_.get() : nullptr);
    if (code)
    {
        graph_->mark_clean();
        if (state_ == State::Unprepared)
            state_ = State::Ready;
    }
    return code;
}

RetCode Engine::start()
{
    if (on_clock_thread() || state_ == State::Running)
        return ErrorCode::Busy;
    if (state_ == State::Unprepared)
        return ErrorCode::NotPrepared;
    clock_->start(*this);
    state_ = State::Running;
    return {};
}

RetCode Engine::stop() noexcept
{
    if (on_clock_thread())
        return ErrorCode::Busy;
    if (state_ == State::Running)
    {
        clock_->stop();
        state_ = State::Ready;
    }
    return {};
}

RetCode Engine::reset() noexcept
{
    if (on_clock_thread() || state_ == State::Running)
        return ErrorCode::Busy;
    runner_->reset(*graph_);
    graph_->reset_nodes();
    position_.store(0, std::memory_order_release);
    return {};
}

std::uint64_t Engine::tick_position() const noexcept
{
    return position_.load(std::memory_order_acquire);
}

/// @brief Owns an audio graph and advances it on an internal software clock.
/// @note Serialize all control calls and destruction, including node lookup.
/// Node callbacks must defer control requests to the caller's serial execution domain
/// and return without waiting for those requests. Control calls from this engine's
/// clock thread return Busy. Destroy the Engine from the control side.
/// block_period() and tick_position() may run concurrently while the Engine is alive.
class Engine
{
  public:
    explicit Engine(BlockPeriod block_period);
    ~Engine();
    Engine(const Engine &) = delete;
    Engine &operator=(const Engine &) = delete;
    Result<NodeId> add_node(std::unique_ptr<Node> instance);
    template <class T, class... Args> Result<NodeId> emplace_node(Args &&...args)
    {
        if (on_clock_thread())
            return ErrorCode::Busy;
        return insert_node(std::make_unique<T>(std::forward<Args>(args)...));
    }
    RetCode remove_node(NodeId node_id) noexcept;
    /// @brief Stage a compatible replacement. Existing connections follow the node ID.
    RetCode replace_node(NodeId node_id, std::unique_ptr<Node> replacement);
    /// @brief Stage a local pause or resume for the next submitted plan.
    RetCode set_paused(NodeId node_id, bool paused);
    /// @brief Borrow the draft node until removal, replacement, or Engine destruction.
    /// @note Follow the node's own contract for concurrent access during rendering.
    Result<Node *> node(NodeId node_id) noexcept;
    template <class T> Result<T *> node(NodeId node_id) noexcept
    {
        const auto result = node(node_id);
        if (!result)
        {
            return result.ret_code();
        }
        auto *typed_node = dynamic_cast<T *>(result.value());
        if (!typed_node)
        {
            return ErrorCode::InvalidType;
        }
        return typed_node;
    }
    Result<ConnId> connect(OPort from, IPort to);
    RetCode disconnect(ConnId conn_id) noexcept;
    /// @brief Prepare the draft and make it the current render plan.
    /// @note While running, wait for block-boundary takeover and release the previous
    /// plan on the calling thread. An unchanged draft succeeds immediately.
    RetCode commit();
    /// @brief Start the software clock after successful preparation.
    /// @note Thread creation exceptions propagate and leave the engine ready to retry.
    RetCode start();
    /// @brief Stop the clock and wait for any in-flight block.
    RetCode stop() noexcept;
    /// @brief Reset nodes and the tick position while stopped.
    RetCode reset() noexcept;
    /// @brief Return the fixed block period.
    BlockPeriod block_period() const noexcept
    {
        return period_;
    }
    /// @brief Return the position of the next tick, advanced after each completed block.
    std::uint64_t tick_position() const noexcept;

  private:
    class Graph;
    class Runner;
    class Clock;
    enum class State
    {
        Unprepared,
        Ready,
        Running
    };

    bool on_clock_thread() const noexcept;
    Result<NodeId> insert_node(std::unique_ptr<Node> instance);
    bool tick() noexcept;

    const BlockPeriod period_;
    State state_ = State::Unprepared;
    std::atomic<std::uint64_t> position_{0};
    std::unique_ptr<Graph> graph_;
    std::unique_ptr<Runner> runner_;
    std::unique_ptr<Clock> clock_;
};

/// @brief Graph execution unit with immutable input and output port layouts.
///
/// Keep the port descriptors and their storage valid and unchanged for as long as
/// the engine owns the node.
/// Defer any requests to control the owning engine and return without waiting for them.
class Node
{
  public:
    virtual ~Node() = default;
    Node(const Node &) = delete;
    Node &operator=(const Node &) = delete;

    /// @brief Describe the input ports.
    /// @return A read-only view of the input port specifications in port index order.
    virtual View<const PortSpec> inputs() const noexcept = 0;

    /// @brief Describe the output ports.
    /// @return A read-only view of the output port specifications in port index order.
    virtual View<const PortSpec> outputs() const noexcept = 0;

    /// @brief Prepare the node's processing resources on the control thread.
    /// @param period Block period validated by the engine.
    /// @return Success when the node is ready to process, or a preparation error.
    /// @note The engine may retry after a failure.
    virtual RetCode prepare(BlockPeriod period) = 0;

    /// @brief Process one block and write every output sample in its declared format.
    /// @param context Current period, tick position, and input and output block views.
    /// @pre Preparation has succeeded.
    /// @note The context and its views are valid only during this call. Keep processing
    /// free of heap allocation and deallocation, blocking I/O, and logging.
    /// Avoid lock waits where possible.
    virtual void process(const ProcessContext &context) noexcept = 0;

    /// @brief Reset the node's processing state.
    /// @pre Reset must be serialized with processing.
    /// @note The engine may reset a node before its first preparation.
    virtual void reset() noexcept
    {
    }

  protected:
    Node() = default;
};

/// @brief Node base with compile-time port counts and inline port specifications.
/// @tparam I Number of input ports.
/// @tparam O Number of output ports.
template <std::size_t I, std::size_t O> class NodeT : public Node
{
    static_assert(I + O > 0, "Node needs at least one port");

  public:
    NodeT(std::array<PortSpec, I> inputs, std::array<PortSpec, O> outputs) : inputs_(inputs), outputs_(outputs)
    {
    }
    View<const PortSpec> inputs() const noexcept final
    {
        return {inputs_.data(), I};
    }
    View<const PortSpec> outputs() const noexcept final
    {
        return {outputs_.data(), O};
    }

  private:
    const std::array<PortSpec, I> inputs_;
    const std::array<PortSpec, O> outputs_;
};

enum class ErrorCode
{
    Ok = 0,
    InvalidArg,
    UnknownNode,
    UnknownConn,
    InvalidPort,
    InvalidType,
    FormatMismatch = 7,
    DuplicateConn,
    InputConnected,
    Cycle,
    NotPrepared,
    Busy,
    BufferFull = 14,
    TooLarge
};

class RetCode
{
  public:
    constexpr RetCode(ErrorCode code = ErrorCode::Ok) noexcept : code_(code)
    {
    }
    constexpr ErrorCode code() const noexcept
    {
        return code_;
    }
    constexpr explicit operator bool() const noexcept
    {
        return code_ == ErrorCode::Ok;
    }
    const char *message() const noexcept
    {
        switch (code_)
        {
        case ErrorCode::Ok:
            return "Success";
        case ErrorCode::InvalidArg:
            return "Invalid argument";
        case ErrorCode::UnknownNode:
            return "Node does not belong to this engine or was removed";
        case ErrorCode::UnknownConn:
            return "Connection does not exist";
        case ErrorCode::InvalidPort:
            return "Port index is out of range";
        case ErrorCode::InvalidType:
            return "Node has a different type";
        case ErrorCode::FormatMismatch:
            return "Port formats do not match; connect a converter";
        case ErrorCode::DuplicateConn:
            return "These ports are already connected";
        case ErrorCode::InputConnected:
            return "Input already has a source; use a mixer for multiple sources";
        case ErrorCode::Cycle:
            return "Connection would create a feedback cycle";
        case ErrorCode::NotPrepared:
            return "Preparation is required";
        case ErrorCode::Busy:
            return "The current execution context or state prevents this operation";
        case ErrorCode::BufferFull:
            return "A buffer is full or still in use";
        case ErrorCode::TooLarge:
            return "Requested capacity exceeds the supported size";
        }
        return "Unknown error code";
    }

  private:
    ErrorCode code_;
};

// For graph results with default-constructible values. Check the status before reading the value.
template <class T> class Result
{
  public:
    Result(T value) noexcept(std::is_nothrow_move_constructible<T>::value) : value_(std::move(value))
    {
    }
    Result(RetCode code) noexcept(std::is_nothrow_default_constructible<T>::value) : ret_code_(code)
    {
        assert(!code);
    }
    Result(ErrorCode code) noexcept(std::is_nothrow_default_constructible<T>::value) : Result(RetCode(code))
    {
    }
    RetCode ret_code() const noexcept
    {
        return ret_code_;
    }
    explicit operator bool() const noexcept
    {
        return static_cast<bool>(ret_code_);
    }
    const T &value() const & noexcept
    {
        assert(ret_code_);
        return value_;
    }
    T value() && noexcept(std::is_nothrow_move_constructible<T>::value)
    {
        assert(ret_code_);
        return std::move(value_);
    }

  private:
    RetCode ret_code_;
    T value_{};
};

RetCode Buffer::resize(std::size_t channels, std::size_t capacity_frames)
{
    if (channels == 0 || capacity_frames == 0)
    {
        return ErrorCode::InvalidArg;
    }
    if (channels > samples_.max_size() / capacity_frames)
    {
        return ErrorCode::TooLarge;
    }
    const auto sample_count = channels * capacity_frames;
    const auto retained_samples = std::min(samples_.size(), sample_count);
    samples_.resize(sample_count);
    std::fill_n(samples_.begin(), retained_samples, 0.0f);
    channels_ = channels;
    capacity_frames_ = capacity_frames;
    return {};
}

OFBlock Buffer::block(std::size_t frames) noexcept
{
    return {samples_.data(), channels_, frames, capacity_frames_};
}

void Buffer::clear() noexcept
{
    std::fill(samples_.begin(), samples_.end(), 0.0f);
}

std::size_t PortSpec::max_frames(BlockPeriod period) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    return static_cast<std::size_t>((units + 999) / 1000);
}

std::size_t PortSpec::frames(BlockPeriod period, std::uint64_t tick) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    const auto fraction = units % 1000;
    if (fraction == 0)
        return static_cast<std::size_t>(units / 1000);
    const auto start = (tick % 1000) * fraction;
    return static_cast<std::size_t>(units / 1000 + (start + fraction + 999) / 1000 - (start + 999) / 1000);
}

std::uint64_t PortSpec::frame_position(BlockPeriod period, std::uint64_t tick) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    // Split whole seconds from the remainder to avoid multiplying tick by the sample rate.
    return (tick / 1000) * units + ((tick % 1000) * units + 999) / 1000;
}

#ifndef AEREBORN_CORE_TYPES_H

/// @brief Supported sample rates, in hertz.
enum class SampleRate : std::uint32_t
{
    Hz8000 = 8000,
    Hz11025 = 11025,
    Hz16000 = 16000,
    Hz22050 = 22050,
    Hz24000 = 24000,
    Hz32000 = 32000,
    Hz44100 = 44100,
    Hz48000 = 48000,
    Hz88200 = 88200,
    Hz96000 = 96000
};

/// @brief Supported durations of one engine tick, in milliseconds.
enum class BlockPeriod : std::uint32_t
{
    Ms05 = 5,
    Ms10 = 10,
    Ms20 = 20,
    Ms40 = 40
};

/// @brief Sample storage format, including channel layout and byte order.
///
/// F32P stores native planar float32. All other formats store interleaved
/// little-endian PCM.
enum class SampleFormat
{
    F32P,
    S16LE,
    S24_3LE, ///< Signed 24-bit PCM packed into three bytes per sample.
    S24LE,   ///< Signed 24-bit PCM stored in a four-byte slot per sample.
    S32LE,
    F32LE
};

constexpr bool is_sample_rate(SampleRate sample_rate) noexcept
{
    switch (sample_rate)
    {
    case SampleRate::Hz8000:
    case SampleRate::Hz11025:
    case SampleRate::Hz16000:
    case SampleRate::Hz22050:
    case SampleRate::Hz24000:
    case SampleRate::Hz32000:
    case SampleRate::Hz44100:
    case SampleRate::Hz48000:
    case SampleRate::Hz88200:
    case SampleRate::Hz96000:
        return true;
    }
    return false;
}
constexpr bool is_block_period(BlockPeriod period) noexcept
{
    return period == BlockPeriod::Ms05 || period == BlockPeriod::Ms10 || period == BlockPeriod::Ms20 ||
           period == BlockPeriod::Ms40;
}
constexpr unsigned int sample_bits(SampleFormat format) noexcept
{
    switch (format)
    {
    case SampleFormat::S16LE:
        return 16;
    case SampleFormat::S24_3LE:
    case SampleFormat::S24LE:
        return 24;
    case SampleFormat::F32P:
    case SampleFormat::S32LE:
    case SampleFormat::F32LE:
        return 32;
    }
    return 0;
}
constexpr std::size_t sample_bytes(SampleFormat format) noexcept
{
    return format == SampleFormat::S24LE ? 4 : sample_bits(format) / 8;
}

/// @brief Fixed sample rate, channel count, and format declared by a port.
///
/// Connections require all three fields to match. Each frame contains one sample
/// per channel.
struct PortSpec
{
    constexpr PortSpec() noexcept = default;
    constexpr PortSpec(SampleRate sample_rate, std::size_t channels, SampleFormat format = SampleFormat::F32P) noexcept
        : channels(channels), sample_rate(sample_rate), format(format)
    {
    }
    constexpr bool valid() const noexcept
    {
        return is_sample_rate(sample_rate) && channels > 0 && sample_bytes(format) != 0;
    }
    constexpr bool operator==(const PortSpec &other) const noexcept
    {
        return sample_rate == other.sample_rate && channels == other.channels && format == other.format;
    }
    constexpr bool operator!=(const PortSpec &other) const noexcept
    {
        return !(*this == other);
    }

    /// @brief Return the maximum frame count in one block for buffer sizing.
    /// @param period Duration of the engine tick.
    std::size_t max_frames(BlockPeriod period) const noexcept;

    /// @brief Return the actual frame count for a tick.
    /// @param period Duration of the engine tick.
    /// @param tick Zero-based tick position.
    /// @note The count is the difference between two consecutive frame positions.
    std::size_t frames(BlockPeriod period, std::uint64_t tick) const noexcept;

    /// @brief Return the zero-based frame position at the start of a tick.
    /// @param period Duration of the engine tick.
    /// @param tick Zero-based tick position.
    /// @note Fractional frame positions round up.
    std::uint64_t frame_position(BlockPeriod period, std::uint64_t tick) const noexcept;

    std::size_t channels = 0;
    SampleRate sample_rate{};
    SampleFormat format = SampleFormat::F32P;
};

/// @brief Borrow the current audio block of a port with its specification and frame count.
/// @tparam Byte Use std::uint8_t for writable bytes or const std::uint8_t for read-only bytes.
///
/// The render plan owns the storage provided to a node. Use its views only for the
/// duration of the process call.
template <class Byte> class PortBlock
{
    template <class> friend class PortBlock;
    using Float = typename std::conditional<std::is_const<Byte>::value, const float, float>::type;

  public:
    PortBlock() noexcept = default;

    /// @brief Interpret a borrowed buffer according to the port specification.
    /// @param data Address of the buffer.
    /// @param spec Sample rate, channel count, and format of the buffer.
    /// @param frames Number of frames available in the buffer for this block.
    /// @pre A nonempty block refers to storage large enough for the specified frames.
    PortBlock(Byte *data, PortSpec spec, std::size_t frames) noexcept : data_(data), spec_(spec), frames_(frames)
    {
    }
    template <class OtherByte, typename std::enable_if<std::is_convertible<OtherByte *, Byte *>::value, int>::type = 0>
    PortBlock(PortBlock<OtherByte> other) noexcept : data_(other.data_), spec_(other.spec_), frames_(other.frames_)
    {
    }
    PortSpec spec() const noexcept
    {
        return spec_;
    }
    std::size_t frames() const noexcept
    {
        return frames_;
    }
    View<Byte> byte_view() const noexcept
    {
        return {data_, frames_ * spec_.channels * sample_bytes(spec_.format)};
    }
    FloatBlock<Float> f32p_view() const noexcept
    {
        assert(spec_.format == SampleFormat::F32P);
        return {reinterpret_cast<Float *>(data_), spec_.channels, frames_, frames_};
    }
    void set_frames(std::size_t frames) noexcept
    {
        frames_ = frames;
    }

  private:
    Byte *data_ = nullptr;
    PortSpec spec_;
    std::size_t frames_ = 0;
};

using IPortBlock = PortBlock<const std::uint8_t>;
using OPortBlock = PortBlock<std::uint8_t>;

/// @brief Stable identity of a node in the graph, including across instance replacement.

    std::uint64_t value = 0;
    constexpr explicit operator bool() const noexcept
    {
        return value != 0;
    }
    constexpr bool operator==(NodeId other) const noexcept
    {
        return value == other.value;
    }
    constexpr bool operator!=(NodeId other) const noexcept
    {
        return !(*this == other);
    }
    constexpr bool operator<(NodeId other) const noexcept
    {
        return value < other.value;
    }
};

    constexpr bool operator!=(ConnId other) const noexcept

#include "convert.h"

constexpr std::size_t order = 48;
constexpr std::size_t taps = 2 * order;
constexpr std::uint32_t phase_steps = 100;
constexpr double pi = 3.141592653589793;

std::uint32_t read_le(const std::uint8_t *input, std::size_t bytes) noexcept
{
    std::uint32_t raw = 0;
    for (std::size_t i = 0; i < bytes; ++i)
    {
        raw |= static_cast<std::uint32_t>(input[i]) << (8 * i);
    }
    return raw;
}

void write_le(std::uint32_t raw, std::uint8_t *output, std::size_t bytes) noexcept
{
    for (std::size_t i = 0; i < bytes; ++i)
    {
        output[i] = static_cast<std::uint8_t>(raw >> (8 * i));
    }
}

float decode_integer(std::uint32_t raw, unsigned int bits) noexcept
{
    const auto scale = std::int64_t{1} << (bits - 1);
    const auto value = std::int64_t{raw} & (2 * scale - 1);
    return static_cast<float>(value >= scale ? value - 2 * scale : value) / static_cast<float>(scale);
}

std::uint32_t encode_integer(float sample, unsigned int bits) noexcept
{
    const auto scale = std::int64_t{1} << (bits - 1);
    const auto normalized = std::isnan(sample) ? 0.0f : std::max(-1.0f, std::min(1.0f, sample));
    const auto rounded = static_cast<std::int64_t>(std::round(static_cast<double>(normalized) * scale));
    const auto value = std::min(scale - 1, rounded);
    return static_cast<std::uint32_t>(value) & static_cast<std::uint32_t>(2 * scale - 1);
}

bool native_f32le() noexcept
{
    const float one = 1.0f;
    constexpr std::uint8_t one_le[] = {0, 0, 0x80, 0x3f};
    return std::memcmp(&one, one_le, sizeof(one)) == 0;
}

void copy_f32le(const std::uint8_t *pcm, OFBlock output) noexcept
{
    if (output.channels() == 1 && native_f32le())
    {
        std::memcpy(output.channel(0), pcm, output.frames() * sizeof(float));
        return;
    }
    for (std::size_t frame = 0; frame < output.frames(); ++frame)
    {
        for (std::size_t ch = 0; ch < output.channels(); ++ch, pcm += sizeof(float))
        {
            const auto raw = read_le(pcm, sizeof(float));
            std::memcpy(output.channel(ch) + frame, &raw, sizeof(raw));
        }
    }
}

void copy_f32le(IFBlock input, std::uint8_t *pcm) noexcept
{
    if (input.channels() == 1 && native_f32le())
    {
        std::memcpy(pcm, input.channel(0), input.frames() * sizeof(float));
        return;
    }
    for (std::size_t frame = 0; frame < input.frames(); ++frame)
    {
        for (std::size_t ch = 0; ch < input.channels(); ++ch, pcm += sizeof(float))
        {
            std::uint32_t raw;
            std::memcpy(&raw, input.channel(ch) + frame, sizeof(raw));
            write_le(raw, pcm, sizeof(raw));
        }
    }
}

void decode_pcm(SampleFormat format, const std::uint8_t *source, OFBlock output) noexcept
{
    if (output.frames() == 0)
        return;
    if (format == SampleFormat::F32LE)
    {
        copy_f32le(source, output);
        return;
    }
    const auto width = sample_bytes(format);
    const auto bits = sample_bits(format);
    for (std::size_t frame = 0; frame < output.frames(); ++frame)
        for (std::size_t ch = 0; ch < output.channels(); ++ch, source += width)
            output.channel(ch)[frame] = decode_integer(read_le(source, width), bits);
}

void encode_pcm(SampleFormat format, IFBlock input, std::uint8_t *destination) noexcept
{
    if (input.frames() == 0)
        return;
    if (format == SampleFormat::F32LE)
    {
        copy_f32le(input, destination);
        return;
    }
    const auto width = sample_bytes(format);
    const auto bits = sample_bits(format);
    for (std::size_t frame = 0; frame < input.frames(); ++frame)
        for (std::size_t ch = 0; ch < input.channels(); ++ch, destination += width)
            write_le(encode_integer(input.channel(ch)[frame], bits), destination, width);
}

// Window and cutoff ported from AudioDriver's SincInterpolator.
double sinc_kernel(double x, double cutoff) noexcept
{
    if (std::abs(x) >= order)
    {
        return 0.0;
    }
    const auto angle = (2.0 * pi * (x + 1.0 - order)) / (taps - 1);
    const auto window =
        0.3635819 - 0.4891775 * std::cos(angle) + 0.1365995 * std::cos(2 * angle) - 0.0106411 * std::cos(3 * angle);
    const auto sinc_angle = pi * cutoff * x;
    const auto sinc = sinc_angle == 0 ? 1.0 : std::sin(sinc_angle) / sinc_angle;
    return sinc * window;
}

using Coefficients = std::array<float, taps>;

void calc_coffs(const float *kernel, std::uint32_t dst_fs, std::uint64_t src_pos, Coefficients &coffs) noexcept
{
    const auto phase_pos = (src_pos % dst_fs) * phase_steps;
    const auto phase_index = phase_pos / dst_fs;
    const auto phase_frac = static_cast<float>(phase_pos % dst_fs) / static_cast<float>(dst_fs);
    const auto *lo_coffs = kernel + phase_index * taps;
    const auto *hi_coffs = lo_coffs + taps;
    for (std::size_t i = 0; i < taps; ++i)
    {
        coffs[i] = lo_coffs[i] + (hi_coffs[i] - lo_coffs[i]) * phase_frac;
    }
}

float interpolate(const float *history, const float *input, std::size_t history_taps,
                  const Coefficients &coffs) noexcept
{
    double sum = 0;
    for (std::size_t i = 0; i < history_taps; ++i)
    {
        sum += history[i] * coffs[i];
    }
    for (std::size_t i = history_taps; i < taps; ++i)
    {
        sum += input[i - history_taps] * coffs[i];
    }
    return static_cast<float>(sum);
}

class SincResampler
{
  public:
    SincResampler(SampleRate input, SampleRate output) noexcept
        : src_fs_(static_cast<std::uint32_t>(input)), dst_fs_(static_cast<std::uint32_t>(output))
    {
    }
    RetCode prepare(std::size_t channels)
    {
        const auto code = history_.resize(channels, taps);
        if (!code)
            return code;
        kernel_.resize((phase_steps + 1) * taps);
        const auto cutoff = std::min(1.0, static_cast<double>(dst_fs_) / src_fs_) * 0.98;
        for (std::uint32_t phase = 0; phase <= phase_steps; ++phase)
        {
            auto *coffs = kernel_.data() + phase * taps;
            const auto fraction = static_cast<double>(phase) / phase_steps;
            double scale = 0;
            for (std::size_t i = 0; i < taps; ++i)
            {
                coffs[i] = static_cast<float>(sinc_kernel(fraction + order - 1 - i, cutoff));
                scale += coffs[i];
            }
            for (std::size_t i = 0; i < taps; ++i)
                coffs[i] = static_cast<float>(coffs[i] / scale);
        }
        return {};
    }
    void reset() noexcept { history_.clear(); }
    void process(IFBlock input, OFBlock output, BlockPeriod period, std::uint64_t tick) noexcept;

  private:
    const std::uint32_t src_fs_;
    const std::uint32_t dst_fs_;
    Buffer history_;
    std::vector<float> kernel_;
};

void SincResampler::process(IFBlock input, OFBlock output, BlockPeriod period, std::uint64_t tick) noexcept
{
    const auto past = history_.block(taps);
    // src_pos is in units of 1 / the output sample rate; the first taps frames address history.
    const auto rounding = [period, tick](std::uint32_t rate)
    {
        const auto remainder =
            (tick % 1000) * ((std::uint64_t{rate} * static_cast<std::uint32_t>(period)) % 1000) % 1000;
        return static_cast<std::int64_t>((1000 - remainder) % 1000);
    };
    const auto phase = (rounding(dst_fs_) * src_fs_ - rounding(src_fs_) * dst_fs_) / 1000;
    auto src_pos = static_cast<std::uint64_t>(dst_fs_ + phase);
    Coefficients coffs;
    for (std::size_t frame = 0; frame < output.frames(); ++frame, src_pos += src_fs_)
    {
        calc_coffs(kernel_.data(), dst_fs_, src_pos, coffs);
        const auto frame_index = static_cast<std::size_t>(src_pos / dst_fs_);
        const auto history_offset = std::min(frame_index, taps);
        const auto input_offset = frame_index - history_offset;
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
        {
            output.channel(ch)[frame] = interpolate(past.channel(ch) + history_offset, input.channel(ch) + input_offset,
                                                    taps - history_offset, coffs);
        }
    }

    const auto copy_frames = std::min(input.frames(), taps);
    const auto keep_frames = taps - copy_frames;
    for (std::size_t ch = 0; ch < input.channels(); ++ch)
    {
        auto *history_samples = past.channel(ch);
        std::memmove(history_samples, history_samples + copy_frames, keep_frames * sizeof(float));
        std::copy_n(input.channel(ch) + input.frames() - copy_frames, copy_frames, history_samples + keep_frames);
    }
}

} // namespace

struct Convert::State
{
    State(SampleRate input, SampleRate output) : resampler(input, output) {}

    RetCode prepare(PortSpec input, PortSpec output, BlockPeriod period)
    {
        const bool resampling = input.sample_rate != output.sample_rate;
        if (input.format != SampleFormat::F32P && (resampling || output.format != SampleFormat::F32P))
        {
            const auto code = decoded.resize(input.channels, input.max_frames(period));
            if (!code)
                return code;
        }
        if (!resampling)
            return {};
        if (output.format != SampleFormat::F32P)
        {
            const auto code = converted.resize(output.channels, output.max_frames(period));
            if (!code)
                return code;
        }
        return resampler.prepare(input.channels);
    }

    Buffer decoded;
    Buffer converted;
    SincResampler resampler;
};

Convert::Convert(PortSpec input, PortSpec output) : NodeT({{input}}, {{output}})
{
    if (!input.valid() || !output.valid())
        throw std::invalid_argument("Invalid converter port specification");
    if (input.channels != output.channels)
        throw std::invalid_argument("Converter input and output channel counts must match");
}
Convert::~Convert() = default;
RetCode Convert::prepare(BlockPeriod period)
{
    const auto input = inputs()[0], output = outputs()[0];
    if (input == output)
        return {};
    auto next = std::make_unique<State>(input.sample_rate, output.sample_rate);
    const auto code = next->prepare(input, output, period);
    if (code)
        state_.swap(next);
    return code;
}
void Convert::reset() noexcept
{
    if (state_)
        state_->resampler.reset();
}
void Convert::process(const ProcessContext &context) noexcept
{
    const auto input = context.inputs[0];
    const auto output = context.outputs[0];
    const auto input_spec = input.spec();
    const auto output_spec = output.spec();
    if (input_spec == output_spec)
    {
        const auto bytes = input.byte_view();
        if (!bytes.empty())
            std::memcpy(output.byte_view().data(), bytes.data(), bytes.size());
        return;
    }

    auto &state = *state_;
    const bool resampling = input_spec.sample_rate != output_spec.sample_rate;
    const bool planar_output = output_spec.format == SampleFormat::F32P;
    IFBlock samples;
    if (input_spec.format == SampleFormat::F32P)
        samples = input.f32p_view();
    else
    {
        const auto decoded = planar_output && !resampling ? output.f32p_view() : state.decoded.block(input.frames());
        decode_pcm(input_spec.format, input.byte_view().data(), decoded);
        samples = decoded;
    }
    if (resampling)
    {
        const auto converted = planar_output ? output.f32p_view() : state.converted.block(output.frames());
        state.resampler.process(samples, converted, context.block_period, context.tick_position);
        samples = converted;
    }
    if (!planar_output)
        encode_pcm(output_spec.format, samples, output.byte_view().data());
}
} // namespace aereborn

#ifndef AEREBORN_PLUGINS_IO_H
#define AEREBORN_PLUGINS_IO_H
#include "core/graph.h"
#include <limits>
namespace aereborn
{
namespace detail
{
template <class Byte> class TickBuffer
{
  public:
    RetCode prepare(BlockPeriod period) noexcept
    {
        if (period_ != period)
            reset();
        period_ = period;
        return {};
    }

    RetCode bind(PortSpec spec, View<Byte> bytes, std::uint64_t tick) noexcept
    {
        if (!bytes.empty() && !bytes.data())
            return ErrorCode::InvalidArg;
        if (period_ == BlockPeriod{})
            return ErrorCode::NotPrepared;
        if (!bytes_.empty())
            return ErrorCode::BufferFull;
        const auto bytes_per_channel = spec.frames(period_, tick) * sample_bytes(spec.format);
        // Every supported rate and period produces a nonempty block.
        if (spec.channels > std::numeric_limits<std::size_t>::max() / bytes_per_channel)
            return ErrorCode::TooLarge;
        if (bytes.size() != spec.channels * bytes_per_channel)
            return ErrorCode::InvalidArg;
        bytes_ = bytes;
        tick_ = tick;
        return {};
    }

    View<Byte> take(std::uint64_t tick) noexcept
    {
        if (bytes_.empty() || tick < tick_)
            return {};
        const auto bytes = bytes_;
        reset();
        return tick == tick_ ? bytes : View<Byte>{};
    }

    void reset() noexcept { bytes_ = {}; }

  private:
    BlockPeriod period_{};
    View<Byte> bytes_;
    std::uint64_t tick_ = 0;
};
} // namespace detail

// Capture and Playback borrow one tick of memory from the caller. Keep it alive through
// that tick. Use a backend queue for buffers exchanged across threads.
class Capture final : public NodeT<0, 1>
{
  public:
    explicit Capture(PortSpec spec);
    RetCode prepare(BlockPeriod period) override;
    // Must be serialized with process(), like reset().
    RetCode bind(View<const std::uint8_t> bytes, std::uint64_t tick) noexcept;
    void process(const ProcessContext &context) noexcept override;
    void reset() noexcept override;

  private:
    detail::TickBuffer<const std::uint8_t> buffer_;
};
class Playback final : public NodeT<1, 0>
{
  public:
    explicit Playback(PortSpec spec);
    RetCode prepare(BlockPeriod period) override;
    // Must be serialized with process(), like reset().
    RetCode bind(View<std::uint8_t> bytes, std::uint64_t tick) noexcept;
    void process(const ProcessContext &context) noexcept override;
    void reset() noexcept override;

  private:
    detail::TickBuffer<std::uint8_t> buffer_;
};
} // namespace aereborn
#endif

===== plugins/matrix.cpp =====
#include "matrix.h"
#include <cmath>
#include <stdexcept>
namespace aereborn
{
namespace
{
template <bool Accumulate> void write_scaled(float &dst, const float &src, float gain) noexcept
{
    if (Accumulate)
        dst += src * gain;
    else
        dst = src * gain;
}

template <bool Accumulate, class Ramp>
void apply_gain(float *dst, const float *src, std::size_t frames, float coefficient, float target, bool steady,
                const Ramp &ramp_gain) noexcept
{
    const auto scaled_target = Accumulate ? coefficient * target : target;
    if (steady)
    {
        if (scaled_target != 0)
            for (std::size_t frame = 0; frame < frames; ++frame)
                write_scaled<Accumulate>(dst[frame], src[frame], scaled_target);
        return;
    }

    const auto write_frame = [&](std::size_t frame, float gain) noexcept {
        if (gain != 0)
            write_scaled<Accumulate>(dst[frame], src[frame], gain);
        else if (!Accumulate)
            dst[frame] = 0.0f;
    };
    const auto last = frames - 1;
    for (std::size_t frame = 0; frame < last; ++frame)
    {
        const auto gain = ramp_gain(frame);
        write_frame(frame, Accumulate ? coefficient * gain : gain);
    }
    write_frame(last, scaled_target);
}
} // namespace

Matrix::Matrix(SampleRate rate, std::size_t channels, float gain)
    : NodeT({{PortSpec(rate, channels)}}, {{PortSpec(rate, channels)}}), target_(gain), gain_(gain)
{
    if (!inputs()[0].valid() || !std::isfinite(gain))
        throw std::invalid_argument("Invalid matrix specification");
}
Matrix::Matrix(SampleRate rate, std::size_t input_channels, std::size_t output_channels, View<const float> coefficients,
               float gain)
    : NodeT({{PortSpec(rate, input_channels)}}, {{PortSpec(rate, output_channels)}}), target_(gain), gain_(gain)
{
    if (!inputs()[0].valid() || !outputs()[0].valid() || !std::isfinite(gain))
        throw std::invalid_argument("Invalid matrix specification");
    if (output_channels > coefficients_.max_size() / input_channels)
        throw std::length_error("Channel matrix exceeds supported size");
    if (coefficients.size() != input_channels * output_channels)
        throw std::invalid_argument("Channel matrix dimensions do not match coefficients");
    for (const auto value : coefficients)
        if (!std::isfinite(value))
            throw std::invalid_argument("Matrix coefficients must be finite");
    coefficients_.assign(coefficients.begin(), coefficients.end());
}
Matrix::Matrix(SampleRate rate, std::size_t input_channels, std::size_t output_channels,
               std::initializer_list<float> coefficients, float gain)
    : Matrix(rate, input_channels, output_channels, {coefficients.begin(), coefficients.size()}, gain)
{
}
RetCode Matrix::set_gain(float gain) noexcept
{
    if (!std::isfinite(gain))
        return ErrorCode::InvalidArg;
    target_.store(gain, std::memory_order_release);
    return {};
}
RetCode Matrix::prepare(BlockPeriod)
{
    reset();
    return {};
}
void Matrix::reset() noexcept
{
    gain_ = target_.load(std::memory_order_acquire);
}
void Matrix::process(const ProcessContext &context) noexcept
{
    const auto output = context.outputs[0].f32p_view();
    const auto frames = output.frames();
    if (frames == 0)
        return;
    const auto target = target_.load(std::memory_order_acquire);
    const bool steady = gain_ == target;
    if (steady && target == 0)
    {
        output.clear();
        return;
    }
    const auto input = context.inputs[0].f32p_view();
    const auto last = frames - 1;
    const auto scale = steady ? 0.0 : 1.0 / frames;
    const auto ramp_gain = [start = static_cast<double>(gain_), end = static_cast<double>(target), last,
                            scale](std::size_t frame) noexcept {
        // Scale after adding the weighted endpoints so exact crossings stay zero with fused multiply-add.
        return static_cast<float>((start * (last - frame) + end * (frame + 1)) * scale);
    };
    if (coefficients_.empty())
    {
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
            apply_gain<false>(output.channel(ch), input.channel(ch), frames, 1.0f, target, steady, ramp_gain);
    }
    else
    {
        output.clear();
        for (std::size_t dst_ch = 0; dst_ch < output.channels(); ++dst_ch)
        {
            auto *dst = output.channel(dst_ch);
            for (std::size_t src_ch = 0; src_ch < input.channels(); ++src_ch)
            {
                const auto coefficient = coefficients_[dst_ch * input.channels() + src_ch];
                if (coefficient != 0)
                    apply_gain<true>(dst, input.channel(src_ch), frames, coefficient, target, steady, ramp_gain);
            }
        }
    }
    gain_ = target;
}
} // namespace aereborn

#include "mixer.h"
#include <stdexcept>
namespace aereborn
{
namespace
{
PortSpec mixer_output(SampleRate rate, std::size_t channels, std::size_t inputs)
{
    const PortSpec spec(rate, channels);
    if (!spec.valid() || inputs == 0)
        throw std::invalid_argument("Mixer needs valid ports and at least one input");
    return spec;
}
} // namespace
Mixer::Mixer(SampleRate rate, std::size_t channels, std::size_t inputs)
    : output_(mixer_output(rate, channels, inputs)), inputs_(inputs, output_),
      targets_(std::make_unique<std::atomic<bool>[]>(inputs)), muted_(inputs)
{
    for (std::size_t i = 0; i < inputs; ++i)
        std::atomic_init(&targets_[i], false);
}
View<const PortSpec> Mixer::inputs() const noexcept
{
    return {inputs_.data(), inputs_.size()};
}
View<const PortSpec> Mixer::outputs() const noexcept
{
    return {&output_, 1};
}
RetCode Mixer::set_muted(std::size_t input, bool muted) noexcept
{
    if (input >= inputs_.size())
        return ErrorCode::InvalidPort;
    targets_[input].store(muted, std::memory_order_release);
    return {};
}
RetCode Mixer::prepare(BlockPeriod)
{
    reset();
    return {};
}
void Mixer::reset() noexcept
{
    for (std::size_t i = 0; i < inputs_.size(); ++i)
        muted_[i] = targets_[i].load(std::memory_order_acquire);
}
void Mixer::process(const ProcessContext &context) noexcept
{
    const auto output = context.outputs[0].f32p_view();
    const auto frames = output.frames();
    if (frames == 0)
        return;
    output.clear();
    for (std::size_t i = 0; i < inputs_.size(); ++i)
    {
        const bool target = targets_[i].load(std::memory_order_acquire);
        const bool ramping = muted_[i] != target;
        if (target && !ramping)
            continue;
        const auto input = context.inputs[i].f32p_view();
        const auto gain = muted_[i] ? 0.0 : 1.0;
        const auto step = ramping ? (target ? -1.0 : 1.0) / frames : 0.0;
        const auto last = frames - 1;
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
        {
            auto *dst = output.channel(ch);
            const auto *src = input.channel(ch);
            if (ramping)
            {
                for (std::size_t frame = 0; frame < last; ++frame)
                    dst[frame] += src[frame] * static_cast<float>(gain + step * (frame + 1));
                if (!target)
                    dst[last] += src[last];
            }
            else
            {
                for (std::size_t frame = 0; frame < frames; ++frame)
                    dst[frame] += src[frame];
            }
        }
        muted_[i] = target;
    }
}
} // namespace aereborn

#include <cstring>

Tone::Tone(SampleRate rate, std::size_t channels, double frequency, float amplitude)
    : NodeT({}, {{PortSpec(rate, channels)}}), frequency_(frequency), amplitude_(amplitude)
{
    if (!outputs()[0].valid() || !(frequency >= 0 && frequency < static_cast<std::uint32_t>(rate) / 2.0) ||
        !std::isfinite(amplitude))
        throw std::invalid_argument("Invalid tone specification");
}
void Tone::process(const ProcessContext &context) noexcept
{
    const auto output = context.outputs[0].f32p_view();
    const auto frames = output.frames();
    if (frames == 0)
        return;
    const auto spec = outputs()[0];
    const auto step = 6.28318530717958647692 * frequency_ / static_cast<std::uint32_t>(spec.sample_rate);
    const auto start = spec.frame_position(context.block_period, context.tick_position);
    const auto phase = std::fmod(static_cast<double>(start) * step, 6.28318530717958647692);
    auto *first = output.channel(0);
    for (std::size_t frame = 0; frame < frames; ++frame)
        first[frame] = amplitude_ * static_cast<float>(std::sin(phase + frame * step));
    for (std::size_t ch = 1; ch < output.channels(); ++ch)
        std::memcpy(output.channel(ch), first, frames * sizeof(float));
}
} // namespace aereborn

===== examples/clocked_graph.cpp =====
#include "core/engine.h"
#include "plugins/matrix.h"
#include "plugins/mixer.h"
#include "plugins/tone.h"
#include <atomic>
#include <chrono>
#include <cmath>
#include <iostream>
#include <stdexcept>
#include <thread>
namespace
{
using namespace aereborn;
void checked(RetCode code)
{
    if (!code)
        throw std::runtime_error(code.message());
}
template <class T> T checked(Result<T> result)
{
    checked(result.ret_code());
    return std::move(result).value();
}
class Meter final : public NodeT<1, 0>
{
  public:
    explicit Meter(std::atomic<float> &level) : NodeT({{PortSpec(SampleRate::Hz48000, 1)}}, {}), level_(level) {}
    RetCode prepare(BlockPeriod) override
    {
        return {};
    }
    void process(const ProcessContext &context) noexcept override
    {
        const auto input = context.inputs[0].f32p_view();
        float level = 0;
        for (std::size_t i = 0; i < input.frames(); ++i)
            level = std::max(level, std::abs(input.channel(0)[i]));
        level_.store(level, std::memory_order_relaxed);
    }

  private:
    std::atomic<float> &level_;
};
} // namespace
int main()
{
    try
    {
        std::atomic<float> level{0};
        Engine engine(BlockPeriod::Ms05);
        const auto tone = checked(engine.emplace_node<Tone>(SampleRate::Hz48000, 1));
        const auto mix = checked(engine.emplace_node<Mixer>(SampleRate::Hz48000, 1, 1));
        const auto matrix = checked(engine.emplace_node<Matrix>(SampleRate::Hz48000, 1));
        const auto sink = checked(engine.emplace_node<Meter>(level));
        checked(engine.connect({tone}, {mix}));
        checked(engine.connect({mix}, {matrix}));
        checked(engine.connect({matrix}, {sink}));
        auto *gain = checked(engine.node<Matrix>(matrix));
        checked(engine.commit());
        checked(engine.start());
        const auto wait = [&]
        {
            const auto target = engine.tick_position() + 4;
            const auto deadline = std::chrono::steady_clock::now() + std::chrono::seconds(3);
            while (engine.tick_position() < target)
            {
                if (std::chrono::steady_clock::now() > deadline)
                    throw std::runtime_error("Audio timeout");
                std::this_thread::sleep_for(std::chrono::milliseconds(1));
            }
            std::cout << "tick=" << engine.tick_position() << " peak=" << level.load() << '\n';
        };
        wait();
        checked(gain->set_gain(0.5f));
        wait();
        checked(engine.stop());
    }
    catch (const std::exception &error)
    {
        std::cerr << error.what() << '\n';
        return 1;
    }
}
