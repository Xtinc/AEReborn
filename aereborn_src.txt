
===== AudioEngine_Outline.md =====
# AEReborn：音频引擎框架草案

项目使用 C++14。时钟运行和计划后台回收使用 standalone Asio。设备、文件和网络后端沿用本稿定义的运行边界。
命名空间统一为 `aereborn`，方向类型采用 `IPort/OPort`、`IBlock/OBlock` 的对称命名。
离线图和虚拟 PCM 路径已由第一阶段验证。第二阶段由时钟驱动同一套渲染逻辑，实际 API、运行约定和构建方法见第 7 节。

## 1. 参考与取舍

下面区分成熟引擎已有的设计，以及本项目据此作出的选择。参考设计思路，不引入这些引擎作为依赖。

| 官方参考 | 可借鉴的设计 | 本项目的选择 |
| --- | --- | --- |
| [JUCE AudioProcessorGraph](https://docs.juce.com/master/classjuce_1_1AudioProcessorGraph.html) | 处理器组成节点图，通过通道连接；提供图重建机制 | 统一 Node/Port/Connection，将图描述编译为执行计划 |
| [JACK 实时处理回调](https://jackaudio.org/api/group__ClientCallbacks.html) | 处理回调禁止内存分配及可能阻塞的 I/O、锁和等待 | 音频执行路径只处理已准备的数据，外部工作通过有界队列交换 |
| [PipeWire 图运行](https://docs.pipewire.org/devel/page_running.html)、[调度](https://docs.pipewire.org/page_scheduling.html)、[时钟](https://docs.pipewire.org/page_man_pipewire-props_7.html) | 调度组选择 driver；配置与数据处理分离；区分设备时钟并适配 | 第一版只做一个渲染执行域、一个 ClockDriver，预留边界时钟适配 |
| [FMOD 混音与连接](https://www.fmod.com/docs/2.04/api/mixing-and-routing-in-the-core-api.html)、[DSPConnection](https://www.fmod.com/docs/2.04/api/core-api-dspconnection.html) | 总线分组、子混音、效果处理；连接持有增益和声道矩阵 | Bus 可接 Bus；Connection 持有增益、静音和声道矩阵，处理器保持单一职责 |

第一版不做多进程共享图、节点并行调度、插件宿主或完整 DAW 自动化系统。先实现能运行、能恢复、能验证的单进程引擎。

## 2. 核心概念与节点实现

Engine 只处理 Node、Port、Connection 三个核心概念。它拥有节点和连接，校验图、准备缓冲并按依赖顺序执行节点；不需要识别节点的具体业务角色。

```text
Node A 的 OPort ── Connection ──> Node B 的 IPort
```

| 对象 | 定位 |
| --- | --- |
| Node | 具有输入/输出端口的执行单元 |
| Port | 节点上的多声道音频入口或出口，带声道布局 |
| Connection | 输出端口到输入端口的有向连接，独立持有增益、静音和声道矩阵 |

Port 按方向使用 `IPort/OPort` 引用。`PortSpec` 固定声明采样率、声道数和格式。连接两端必须完全一致，否则返回 `FormatMismatch`；需要转换时显式插入 Convert。一个输入端口只能接一个来源，重复占用返回 `InputConnected`，多路求和使用 Mixer 的不同输入。没有连接的输入得到该格式的零值静音。
一个 Port 表示一组声道，声道间的选择、复制、合并由 Connection 的矩阵表达。
`NodeId/ConnId` 是类型化句柄，原型采用进程内不复用的唯一 ID。Node 不持有其他 Node 的共享所有权，也不各自维护连接列表或调度循环。

Source、Processor、Mixer、Sink 是具体节点的用途。`plugins/` 中的 Capture、Playback 是设备缓冲交接节点，Convert 是格式与采样率转换节点。Mixer、Matrix 和 Tone 是只支持 planar float 的普通插件；算法节点可以声明自己需要的 PCM 格式。

| 用途 | 职责 | 当前实现 |
| --- | --- | --- |
| Source | 向图提供音频 | `Capture`、`Tone` |
| Processor | 处理输入并产生输出 | `Convert`、`Matrix`、用户算法节点 |
| Mixer | 显式合并多个相同规格的输入 | `Mixer` |
| Sink | 消费音频并交给设备 | `Playback` |

PCM 适配器和固定端口数量的自定义节点通常继承 `NodeT<I, O>`，由它保存端口描述。节点在 `prepare(BlockPeriod)` 中取得统一推进周期，数据规格来自自身端口。端口数量由运行时决定的节点可以直接继承 `Node`，通过 `inputs()/outputs()` 提供固定的端口描述。引擎持有节点期间借用这些描述，节点负责保持描述及其存储有效。
后续设备、文件、网络、滤波等节点遵循同一边界。Bus 表示 Mixer 与效果节点构成的应用层总线，不是新的核心基类。

### 从输出创建输入：直接复用端口

任何 OPort 都能继续连接到其他节点。Bus 可提供 PreEffects、PostEffects、PostFader 等命名输出位置，第一版先提供最终输出。
需要取得总线音频时，从相应输出连接普通 Sink；需要其他数据规格时连接 Convert，再由算法节点或 Playback 消费结果。图核心不提供独立的端口订阅机制。
编译器保证一个节点每个渲染块只执行一次，同一输出供多个下游只读使用；需要修改数据的下游使用自己的工作缓冲。

这支持“输出作为另一个输入”，并且不依赖物理设备是否在线。系统全局回环录音则作为独立 CaptureSource 能力接入。
第一版拒绝所有图内反馈环，校验同时覆盖音频与侧链依赖。

## 3. 引擎骨架

core 提供 Node、端口描述、只读/可写块视图、ClockDriver 和 Engine。plugins 提供按功能命名的 Convert、Mixer、Matrix、Capture、Playback、Tone。

Engine 持有编辑图和渲染计划。prepare() 按依赖排序，从无输出的 Sink 遍历可达节点；未连接到 Sink 的分支不执行。每个可达节点每周期只执行一次。

引擎按各端口的最大周期帧数预分配缓冲。F32P 存储为真正的 float 对象，PCM 存储为字节。连接输入只读借用上游输出，不复制、不混音；未连接的输入使用预分配的零值缓冲。所有缓冲和块视图由 Engine 管理，不通过节点虚接口查询数据地址。

ProcContext 提供 tick_position、inputs 和 outputs。IPortBlock / OPortBlock 携带端口规格和本周期实际帧数。普通 float 插件声明 F32P 后使用 audio() 取得 IBlock / OBlock；PCM 插件使用 bytes()，不必处理其他格式。视图只在 process() 调用内有效，节点必须写满自己的输出。

渲染计划直接保存已绑定的输入、输出视图，每个 tick 只更新实际帧数。构图节点索引在 prepare() 返回前释放，缓冲归属由计划统一保存。

控制侧 prepare() 完成所有分配和节点准备，再提交至多一个待应用计划；音频线程在周期边界接管。原有连接参数、隐式矩阵、增益斜坡、输入累加及参数 FIFO 已删除。节点身份不变时保留 DSP 状态；旧计划在驱动确认不再使用后由控制侧或后台回收，音频线程不释放旧计划。

## 4. 执行与时钟

第一版只有一个串行渲染执行域：任意时刻只有一个执行上下文可以调用 render。
选定的 ClockDriver 驱动整张图，其他设备仅通过边界适配器交换数据，不分别执行同一张图。
引擎周期是运行时的基础节拍。当前 Capture / Playback 每次交接一个基础周期的数据；后端负责将实际硬件收发整理为这个粒度，不要求硬件周期本身与图周期相同。跨周期拼拆包插件留待后续实现。

| 场景 | ClockDriver |
| --- | --- |
| 主设备周期等于引擎周期 | 该设备的音频回调或设备 I/O 线程可提供基础节拍 |
| 设备周期覆盖多个引擎周期 | 由基础周期驱动器推进图，设备在各自的周期边界收发 |
| 主设备掉线、纯网络或无物理设备 | 独立的 TimerDriver，保持逻辑时间推进 |
| 确定性测试 | 测试时钟逐块触发 |

主设备由显式配置或确定的选择策略指定，可以是采集或播放设备，不把某一方向写死为主时钟。
主设备能提供基础节拍时，可以直接在其回调或设备线程执行渲染。
主驱动切换须先确认旧驱动退出，再接管执行权；帧序号继续递增，并报告时钟切换或数据不连续。

Engine(BlockPeriod) 只固定推进周期，不持有全局采样率或音频格式。block_period() 返回周期，tick_position() 返回已完成的周期数，停止后重启继续计数，reset() 归零。每个 process() 收到本周期开始时的 tick_position。

端口支持 1 至 96000 Hz 的整数采样率。Format::F32P 是原生 planar float32；S16LE、S24_3LE、S24LE、S32LE、F32LE 是交错小端 PCM。连接匹配包含采样率、声道数、样本格式及其布局，不做自动协商或隐式转换。

每个端口按累计时间的向上取整差值计算本周期实际帧数。44.1 kHz / 5 ms 为 221、220 帧交替，11.025 kHz 等规格也不逐周期独立取整；PortSpec::max_frames() 用于容量，frames() 和 frame_position() 用于实际块与该端口的样本时间。不同采样率端口仍由同一个基础周期驱动。Convert 将分数相位对齐到共享 tick，运行中新增或替换节点不会另起采样时钟。

ClockDriver 每次触发一个完整周期，包括空图。默认时钟仍使用 standalone Asio 的单调定时器，延误时跳过过期定时期限，逻辑时间只按实际执行的 tick 前进。本轮所有可达节点每 tick 调用一次；不同算法处理间隔、独立设备时钟和跨周期拼拆包留给后续插件。

从设备与引擎时钟不一致时，在边界做缓冲与自适应重采样。即使标称采样率相同，也不能默认两个设备共享时钟。

### Asio 与实时处理的边界

Asio 负责控制命令、UDP I/O、设备事件、恢复定时及非实时任务协调。
设备打开/关闭、文件访问、编解码和应用回调都在非渲染路径完成。设备必要的实时缓冲交付由平台后端封装。
音频路径不分配/释放堆内存，不等待互斥锁，不打印日志，不调用普通应用回调，也不依赖一次 asio::post 在截止时间前完成。

```text
Asio 控制执行器 ──> 计划/参数 ──> 渲染路径
从设备 / 网络 / 文件 ──> 有界队列 ──> 音频入口节点
音频出口节点 ──> 有界队列 ──> 从设备 / 网络 / 文件
音频出口节点 ──> 有界队列 ──> 用户回调执行器
```

队列预先明确单/多生产者归属、容量和满队列行为。活跃数据流不允许无限堆积；慢回调只影响自身输出分支，录音写入跟不上时由后端报告数据缺口。
Engine 停止会等待图处理退出。后端负责等待自己的 I/O 与应用回调退出；不能仅取消定时器就释放仍在使用的对象。

## 5. 外部资源与恢复

逻辑端点长期存在，物理句柄归 DeviceSession。DeviceService 分开维护设备清单、选择策略与运行会话。
选择可以是固定设备、跟随系统默认、优先某类设备；不在收到任意插入事件后立即抢占当前设备。
设备身份使用平台稳定标识及匹配规则，不依赖枚举序号永久不变。

```text
逻辑意图：Running / Paused / Stopped
资源状态：WaitingDevice -> Opening -> Ready -> Recovering / Failed
```

两组状态分别维护：恢复完成仍要服从用户当前意图。
掉线期间保留图、音量和连接；缺失采集数据补静音并由后端记录缺口，输出设备不可用时丢弃该设备数据，总线及其他下游继续处理。
可就地恢复的欠载由后端处理；需重开、等待设备、不可恢复的配置错误由统一恢复策略区分。
重试带退避和取消，主动定期重开也是同一策略的选项。会话代际编号屏蔽过期打开结果与旧设备数据。

同一设备的兼容逻辑端点共享 DeviceSession。播放侧明确汇入该设备的最终混音节点，再交给唯一设备写入者；独占或格式冲突明确报错。
设备协商格式与逻辑音频格式分离，恢复不改变应用看到的端口布局；适配不了时报告端点失败。

网络与文件复用相同入口/出口节点机制：

- NetworkSource：会话识别、乱序整理、按播放期限解码/FEC/PLC，再交付音频。NetworkSink：排队、编码、发送。先 PCM，后 Opus；协议独立版本化。
- FileSource：工作线程预读，独立 PlaybackHandle 管理循环、暂停和停止。FileSink：排队写入，支持分段保存。
- PushSource：应用显式推入带格式、帧时间和连续性信息的音频，接口报告接收数量或队列满。
- 回调输出：普通 Sink 接收图内 float，或由 Convert 转换为所需 PCM。后端通过有界队列异步调用用户函数，负责数据所有权、缺口报告和停止屏障。

## 6. 混音策略归属

Mixer 显式求和，Matrix 负责声道映射与增益。两者都只支持 F32P，采样率由构造参数固定，并不要求整张图使用同一采样率。Mixer 每个输入与输出的规格相同；Matrix 的输入、输出声道数可不同，采样率保持一致。

Matrix 的行是目标声道，列是源声道，系数可用于选取、复制、合并和相位反转。全局增益与矩阵在同一遍采样处理中完成。Mixer 对每个输入独立静音。增益和静音改变在下一个处理块读取，并在该块内线性过渡到目标值，零增益或零系数跳过源样本，避免未使用的 NaN / Inf 污染输出。

总线可以由 Mixer、Matrix 和效果节点组成，不增加核心基类。Voice、Music、Alert 等抑制策略由后续插件产生增益目标，Engine 不识别角色或策略。

## 7. 时钟运行 API

应用创建 Engine，加入节点、连接端口、调用 prepare()，再用 start() 启动时钟。示例演示 Tone → Mixer → Matrix → 电平 Sink，以及运行中修改 Matrix 增益。[时钟运行示例](examples/clocked_graph.cpp)

### 固定能力与连接检查

插件通过不可变的 inputs()/outputs() 声明实际端口规格。Mixer、Matrix、Tone 构造函数只生成 F32P 端口；普通插件直接编写 float 算法。特殊算法声明其支持的固定 PCM 规格，Engine 在 connect() 时检查两端，准备阶段验证时序和资源。本版不增加动态能力列表或格式协商协议。

每个输入最多一个来源；同一输出可供多个下游只读使用。需要多路混音必须显式创建 Mixer 的多个输入。连接不包含增益、静音或矩阵，也不增加转换器。

下面的链路可以直接用 connect() 表达：

~~~text
Tone / BUS（48k F32P）
    → Convert（48k F32P → 16k S16LE）
    → 算法（固定 16k S16LE）
    → Convert（16k S16LE → 48k F32P）
    → 其他节点 / Playback
~~~

### 插件接口

| 插件 | 端口 | 配置与职责 |
| --- | --- | --- |
| Convert(input_spec, output_spec) | (1,1) | 支持上述全部格式的转换和固定比例重采样，要求两端声道数相同 |
| Mixer(rate, channels, inputs) | (N,1) | 相同 F32P 规格显式求和；set_muted(index, bool) 控制单个输入 |
| Matrix(rate, input_channels, output_channels, coefficients, gain) | (1,1) | F32P 声道映射与增益；行对应输出、列对应输入，系数固定；set_gain() 更新增益 |
| Matrix(rate, channels, gain) | (1,1) | 使用恒等声道映射，仅控制增益 |
| Capture(spec) | (0,1) | 将后端绑定的一周期字节复制进 Engine 输出缓冲；缺少数据时输出静音 |
| Playback(spec) | (1,0) | 将输入复制进后端绑定的一周期缓冲；无缓冲时丢弃数据 |
| Tone(rate, channels, frequency, amplitude) | (0,1) | 按端口样本时间生成 F32P 正弦波 |

相同规格的 Convert 按字节直通，无需转换状态或工作区；同采样率 PCM → F32P 直接写入 Engine 输出，不经中间 float 缓冲。其余路径只准备实际转换需要的工作区。

需要 PCM 声道映射时，先 Convert 到 F32P，经过 Matrix，再按需要 Convert 回 PCM。Convert 不负责声道矩阵，Capture / Playback 不负责转换。

### 运行控制与缓冲交接

- 图编辑修改草稿，prepare() 返回计划版本；运行时在块边界生效，applied_revision() 返回已接管的版本。已有待应用计划时再次提交新草稿返回 BufferFull；准备失败保留当前计划。
- replace_node() 要求输入、输出的数量及完整规格相同，否则返回 FormatMismatch。改变设备格式时，显式替换相应设备节点与 Convert 并重建连接，可用一次 prepare() 共同提交；稳定的下游 float 节点继续运行。
- set_paused() 通过计划移除或恢复节点及相关连接，未改动实例保留状态。暂停导致某个输入失去来源时，该输入得到静音。需要平滑暂停时，先淡出 Matrix 增益或静音 Mixer 输入，再提交暂停。
- Matrix 增益和 Mixer 静音是插件自己的无锁原子目标，不占用 Engine 的计划提交槽；每块读取最新值，不保留逐条参数命令 FIFO。控制侧持有的插件指针只在节点仍被拥有时使用。
- Capture / Playback 在 prepare() 后接受 bind(bytes, tick_position)，字节数必须恰好等于该 tick 的端口帧数乘声道数和样本宽度。已有绑定时返回 BufferFull；绑定和 reset 与处理串行，借用内存在指定 tick 结束前保持有效。未来 tick 的绑定保留到该 tick，过期数据不再输出。
- 设备 I/O、跨线程队列、长设备包及完成通知由后端负责，本轮 bind 只交接一个图周期。不提供物理设备驱动或算法后台服务。
- stop() 等待驱动和在途处理退出，停止后台回收并应用已接受的计划；reset() 只允许在停止时调用，归零 tick 并重置节点。处理或准备期间同步修改 Engine 返回 Busy，tick_position() 和 applied_revision() 可并发查询。
- 处理路径不分配/释放内存、不等待锁、不调用普通应用回调。异步使用块数据必须在 process() 返回前复制到后端自有缓冲。

### 构建与验证

项目使用 C++14、standalone Asio 和 Threads。CMake 搜索仓库根目录的 asio-1.30.2/include；其他位置通过 ASIO_INCLUDE_DIR 指定。应用链接 aereborn::plugins，单独使用核心可链接 aereborn::core。

cmake --build build --config Debug --parallel 4

cmake --build build --config Release --parallel 4

测试按 core、runtime、routing、convert、resampling、mix、device、tone、allocation、example 分组。混音、格式转换和重采样使用独立字节或数值参照；完整算法链验证不同格式节点直接连线。覆盖分数帧、格式拒绝、禁止隐式混音、只读共享、参数斜坡、计划切换、停止屏障、失败恢复和实时路径无堆操作。

后续真实设备接入仍需后端处理短读写、硬件缓冲、不同设备时钟漂移、会话代际和热插拔；这些职责不进入 Engine 的格式校验与图调度。

## 8. 实现顺序

1. **离线图核心**：Node、Port、Connection、音频块及 Engine 的准备与执行。用插件节点验证多对多、处理器串联、总线互连、输出分发、环路拒绝。
2. **运行内核**：ClockDriver、块边界计划切换、插件参数、显式 Mixer/Matrix、停止屏障。验证调音量不重建图，修改连接不重置未变节点的状态。
3. **一个平台的设备闭环**：主设备驱动、多设备边界适配、DeviceSession、热插拔与恢复。验证同一张图只被一个驱动执行，拔插不破坏其他连接；再接另一个平台。
4. **文件、推入和混音策略**：预读/录制、PlaybackHandle、PushSource、DSP 链、ducking。验证多实例、循环、过载报告和增益包络。
5. **网络**：先 PCM，再 Opus、乱序/抖动缓冲与丢包恢复；验证本地与远程源进入同一 Bus，断网后有界退化并恢复。

第一步先写少量核心类型和离线执行，不接系统设备，不启动 Asio 线程。每一步复用同一张图与同一套节点执行机制。

第一步的验收用例包括 `core.audio_block_layout`、`core.prepare_retry`、`routing.explicit_mix_and_fanout`、`routing.algorithm_chain`、`routing.silence_and_pruning` 和 `core.feedback_rejection`。路由走实际的 Convert、Mixer 和 Matrix，算法由声明固定 PCM 格式的测试节点提供。

第二步的验收覆盖 `runtime` 用例、`allocation.render_uses_prepared_buffers` 和 `example.clocked_graph`。

# AEReborn 编程约束

## 1. 命名

**变量名用能清楚表达含义的最短写法。** 缩写应当能从组合词或局部上下文直接读懂。需要查注释才能知道变量指什么时，用全称。

| 场景 | 写法 |
| --- | --- |
| 连接 | 单独指一个连接时用 `connection`。组合词可用 `conn`，如 `conn_id`、`conn_count`。 |
| 声道 | 声道循环的索引用 `ch`。声明端口时用 `channels` 表示声道数，用 `input_channels`、`output_channels` 区分方向。 |
| 采样率 | 配置和公开接口用 `sample_rate`。重采样内部可以用常见的 DSP 记号 `src_fs`、`dst_fs`。 |
| 帧、采样点、字节 | 根据单位使用 `frames`、`samples`、`bytes`。含义可能混淆时，用 `frame_offset`、`byte_offset` 或 `period_ms` 写明单位。 |

- **成对的变量保持对称。** 用同一组方向词、相同的后缀和缩写程度，例如 `src_fs` / `dst_fs`、`input_channels` / `output_channels`、`from` / `to`。同一个值在相邻函数中沿用同一术语。
- **名字反映变量的用途。** `conn_count` 是数量，`conn_index` 是索引。短循环可以用 `i` 和 `ch`，跨多个步骤使用的变量写明角色，例如 `frame_offset`。
- **沿用项目的拼写风格。** 局部变量、参数和函数用 `snake_case`，私有成员变量在末尾加 `_`，如 `frame_position_`。类型和枚举值通常用 `PascalCase`，例如 `ConnId`、`ErrorCode::InvalidPort`。PCM 枚举沿用 `S16LE`、`S24_3LE`、`F32LE` 这样的格式名。

## 2. 类型与接口

- 优先复用现有类型。只有在需要表达独立的含义、约束、所有权或生命周期时才引入新类型。单纯的数量和索引使用现有整数类型。
- 一项规格只保留一个定义来源。采样率和 PCM 格式由 `core/types.h` 提供，样本位深和存储字节数从 `Format` 推导。端口固定声明采样率、声道数和格式，Engine 只持有推进周期。普通 DSP 插件声明 F32P，特殊模块声明其实际格式，转换由 Convert 完成。
- 函数名和参数顺序应能直接说明调用方向。底层函数、辅助记录和临时状态放在使用它们的实现范围内。对外接口集中表达调用方需要配置、传递或查询的内容。
- 保持调用路径直接。抽取能消除重复、集中维护同一约束的逻辑，优先选用普通函数和直接的成员状态。模板用于确有编译期差异的场景，例如固定端口数量。采样率和处理周期作为运行时规格传递。

## 3. 错误处理

- 参数、状态和容量校验等可预期的操作失败通过 `RetCode` 返回，需要同时返回结果时用 `Result<T>`。检查成功后再读 `value()`。
- 标准库的分配异常和自定义节点在构造或准备时抛出的异常交由调用方处理。构造函数可以抛异常来维护对象不变量。会分配资源或调用可抛异常代码的控制侧接口允许异常传播，实时 `process()` 保持 `noexcept`。
- 在建立约束的入口做校验。连接时检查完整端口规格和输入占用，Matrix 构造时检查矩阵尺寸，绑定设备缓冲时检查长度与占用状态。处理路径直接使用已经校验和准备好的数据。
- 资源准备成功后再发布可用状态。失败时保留有效状态，使调用方可以重试。内部不变量可以用断言表达。

## 4. 音频处理

- 每次时钟触发推进一个固定的引擎周期。节点按自身端口规格写满输出块，连接只读借用上游输出，每个输入只接一个来源。多路混音由 Mixer 完成；Matrix 的行对应输出声道，列对应输入声道。
- 普通 DSP 使用按声道存放的 IEEE float32，PCM 算法使用明确声明的字节格式。Convert 统一承担格式和采样率转换，Matrix 承担声道映射与增益，设备节点只交接数据。同采样率的 float32 保持样本的位表示，只做复制和必要的布局、字节序调整。
- 在 `prepare()` 中分配缓冲并准备滤波等资源。把阻塞 I/O、锁等待、日志和堆分配放在实时处理路径之外。接口借用缓冲时，应写清谁持有缓冲以及它需要保持有效的时间。

## 5. 修改与验证

- 使用 C++14。修改集中在受影响的接口和实现，沿用周围代码的风格。注释优先说明约束和原因。
- 沿实际调用入口验证改动。优先复用现有测试，在现有测试覆盖不到具体回归时补充用例。音频转换和图处理的边界用实际帧数、声道数和输出值验证。
- 路由测试使用 Tone 或测试源，经 Convert、Mixer、Matrix 和测试收端验证显式图；设备交接使用 Capture / Playback。格式转换使用独立的字节参照，混音和重采样使用独立的数值参照。测试按职责分组、每个场景独立注册到 CTest；共用准备和断言工具，不复制路由驱动逻辑。

项目的接口、处理流程和构建方法见 [AudioEngine_Outline.md](AudioEngine_Outline.md)。

namespace aereborn
{
// Non-owning view. A nonempty view refers to a valid contiguous range.
template <class T> class View
{
  public:
    View(T *data, std::size_t size) noexcept : data_(data), size_(size)
    {
    }
    template <class U, typename std::enable_if<std::is_convertible<U (*)[], T (*)[]>::value, int>::type = 0>
    View(View<U> other) noexcept : data_(other.data()), size_(other.size())
    {
    }
    T *data() const noexcept
    {
        return data_;
    }
    std::size_t size() const noexcept
    {
        return size_;
    }
    bool empty() const noexcept
    {
        return size_ == 0;
    }
    T *begin() const noexcept
    {
        return data_;
    }
    T *end() const noexcept
    {
        return size_ == 0 ? data_ : data_ + size_;
    }
    T &operator[](std::size_t index) const noexcept
    {
        assert(index < size_);
        return data_[index];
    }

  private:
    T *data_;
    std::size_t size_;
};

static_assert(sizeof(float) == 4 && std::numeric_limits<float>::is_iec559, "Audio samples require IEEE float32");

// Non-owning planar views. frames() is the processing span, including any padded tail.
template <class T> class Block
{
    static_assert(std::is_same<typename std::remove_const<T>::type, float>::value, "Audio samples must be float");
    template <class> friend class Block;

  public:
    Block() noexcept = default;
    Block(T *data, std::size_t channels, std::size_t frames, std::size_t channel_stride) noexcept
        : data_(data), channels_(channels), frames_(frames), channel_stride_(channel_stride)
    {
        assert(frames <= channel_stride);
    }
    template <class U, typename std::enable_if<std::is_convertible<U *, T *>::value, int>::type = 0>
    Block(Block<U> other) noexcept
        : data_(other.data_), channels_(other.channels_), frames_(other.frames_), channel_stride_(other.channel_stride_)
    {
    }
    T *channel(std::size_t ch) const noexcept
    {
        assert(ch < channels_);
        return data_ + ch * channel_stride_;
    }
    std::size_t channels() const noexcept
    {
        return channels_;
    }
    std::size_t frames() const noexcept
    {
        return frames_;
    }
    template <class U = T, typename std::enable_if<!std::is_const<U>::value, int>::type = 0> void clear() const noexcept
    {
        for (std::size_t ch = 0; ch < channels_; ++ch)
        {
            std::fill_n(channel(ch), frames_, 0.0f);
        }
    }

  private:
    T *data_ = nullptr;
    std::size_t channels_ = 0;
    std::size_t frames_ = 0;
    std::size_t channel_stride_ = 0;
};

using IBlock = Block<const float>;
using OBlock = Block<float>;

// Allocation belongs to construction/preparation, never to block processing.
class Buffer
{
  public:
    RetCode resize(std::size_t channels, std::size_t capacity_frames);
    OBlock block(std::size_t frames) noexcept;
    std::size_t capacity_frames() const noexcept;

  private:
    std::vector<float> samples_;
    std::size_t channels_ = 0;
    std::size_t capacity_frames_ = 0;
};

} // namespace aereborn

#endif // AEREBORN_CORE_BLOCK_H

std::uint64_t next_identifier() noexcept
{
    static std::atomic<std::uint64_t> next{1};
    return next.fetch_add(1, std::memory_order_relaxed);
}

struct GraphNode
{
    explicit GraphNode(std::unique_ptr<Node> instance)
        : node(std::move(instance)), inputs(node->inputs()), outputs(node->outputs())
    {
    }
    View<const PortSpec> ports(IPort) const noexcept { return inputs; }
    View<const PortSpec> ports(OPort) const noexcept { return outputs; }
    std::unique_ptr<Node> node;
    const View<const PortSpec> inputs;
    const View<const PortSpec> outputs;
    bool prepared = false;
};
bool same_ports(View<const PortSpec> a, View<const PortSpec> b) noexcept
{
    return a.size() == b.size() && std::equal(a.begin(), a.end(), b.begin());
}
struct Connection
{
    OPort from;
    IPort to;
};

// Float storage contains actual float objects; PCM storage is byte-addressable.
// Input views alias an upstream output or an immutable zero-filled buffer.
struct PortBuffer
{
    Result<OPortBlock> prepare(PortSpec format, BlockPeriod period)
    {
        const auto frames = format.max_frames(period);
        const auto width = sample_bytes(format.format);
        if (format.format == Format::F32P)
        {
            if (format.channels > audio.max_size() / frames)
                return ErrorCode::TooLarge;
            audio.resize(format.channels * frames);
        }
        else
        {
            if (format.channels > pcm.max_size() / frames / width)
                return ErrorCode::TooLarge;
            pcm.resize(format.channels * frames * width);
        }
        auto *data = format.format == Format::F32P ? reinterpret_cast<std::uint8_t *>(audio.data()) : pcm.data();
        return OPortBlock{data, format, frames};
    }
    std::vector<float> audio;
    std::vector<std::uint8_t> pcm;
};
struct PlanNode
{
    NodeId id;
    std::shared_ptr<GraphNode> entry;
    std::vector<IPortBlock> inputs;
    std::vector<OPortBlock> outputs;
};
struct RenderPlan
{
    PlanRevision revision = 0;
    std::vector<PortBuffer> buffers;
    std::vector<PlanNode> nodes;
    Result<OPortBlock> add_buffer(PortSpec format, BlockPeriod period)
    {
        if (buffers.size() == buffers.max_size())
            return ErrorCode::TooLarge;
        // Views point into the owned allocations, which stay valid when PortBuffer is moved.
        buffers.emplace_back();
        return buffers.back().prepare(format, period);
    }
    void render(BlockPeriod period, std::uint64_t tick) noexcept
    {
        for (auto &item : nodes)
        {
            for (auto &input : item.inputs)
                input = {input.bytes().data(), input.spec(), input.spec().frames(period, tick)};
            for (auto &output : item.outputs)
                output = {output.bytes().data(), output.spec(), output.spec().frames(period, tick)};
            item.entry->node->process(
                {tick, {item.inputs.data(), item.inputs.size()}, {item.outputs.data(), item.outputs.size()}});
        }
    }
};
using Incoming = std::map<NodeId, std::vector<const Connection *>>;
using NodeIndex = std::map<NodeId, std::size_t>;
} // namespace

struct Engine::Runtime
{
    explicit Runtime(BlockPeriod period) : period(period) {}
    const BlockPeriod period;
    std::map<NodeId, std::shared_ptr<GraphNode>> nodes;
    std::map<ConnId, Connection> connections;
    std::set<NodeId> paused;
    std::unique_ptr<RenderPlan> current;
    std::unique_ptr<RenderPlan> pending;
    std::mutex plans_mutex;
    RenderPlan *active = nullptr;
    std::atomic<RenderPlan *> submitted{nullptr};
    std::unique_ptr<ClockDriver> driver;
    std::unique_ptr<RuntimeTask> maintenance;
    std::atomic<PlanRevision> applied{0};
    std::atomic<std::uint64_t> position{0};
    bool dirty = true;

    bool on_execution_thread() const noexcept { return engine_execution_context == this; }
    template <class Port> Result<PortSpec> port_spec(Port port) const noexcept
    {
        const auto found = nodes.find(port.node);
        if (found == nodes.end())
            return ErrorCode::UnknownNode;
        const auto ports = found->second->ports(port);
        if (port.index >= ports.size())
            return ErrorCode::InvalidPort;
        return ports[port.index];
    }
    bool would_cycle(NodeId from, NodeId to) const
    {
        std::vector<NodeId> stack{to};
        std::set<NodeId> visited{to};
        while (!stack.empty())
        {
            const auto id = stack.back();
            stack.pop_back();
            if (id == from)
                return true;
            for (const auto &item : connections)
                if (item.second.from.node == id && visited.insert(item.second.to.node).second)
                    stack.push_back(item.second.to.node);
        }
        return false;
    }
    RetCode visit(NodeId id, const Incoming &incoming, RenderPlan &plan, NodeIndex &node_index)
    {
        if (node_index.count(id))
            return {};
        const auto found = incoming.find(id);
        if (found != incoming.end())
            for (const auto *connection : found->second)
            {
                const auto code = visit(connection->from.node, incoming, plan, node_index);
                if (!code)
                    return code;
            }
        const auto &entry = nodes.find(id)->second;
        if (!entry->prepared)
        {
            const auto code = entry->node->prepare(period);
            if (!code)
                return code;
            entry->prepared = true;
        }
        node_index.emplace(id, plan.nodes.size());
        plan.nodes.push_back(
            {id, entry, std::vector<IPortBlock>(entry->inputs.size()), std::vector<OPortBlock>(entry->outputs.size())});
        return {};
    }
    RetCode build_plan(RenderPlan &plan)
    {
        if (!is_block_period(period))
            return ErrorCode::InvalidArg;
        Incoming incoming;
        NodeIndex node_index;
        for (const auto &item : connections)
            if (!paused.count(item.second.from.node) && !paused.count(item.second.to.node))
                incoming[item.second.to.node].push_back(&item.second);
        for (const auto &item : nodes)
            if (!paused.count(item.first) && item.second->outputs.empty())
            {
                const auto code = visit(item.first, incoming, plan, node_index);
                if (!code)
                    return code;
            }
        for (auto &item : plan.nodes)
        {
            for (std::size_t port = 0; port < item.outputs.size(); ++port)
            {
                const auto block = plan.add_buffer(item.entry->outputs[port], period);
                if (!block)
                    return block.ret_code();
                item.outputs[port] = block.value();
            }
            const auto found = incoming.find(item.id);
            if (found != incoming.end())
                for (const auto *connection : found->second)
                    item.inputs[connection->to.index] =
                        plan.nodes[node_index.find(connection->from.node)->second].outputs[connection->from.index];
            for (std::size_t port = 0; port < item.inputs.size(); ++port)
                if (!item.inputs[port].bytes().data())
                {
                    const auto block = plan.add_buffer(item.entry->inputs[port], period);
                    if (!block)
                        return block.ret_code();
                    item.inputs[port] = block.value();
                }
        }
        return {};
    }
    void activate(RenderPlan *plan) noexcept
    {
        active = plan;
        applied.store(plan->revision, std::memory_order_release);
    }
    std::unique_ptr<RenderPlan> collect() noexcept
    {
        if (pending && applied.load(std::memory_order_acquire) == pending->revision)
        {
            auto retired = std::move(current);
            current = std::move(pending);
            return retired;
        }
        return {};
    }
    void maintain()
    {
        const EngineExecutionScope scope(this);
        std::unique_ptr<RenderPlan> retired;
        {
            const std::lock_guard<std::mutex> lock(plans_mutex);
            retired = collect();
        }
    }
    void apply_pending() noexcept
    {
        if (auto *plan = submitted.exchange(nullptr, std::memory_order_acquire))
            activate(plan);
    }
    static void tick(void *context) noexcept
    {
        auto &runtime = *static_cast<Runtime *>(context);
        const EngineExecutionScope scope(context);
        runtime.apply_pending();
        const auto tick = runtime.position.load(std::memory_order_relaxed);
        runtime.active->render(runtime.period, tick);
        runtime.position.store(tick + 1, std::memory_order_release);
    }
};

Engine::Engine(BlockPeriod period) : runtime_(std::make_unique<Runtime>(period)) {}
Engine::~Engine()
{
    stop();
}

Result<NodeId> Engine::add_node(std::unique_ptr<Node> instance)
{
    if (runtime_->on_execution_thread())
        return ErrorCode::Busy;
    if (!instance)
        return ErrorCode::InvalidArg;
    auto entry = std::make_shared<GraphNode>(std::move(instance));
    if (entry->inputs.empty() && entry->outputs.empty())
        return ErrorCode::InvalidArg;
    for (const auto ports : {entry->inputs, entry->outputs})
        for (const auto &port : ports)
            if (!port.valid())
                return ErrorCode::InvalidArg;
    const NodeId id{next_identifier()};
    runtime_->nodes.emplace(id, std::move(entry));
    runtime_->dirty = true;
    return id;
}
RetCode Engine::remove_node(NodeId id) noexcept
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread())
        return ErrorCode::Busy;
    if (!runtime.nodes.erase(id))
        return ErrorCode::UnknownNode;
    for (auto it = runtime.connections.begin(); it != runtime.connections.end();)
        if (it->second.from.node == id || it->second.to.node == id)
            it = runtime.connections.erase(it);
        else
            ++it;
    runtime.paused.erase(id);
    runtime.dirty = true;
    return {};
}
RetCode Engine::replace_node(NodeId id, std::unique_ptr<Node> replacement)
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread())
        return ErrorCode::Busy;
    const auto found = runtime.nodes.find(id);
    if (found == runtime.nodes.end())
        return ErrorCode::UnknownNode;
    if (!replacement)
        return ErrorCode::InvalidArg;
    auto entry = std::make_shared<GraphNode>(std::move(replacement));
    if (!same_ports(found->second->inputs, entry->inputs) || !same_ports(found->second->outputs, entry->outputs))
        return ErrorCode::FormatMismatch;
    found->second = std::move(entry);
    runtime.dirty = true;
    return {};
}
RetCode Engine::set_paused(NodeId id, bool paused)
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread())
        return ErrorCode::Busy;
    if (!runtime.nodes.count(id))
        return ErrorCode::UnknownNode;
    const bool changed = paused ? runtime.paused.insert(id).second : runtime.paused.erase(id) != 0;
    runtime.dirty |= changed;
    return {};
}
Result<Node *> Engine::node(NodeId id) noexcept
{
    const auto result = static_cast<const Engine &>(*this).node(id);
    if (!result)
        return result.ret_code();
    return const_cast<Node *>(result.value());
}
Result<const Node *> Engine::node(NodeId id) const noexcept
{
    if (runtime_->on_execution_thread())
        return ErrorCode::Busy;
    const auto found = runtime_->nodes.find(id);
    if (found == runtime_->nodes.end())
        return ErrorCode::UnknownNode;
    return found->second->node.get();
}
Result<ConnId> Engine::connect(OPort from, IPort to)
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread())
        return ErrorCode::Busy;
    const auto source = runtime.port_spec(from);
    if (!source)
        return source.ret_code();
    const auto destination = runtime.port_spec(to);
    if (!destination)
        return destination.ret_code();
    if (source.value() != destination.value())
        return ErrorCode::FormatMismatch;
    for (const auto &item : runtime.connections)
        if (item.second.to.node == to.node && item.second.to.index == to.index)
            return item.second.from.node == from.node && item.second.from.index == from.index
                       ? ErrorCode::DuplicateConn
                       : ErrorCode::InputConnected;
    if (runtime.would_cycle(from.node, to.node))
        return ErrorCode::Cycle;
    const ConnId id{next_identifier()};
    runtime.connections.emplace(id, Connection{from, to});
    runtime.dirty = true;
    return id;
}
RetCode Engine::disconnect(ConnId id) noexcept
{
    if (runtime_->on_execution_thread())
        return ErrorCode::Busy;
    if (!runtime_->connections.erase(id))
        return ErrorCode::UnknownConn;
    runtime_->dirty = true;
    return {};
}
Result<PlanRevision> Engine::prepare()
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread())
        return ErrorCode::Busy;
    std::unique_ptr<RenderPlan> retired;
    const std::lock_guard<std::mutex> lock(runtime.plans_mutex);
    retired = runtime.collect();
    if (!runtime.dirty)
        return (runtime.pending ? runtime.pending : runtime.current)->revision;
    if (runtime.pending)
        return ErrorCode::BufferFull;
    auto plan = std::make_unique<RenderPlan>();
    const EngineExecutionScope scope(&runtime);
    const auto code = runtime.build_plan(*plan);
    if (!code)
        return code;
    const auto revision = runtime.current ? runtime.current->revision + 1 : 1;
    plan->revision = revision;
    if (runtime.driver)
    {
        runtime.pending = std::move(plan);
        runtime.submitted.store(runtime.pending.get(), std::memory_order_release);
    }
    else
    {
        runtime.activate(plan.get());
        runtime.current = std::move(plan);
    }
    runtime.dirty = false;
    return revision;
}
RetCode Engine::start(std::unique_ptr<ClockDriver> driver)
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread() || runtime.driver)
        return ErrorCode::Busy;
    if (!runtime.current)
        return ErrorCode::NotPrepared;
    if (!runtime.submitted.is_lock_free() || !runtime.applied.is_lock_free() || !runtime.position.is_lock_free())
        return ErrorCode::Unsupported;
    runtime.driver = driver ? std::move(driver) : make_timer_driver();
    try
    {
        runtime.maintenance = start_background_task([&runtime] { runtime.maintain(); });
        const auto code = runtime.driver->start(runtime.period, &Runtime::tick, &runtime);
        if (!code)
            stop();
        return code;
    }
    catch (...)
    {
        stop();
        throw;
    }
}
RetCode Engine::stop() noexcept
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread())
        return ErrorCode::Busy;
    if (runtime.driver)
    {
        runtime.driver->stop();
        runtime.driver.reset();
        runtime.maintenance.reset();
        runtime.apply_pending();
        runtime.collect();
    }
    return {};
}
RetCode Engine::reset() noexcept
{
    auto &runtime = *runtime_;
    if (runtime.on_execution_thread() || runtime.driver)
        return ErrorCode::Busy;
    if (runtime.current)
        for (const auto &item : runtime.current->nodes)
        {
            const auto draft = runtime.nodes.find(item.id);
            if (draft == runtime.nodes.end() || draft->second != item.entry)
                item.entry->node->reset();
        }
    for (const auto &item : runtime.nodes)
        item.second->node->reset();
    runtime.position.store(0, std::memory_order_release);
    return {};
}
BlockPeriod Engine::block_period() const noexcept
{
    return runtime_->period;
}
std::uint64_t Engine::tick_position() const noexcept
{
    return runtime_->position.load(std::memory_order_acquire);
}
PlanRevision Engine::applied_revision() const noexcept
{
    return runtime_->applied.load(std::memory_order_acquire);
}

        case ErrorCode::DuplicateConn:
            return "These ports are already connected";
        case ErrorCode::Cycle:
            return "Connection would create a feedback cycle";
        case ErrorCode::NotPrepared:
            return "Preparation is required";
        case ErrorCode::BufferFull:
            return "A buffer is full or still in use";
        case ErrorCode::TooLarge:
            return "Requested capacity exceeds the supported size";
        case ErrorCode::Busy:
            return "The current execution context or state prevents this operation";
        case ErrorCode::FormatMismatch:
            return "Port formats do not match; connect a converter";
        case ErrorCode::InputConnected:

        case ErrorCode::Unsupported:

        }
        return "Unknown error code";
    }

  private:
    ErrorCode code_;
};

// For graph results with default-constructible values. Check the status before reading the value.
template <class T> class Result

  public:
    Result(T value) noexcept(std::is_nothrow_move_constructible<T>::value) : value_(std::move(value))

    }

        assert(!code);
    }
    Result(ErrorCode code) noexcept(std::is_nothrow_default_constructible<T>::value) : Result(RetCode(code))
    {
    }
    RetCode ret_code() const noexcept
    {
        return ret_code_;
    }
    explicit operator bool() const noexcept
    {
        return static_cast<bool>(ret_code_);
    }
    const T &value() const & noexcept
    {
        assert(ret_code_);
        return value_;
    }
    T value() && noexcept(std::is_nothrow_move_constructible<T>::value)
    {
        assert(ret_code_);
        return std::move(value_);
    }

  private:
    RetCode ret_code_;
    T value_{};
};

namespace aereborn

thread_local const void *engine_execution_context = nullptr;

namespace
{
// Scheduling and timer allocation are outside the Engine tick.
class PeriodicTask final : public RuntimeTask
{
  public:
    PeriodicTask(std::chrono::steady_clock::duration period, std::function<void()> run)
        : period_(period),
          deadline_(std::chrono::steady_clock::now() + period_), run_(std::move(run))
    {
        schedule();
        thread_ = std::thread([this] { context_.run(); });
    }
    ~PeriodicTask() override
    {
        context_.stop();
        thread_.join();
    }

  private:
    void schedule()
    {
        timer_.expires_at(deadline_);
        timer_.async_wait([this](const asio::error_code &error) {
            if (error || context_.stopped())
            {
                return;
            }
            run_();
            if (!context_.stopped())
            {
                const auto now = std::chrono::steady_clock::now();
                const auto lateness = now - deadline_;
                deadline_ += period_ * (lateness >= period_ ? lateness / period_ + 1 : 1);
                schedule();
            }
        });
    }

    asio::io_context context_;
    asio::steady_timer timer_{context_};
    const std::chrono::steady_clock::duration period_;
    std::chrono::steady_clock::time_point deadline_;
    std::function<void()> run_;
    std::thread thread_;
};

class TimerDriver final : public ClockDriver
{
  public:
    RetCode start(BlockPeriod block_period, Tick tick, void *context) override
    {
        const auto period = std::chrono::milliseconds(static_cast<std::uint32_t>(block_period));
        task_ = std::make_unique<PeriodicTask>(period, [tick, context] { tick(context); });
        return {};
    }
    void stop() noexcept override
    {
        task_.reset();
    }

  private:
    std::unique_ptr<RuntimeTask> task_;
};
} // namespace

std::unique_ptr<ClockDriver> make_timer_driver()
{
    return std::make_unique<TimerDriver>();
}

std::unique_ptr<RuntimeTask> start_background_task(std::function<void()> run)
{
    const std::chrono::duration<double> period(1.0 / 30.0);
    return std::make_unique<PeriodicTask>(std::chrono::duration_cast<std::chrono::steady_clock::duration>(period),
                                          std::move(run));
}

RetCode Buffer::resize(std::size_t channels, std::size_t capacity_frames)
{
    if (channels == 0 || capacity_frames == 0)
    {
        return ErrorCode::InvalidArg;
    }
    if (channels > samples_.max_size() / capacity_frames)
    {
        return ErrorCode::TooLarge;
    }
    const auto sample_count = channels * capacity_frames;
    const auto retained_samples = std::min(samples_.size(), sample_count);
    samples_.resize(sample_count);
    std::fill_n(samples_.begin(), retained_samples, 0.0f);
    channels_ = channels;
    capacity_frames_ = capacity_frames;
    return {};
}

OBlock Buffer::block(std::size_t frames) noexcept
{
    return {samples_.data(), channels_, frames, capacity_frames_};
}

std::size_t Buffer::capacity_frames() const noexcept
{
    return capacity_frames_;
}

std::size_t PortSpec::max_frames(BlockPeriod period) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    return static_cast<std::size_t>((units + 999) / 1000);
}

std::size_t PortSpec::frames(BlockPeriod period, std::uint64_t tick) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    const auto fraction = units % 1000;
    const auto start = (tick % 1000) * fraction;
    return static_cast<std::size_t>(units / 1000 + (start + fraction + 999) / 1000 - (start + 999) / 1000);
}

std::uint64_t PortSpec::frame_position(BlockPeriod period, std::uint64_t tick) const noexcept
{
    const auto units = std::uint64_t{static_cast<std::uint32_t>(sample_rate)} * static_cast<std::uint32_t>(period);
    // Split whole seconds from the remainder to avoid multiplying tick by the sample rate.
    return (tick / 1000) * units + ((tick % 1000) * units + 999) / 1000;
}

#ifndef AEREBORN_CORE_TYPES_H
#define AEREBORN_CORE_TYPES_H

#include "block.h"

namespace aereborn
{

enum class SampleRate : std::uint32_t
{
    Hz8000 = 8000,
    Hz11025 = 11025,
    Hz16000 = 16000,
    Hz22050 = 22050,
    Hz24000 = 24000,
    Hz32000 = 32000,
    Hz44100 = 44100,
    Hz48000 = 48000,
    Hz88200 = 88200,
    Hz96000 = 96000
};

enum class BlockPeriod : std::uint32_t
{
    Ms05 = 5,
    Ms10 = 10,
    Ms20 = 20,
    Ms40 = 40
};
constexpr bool is_block_period(BlockPeriod period) noexcept
{
    return period == BlockPeriod::Ms05 || period == BlockPeriod::Ms10 || period == BlockPeriod::Ms20 ||
           period == BlockPeriod::Ms40;
}

// F32P is native planar float32. The other formats are interleaved little-endian PCM.
enum class Format
{
    F32P,
    S16LE,
    S24_3LE,
    S24LE,
    S32LE,
    F32LE
};
constexpr unsigned int sample_bits(Format format) noexcept
{
    switch (format)
    {
    case Format::S16LE:
        return 16;
    case Format::S24_3LE:
    case Format::S24LE:
        return 24;
    case Format::F32P:
    case Format::S32LE:
    case Format::F32LE:
        return 32;
    }
    return 0;
}
constexpr std::size_t sample_bytes(Format format) noexcept
{
    return format == Format::S24LE ? 4 : sample_bits(format) / 8;
}

struct PortSpec
{
    constexpr PortSpec() noexcept = default;
    constexpr PortSpec(SampleRate rate, std::size_t channels, Format format = Format::F32P) noexcept
        : sample_rate(rate), channels(channels), format(format)
    {
    }
    constexpr bool valid() const noexcept
    {
        return static_cast<std::uint32_t>(sample_rate) > 0 && sample_rate <= SampleRate::Hz96000 && channels > 0 &&
               sample_bytes(format) != 0;
    }
    constexpr bool operator==(const PortSpec &other) const noexcept
    {
        return sample_rate == other.sample_rate && channels == other.channels && format == other.format;
    }
    constexpr bool operator!=(const PortSpec &other) const noexcept { return !(*this == other); }
    std::size_t max_frames(BlockPeriod period) const noexcept;
    std::size_t frames(BlockPeriod period, std::uint64_t tick) const noexcept;
    std::uint64_t frame_position(BlockPeriod period, std::uint64_t tick) const noexcept;

    SampleRate sample_rate{};
    std::size_t channels = 0;
    Format format = Format::F32P;
};

// A read-only or writable view of one port's current block. Storage is owned by Engine.
// audio() is for plugins whose declared ports are F32P; bytes() exposes any declared format.
template <class T> class PortBlock
{
    template <class> friend class PortBlock;
    using Sample = typename std::conditional<std::is_const<T>::value, const float, float>::type;

  public:
    PortBlock() noexcept = default;
    PortBlock(T *data, PortSpec spec, std::size_t frames) noexcept : data_(data), spec_(spec), frames_(frames) {}
    template <class U, typename std::enable_if<std::is_convertible<U *, T *>::value, int>::type = 0>
    PortBlock(PortBlock<U> other) noexcept : data_(other.data_), spec_(other.spec_), frames_(other.frames_)
    {
    }
    PortSpec spec() const noexcept { return spec_; }
    std::size_t frames() const noexcept { return frames_; }
    View<T> bytes() const noexcept { return {data_, frames_ * spec_.channels * sample_bytes(spec_.format)}; }
    Block<Sample> audio() const noexcept
    {
        assert(spec_.format == Format::F32P);
        return {reinterpret_cast<Sample *>(data_), spec_.channels, frames_, frames_};
    }

  private:
    T *data_ = nullptr;
    PortSpec spec_;

#include "convert.h"

#include <cstring>

constexpr std::size_t order = 48;
constexpr std::size_t taps = 2 * order;
constexpr std::uint32_t phase_steps = 100;
constexpr double pi = 3.141592653589793;

std::uint32_t read_le(const std::uint8_t *input, std::size_t bytes) noexcept
{
    std::uint32_t raw = 0;
    for (std::size_t i = 0; i < bytes; ++i)
    {
        raw |= static_cast<std::uint32_t>(input[i]) << (8 * i);
    }
    return raw;
}

void write_le(std::uint32_t raw, std::uint8_t *output, std::size_t bytes) noexcept
{
    for (std::size_t i = 0; i < bytes; ++i)
    {
        output[i] = static_cast<std::uint8_t>(raw >> (8 * i));
    }
}

float decode_integer(std::uint32_t raw, unsigned int bits) noexcept
{
    const auto scale = std::int64_t{1} << (bits - 1);
    const auto value = std::int64_t{raw} & (2 * scale - 1);
    return static_cast<float>(value >= scale ? value - 2 * scale : value) / static_cast<float>(scale);
}

std::uint32_t encode_integer(float sample, unsigned int bits) noexcept
{
    const auto scale = std::int64_t{1} << (bits - 1);
    const auto normalized = std::isnan(sample) ? 0.0f : std::max(-1.0f, std::min(1.0f, sample));
    const auto rounded = static_cast<std::int64_t>(std::round(static_cast<double>(normalized) * scale));
    const auto value = std::min(scale - 1, rounded);
    return static_cast<std::uint32_t>(value) & static_cast<std::uint32_t>(2 * scale - 1);
}

bool native_f32le() noexcept
{
    const float one = 1.0f;
    constexpr std::uint8_t one_le[] = {0, 0, 0x80, 0x3f};
    return std::memcmp(&one, one_le, sizeof(one)) == 0;
}

void copy_f32le(const std::uint8_t *pcm, OBlock output) noexcept
{
    if (output.channels() == 1 && native_f32le())
    {
        std::memcpy(output.channel(0), pcm, output.frames() * sizeof(float));
        return;
    }
    for (std::size_t frame = 0; frame < output.frames(); ++frame)
    {
        for (std::size_t ch = 0; ch < output.channels(); ++ch, pcm += sizeof(float))
        {
            const auto raw = read_le(pcm, sizeof(float));
            std::memcpy(output.channel(ch) + frame, &raw, sizeof(raw));
        }
    }
}

void copy_f32le(IBlock input, std::uint8_t *pcm) noexcept
{
    if (input.channels() == 1 && native_f32le())
    {
        std::memcpy(pcm, input.channel(0), input.frames() * sizeof(float));
        return;
    }
    for (std::size_t frame = 0; frame < input.frames(); ++frame)
    {
        for (std::size_t ch = 0; ch < input.channels(); ++ch, pcm += sizeof(float))
        {
            std::uint32_t raw;
            std::memcpy(&raw, input.channel(ch) + frame, sizeof(raw));
            write_le(raw, pcm, sizeof(raw));
        }
    }
}

// Window and cutoff ported from AudioDriver's SincInterpolator.
double sinc_kernel(double x, double cutoff) noexcept
{
    if (std::abs(x) >= order)
    {
        return 0.0;
    }
    const auto angle = (2.0 * pi * (x + 1.0 - order)) / (taps - 1);
    const auto window =
        0.3635819 - 0.4891775 * std::cos(angle) + 0.1365995 * std::cos(2 * angle) - 0.0106411 * std::cos(3 * angle);
    const auto sinc_angle = pi * cutoff * x;
    const auto sinc = sinc_angle == 0 ? 1.0 : std::sin(sinc_angle) / sinc_angle;
    return sinc * window;
}

using Coefficients = std::array<float, taps>;

void calc_coffs(const float *kernel, std::uint32_t dst_fs, std::uint64_t src_pos, Coefficients &coffs) noexcept
{
    const auto phase_pos = (src_pos % dst_fs) * phase_steps;
    const auto phase_index = phase_pos / dst_fs;
    const auto phase_frac = static_cast<float>(phase_pos % dst_fs) / static_cast<float>(dst_fs);
    const auto *lo_coffs = kernel + phase_index * taps;
    const auto *hi_coffs = lo_coffs + taps;
    for (std::size_t i = 0; i < taps; ++i)
    {
        coffs[i] = lo_coffs[i] + (hi_coffs[i] - lo_coffs[i]) * phase_frac;
    }
}

float interpolate(const float *history, const float *input, std::size_t history_taps,
                  const Coefficients &coffs) noexcept
{
    double sum = 0;
    for (std::size_t i = 0; i < history_taps; ++i)
    {
        sum += history[i] * coffs[i];
    }
    for (std::size_t i = history_taps; i < taps; ++i)
    {
        sum += input[i - history_taps] * coffs[i];
    }
    return static_cast<float>(sum);
}

} // namespace

struct Convert::State
{
    State(PortSpec input, PortSpec output, BlockPeriod period)
        : input(input), output(output), period(period), src_fs(static_cast<std::uint32_t>(input.sample_rate)),
          dst_fs(static_cast<std::uint32_t>(output.sample_rate))
    {
    }
    RetCode prepare()
    {
        if (input.format != Format::F32P && (src_fs != dst_fs || output.format != Format::F32P))
        {
            const auto code = decoded.resize(input.channels, input.max_frames(period));
            if (!code)
                return code;
        }
        if (src_fs != dst_fs)
        {
            if (output.format != Format::F32P)
            {
                const auto code = converted.resize(output.channels, output.max_frames(period));
                if (!code)
                    return code;
            }
            const auto code = history.resize(input.channels, taps);
            if (!code)
                return code;
            kernel.resize((phase_steps + 1) * taps);
            const auto cutoff = std::min(1.0, static_cast<double>(dst_fs) / src_fs) * 0.98;
            for (std::uint32_t phase = 0; phase <= phase_steps; ++phase)
            {
                auto *coffs = kernel.data() + phase * taps;
                const auto fraction = static_cast<double>(phase) / phase_steps;
                double scale = 0;
                for (std::size_t i = 0; i < taps; ++i)
                {
                    coffs[i] = static_cast<float>(sinc_kernel(fraction + order - 1 - i, cutoff));
                    scale += coffs[i];
                }
                for (std::size_t i = 0; i < taps; ++i)
                    coffs[i] = static_cast<float>(coffs[i] / scale);
            }
        }
        return {};
    }
    void resample(IBlock input, OBlock output, std::uint64_t tick) noexcept;
    const PortSpec input;
    const PortSpec output;
    const BlockPeriod period;
    const std::uint32_t src_fs;
    const std::uint32_t dst_fs;
    Buffer decoded;
    Buffer converted;
    Buffer history;
    std::vector<float> kernel;
};

void Convert::State::resample(IBlock input, OBlock output, std::uint64_t tick) noexcept
{
    const auto past = history.block(taps);
    // src_pos is in units of 1 / dst_fs; the first taps frames address history.
    const auto rounding = [this, tick](std::uint32_t rate)
    {
        const auto remainder =
            (tick % 1000) * ((std::uint64_t{rate} * static_cast<std::uint32_t>(period)) % 1000) % 1000;
        return static_cast<std::int64_t>((1000 - remainder) % 1000);
    };
    const auto phase = (rounding(dst_fs) * src_fs - rounding(src_fs) * dst_fs) / 1000;
    auto src_pos = static_cast<std::uint64_t>(dst_fs + phase);
    Coefficients coffs;
    for (std::size_t frame = 0; frame < output.frames(); ++frame, src_pos += src_fs)
    {
        calc_coffs(kernel.data(), dst_fs, src_pos, coffs);
        const auto frame_index = static_cast<std::size_t>(src_pos / dst_fs);
        const auto history_offset = std::min(frame_index, taps);
        const auto input_offset = frame_index - history_offset;
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
        {
            output.channel(ch)[frame] = interpolate(past.channel(ch) + history_offset, input.channel(ch) + input_offset,
                                                    taps - history_offset, coffs);
        }
    }

    const auto copy_frames = std::min(input.frames(), taps);
    const auto keep_frames = taps - copy_frames;
    for (std::size_t ch = 0; ch < input.channels(); ++ch)
    {
        auto *history_samples = past.channel(ch);
        std::memmove(history_samples, history_samples + copy_frames, keep_frames * sizeof(float));
        std::copy_n(input.channel(ch) + input.frames() - copy_frames, copy_frames, history_samples + keep_frames);
    }
}

Convert::Convert(PortSpec input, PortSpec output) : NodeT({{input}}, {{output}}) {}
Convert::~Convert() = default;
RetCode Convert::prepare(BlockPeriod period)
{
    const auto input = inputs()[0], output = outputs()[0];
    if (!is_block_period(period) || !input.valid() || !output.valid())
        return ErrorCode::InvalidArg;
    if (input.channels != output.channels)
        return ErrorCode::ChannelMismatch;
    if (input == output)
        return {};
    auto next = std::make_unique<State>(input, output, period);
    const auto code = next->prepare();
    if (code)
        state_.swap(next);
    return code;
}
void Convert::reset() noexcept
{
    if (state_)
        state_->history.block(state_->history.capacity_frames()).clear();
}
void Convert::process(const ProcContext &context) noexcept
{
    const auto input = context.inputs[0];
    const auto output = context.outputs[0];
    if (input.spec() == output.spec())
    {
        std::memcpy(output.bytes().data(), input.bytes().data(), input.bytes().size());
        return;
    }
    auto &state = *state_;
    IBlock samples;
    if (state.input.format == Format::F32P)
        samples = input.audio();
    else
    {
        const auto decoded = state.output.format == Format::F32P && state.src_fs == state.dst_fs
                                 ? output.audio()
                                 : state.decoded.block(input.frames());
        const auto *source = input.bytes().data();
        if (state.input.format == Format::F32LE)
            copy_f32le(source, decoded);
        else
        {
            const auto width = sample_bytes(state.input.format);
            for (std::size_t frame = 0; frame < input.frames(); ++frame)
                for (std::size_t ch = 0; ch < state.input.channels; ++ch, source += width)
                    decoded.channel(ch)[frame] =
                        decode_integer(read_le(source, width), sample_bits(state.input.format));
        }
        samples = decoded;
    }
    if (state.src_fs != state.dst_fs)
    {
        const auto converted =
            state.output.format == Format::F32P ? output.audio() : state.converted.block(output.frames());
        state.resample(samples, converted, context.tick_position);
        samples = converted;
    }
    if (state.output.format == Format::F32P)
        return;
    auto *destination = output.bytes().data();
    if (state.output.format == Format::F32LE)
        copy_f32le(samples, destination);
    else
    {
        const auto width = sample_bytes(state.output.format);
        for (std::size_t frame = 0; frame < samples.frames(); ++frame)
            for (std::size_t ch = 0; ch < state.output.channels; ++ch, destination += width)
                write_le(encode_integer(samples.channel(ch)[frame], sample_bits(state.output.format)), destination,
                         width);
    }
}

RetCode check_binding(PortSpec spec, BlockPeriod period, std::size_t bytes, std::uint64_t tick, bool bound) noexcept
{
    if (!is_block_period(period))
        return ErrorCode::NotPrepared;
    if (bound)
        return ErrorCode::BufferFull;
    const auto frames = spec.frames(period, tick);
    const auto width = sample_bytes(spec.format);
    if (frames && spec.channels > std::numeric_limits<std::size_t>::max() / frames / width)
        return ErrorCode::TooLarge;
    if (bytes != frames * spec.channels * width)
        return ErrorCode::InvalidArg;
    return {};
}
} // namespace
RetCode Capture::prepare(BlockPeriod period)
{
    if (!is_block_period(period) || !outputs()[0].valid())
        return ErrorCode::InvalidArg;
    period_ = period;
    return {};
}
RetCode Capture::bind(View<const std::uint8_t> bytes, std::uint64_t tick) noexcept
{
    if (bytes.size() && !bytes.data())
        return ErrorCode::InvalidArg;
    const auto code = check_binding(outputs()[0], period_, bytes.size(), tick, bound_);
    if (code)
    {
        bytes_ = bytes;
        tick_ = tick;
        bound_ = true;
    }
    return code;
}
void Capture::process(const ProcContext &context) noexcept
{
    const auto output = context.outputs[0].bytes();
    if (bound_ && tick_ == context.tick_position)
    {
        if (output.size())
            std::memcpy(output.data(), bytes_.data(), output.size());
    }
    else if (output.size())
        std::memset(output.data(), 0, output.size());
    if (bound_ && tick_ <= context.tick_position)
        reset();
}
void Capture::reset() noexcept
{
    bytes_ = {nullptr, 0};
    bound_ = false;
}

    : NodeT({{PortSpec(rate, channels)}}, {{PortSpec(rate, channels)}}), target_(gain), gain_(gain)

Matrix::Matrix(SampleRate rate, std::size_t input_channels, std::size_t output_channels, View<const float> coefficients,
               float gain)
    : NodeT({{PortSpec(rate, input_channels)}}, {{PortSpec(rate, output_channels)}}), target_(gain), gain_(gain)
{
    if (!inputs()[0].valid() || !outputs()[0].valid() || !std::isfinite(gain))
        throw std::invalid_argument("Invalid matrix specification");
    if (output_channels > coefficients_.max_size() / input_channels)
        throw std::length_error("Channel matrix exceeds supported size");
    if (coefficients.size() != input_channels * output_channels)
        throw std::invalid_argument("Channel matrix dimensions do not match coefficients");
    for (const auto value : coefficients)
        if (!std::isfinite(value))
            throw std::invalid_argument("Matrix coefficients must be finite");
    coefficients_.assign(coefficients.begin(), coefficients.end());
}
Matrix::Matrix(SampleRate rate, std::size_t input_channels, std::size_t output_channels,
               std::initializer_list<float> coefficients, float gain)
    : Matrix(rate, input_channels, output_channels, {coefficients.begin(), coefficients.size()}, gain)
{
}
RetCode Matrix::set_gain(float gain) noexcept
{
    if (!std::isfinite(gain))
        return ErrorCode::InvalidArg;
    target_.store(gain, std::memory_order_release);
    return {};
}
RetCode Matrix::prepare(BlockPeriod period)
{
    if (!is_block_period(period))
        return ErrorCode::InvalidArg;
    if (!target_.is_lock_free())
        return ErrorCode::Unsupported;
    reset();
    return {};
}
void Matrix::reset() noexcept
{
    gain_ = target_.load(std::memory_order_acquire);
}
void Matrix::process(const ProcContext &context) noexcept
{
    const auto input = context.inputs[0].audio();
    const auto output = context.outputs[0].audio();
    output.clear();
    const auto target = target_.load(std::memory_order_acquire);
    const auto frames = output.frames();
    const auto step = frames ? (static_cast<double>(target) - gain_) / frames : 0;
    for (std::size_t dst = 0; dst < output.channels(); ++dst)
    {
        const auto first = coefficients_.empty() ? dst : 0;
        const auto last = coefficients_.empty() ? dst + 1 : input.channels();
        for (std::size_t src = first; src < last; ++src)
        {
            const auto coefficient = coefficients_.empty() ? 1.0f : coefficients_[dst * input.channels() + src];
            if (coefficient == 0)
                continue;
            for (std::size_t frame = 0; frame < frames; ++frame)
            {
                const auto gain = frame + 1 == frames ? target : static_cast<float>(gain_ + step * (frame + 1));
                const auto scaled = coefficient * gain;
                if (scaled != 0)
                    output.channel(dst)[frame] += input.channel(src)[frame] * scaled;
            }
        }
    }
    gain_ = target;
}

        return ErrorCode::Unsupported;

        gains_[i] = muted_[i].load(std::memory_order_acquire) ? 0.0f : 1.0f;
}
void Mixer::process(const ProcContext &context) noexcept
{
    const auto output = context.outputs[0].audio();
    output.clear();
    for (std::size_t i = 0; i < inputs_.size(); ++i)
    {
        const auto input = context.inputs[i].audio();
        const auto target = muted_[i].load(std::memory_order_acquire) ? 0.0f : 1.0f;
        const auto step = output.frames() ? static_cast<double>(target - gains_[i]) / output.frames() : 0;
        for (std::size_t frame = 0; frame < output.frames(); ++frame)
        {
            const auto gain =
                frame + 1 == output.frames() ? target : static_cast<float>(gains_[i] + step * (frame + 1));
            if (gain == 0)
                continue;
            for (std::size_t ch = 0; ch < output.channels(); ++ch)
                output.channel(ch)[frame] += input.channel(ch)[frame] * gain;
        }
        gains_[i] = target;
    }
}

  private:

===== plugins/tone.cpp =====
#include "tone.h"
#include <cmath>
namespace aereborn
{
Tone::Tone(SampleRate rate, std::size_t channels, double frequency, float amplitude)
    : NodeT({}, {{PortSpec(rate, channels)}}), frequency_(frequency), amplitude_(amplitude)
{
}
RetCode Tone::prepare(BlockPeriod period)
{
    const auto rate = static_cast<std::uint32_t>(outputs()[0].sample_rate);
    if (!is_block_period(period) || !outputs()[0].valid() || !(frequency_ >= 0 && frequency_ < rate / 2.0) ||
        !std::isfinite(amplitude_))
        return ErrorCode::InvalidArg;
    period_ = period;
    return {};
}
void Tone::process(const ProcContext &context) noexcept
{
    const auto output = context.outputs[0].audio();
    const auto spec = outputs()[0];
    const auto step = 6.28318530717958647692 * frequency_ / static_cast<std::uint32_t>(spec.sample_rate);
    const auto start = spec.frame_position(period_, context.tick_position);
    const auto phase = std::fmod(static_cast<double>(start) * step, 6.28318530717958647692);
    for (std::size_t frame = 0; frame < output.frames(); ++frame)
    {
        const auto sample = amplitude_ * static_cast<float>(std::sin(phase + frame * step));
        for (std::size_t ch = 0; ch < output.channels(); ++ch)
            output.channel(ch)[frame] = sample;
    }
}
} // namespace aereborn

===== examples/clocked_graph.cpp =====
#include "core/engine.h"
#include "plugins/matrix.h"
#include "plugins/mixer.h"
#include "plugins/tone.h"
#include <atomic>
#include <chrono>
#include <cmath>
#include <iostream>
#include <stdexcept>
#include <thread>
namespace
{
using namespace aereborn;
void checked(RetCode code)
{
    if (!code)
        throw std::runtime_error(code.message());
}
template <class T> T checked(Result<T> result)
{
    checked(result.ret_code());
    return std::move(result).value();
}
class Meter final : public NodeT<1, 0>
{
  public:
    explicit Meter(std::atomic<float> &level) : NodeT({{PortSpec(SampleRate::Hz48000, 1)}}, {}), level_(level) {}
    RetCode prepare(BlockPeriod) override
    {
        return level_.is_lock_free() ? RetCode{} : RetCode{ErrorCode::Unsupported};
    }
    void process(const ProcContext &context) noexcept override
    {
        const auto input = context.inputs[0].audio();
        float level = 0;
        for (std::size_t i = 0; i < input.frames(); ++i)
            level = std::max(level, std::abs(input.channel(0)[i]));
        level_.store(level, std::memory_order_relaxed);
    }

  private:
    std::atomic<float> &level_;
};
} // namespace
int main()
{
    try
    {
        std::atomic<float> level{0};
        Engine engine(BlockPeriod::Ms05);
        const auto tone = checked(engine.emplace_node<Tone>(SampleRate::Hz48000, 1));
        const auto mix = checked(engine.emplace_node<Mixer>(SampleRate::Hz48000, 1, 1));
        const auto matrix = checked(engine.emplace_node<Matrix>(SampleRate::Hz48000, 1));
        const auto sink = checked(engine.emplace_node<Meter>(level));
        checked(engine.connect({tone}, {mix}));
        checked(engine.connect({mix}, {matrix}));
        checked(engine.connect({matrix}, {sink}));
        auto *gain = checked(engine.node<Matrix>(matrix));
        checked(engine.prepare());
        checked(engine.start());
        const auto wait = [&]
        {
            const auto target = engine.tick_position() + 4;
            const auto deadline = std::chrono::steady_clock::now() + std::chrono::seconds(3);
            while (engine.tick_position() < target)
            {
                if (std::chrono::steady_clock::now() > deadline)
                    throw std::runtime_error("Audio timeout");
                std::this_thread::sleep_for(std::chrono::milliseconds(1));
            }
            std::cout << "tick=" << engine.tick_position() << " peak=" << level.load() << '\n';
        };
        wait();
        checked(gain->set_gain(0.5f));
        wait();
        checked(engine.stop());
    }
    catch (const std::exception &error)
    {
        std::cerr << error.what() << '\n';
        return 1;
    }
}
